# 硬件侧信道与后量子密码研究资料

本项目整理硬件侧信道基础、NIST 后量子密码算法的攻击研究、安全实现方法与可复现评价路线。

## 研究资料

- [完整中文研究报告](docs/research/nist-pqc-hardware-sidechannel-report.md)：13 个章节，覆盖物理与统计基础、ML-KEM、ML-DSA、SLH-DSA、Falcon/HQC、故障交叉、硬件防护、随机数受限统一 IP、实验方案和研究选题。
- [原始研究证据索引](docs/research/evidence-matrix.md)：按平台、攻击结果粒度和核验范围整理 19 项代表性研究。

报告的信息截点为 **2026-09-11**，包含 36 项标准、原始论文及官方技术来源。Falcon 与 HQC 按仍在标准化中的算法讨论。

## 阅读建议

先读报告摘要与第 1–3 章，再按兴趣进入 ML-KEM 或 ML-DSA。硬件设计研究重点参考第 8–11 章，学习和研究推进参考第 12 章。引用实验数字时，请同时保留算法版本、平台、训练成本、攻击预算与结果粒度。

报告中的模 17 算例和随机数预算例为教学模型；研究设计为待验证建议。实验结论均引用原始来源，并明确区分实测、模拟、局部恢复和完整恢复。目录收录原创综述及文献链接，未收录第三方论文全文或未运行的攻击代码。
