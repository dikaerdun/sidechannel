# 第 4 章　攻击的本质：比较哪一个假设更能解释观测

[目录](../README.md) · [上一章](03-measurement.md) · [下一章](05-dpa-cpa.md)

本章的公式和数值例子是教学推导，用来建立不同分析方法之间的联系。

## 4.1 为什么不需要直接读出比特

设公开输入为 X，秘密为 K，中间值为 Z=f(X,K)，测量为 L。即使同一个 Z 对应很多可能的 L，不同 Z 的分布仍可能稍有不同。

例如某一位为 0 时，测量均值为 10；为 1 时均值为 10.2；两类标准差均为 1。一条观测很难判断，但很多观测可以积累证据。关键并非每次测量精确，而是不同秘密假设产生的预测分布是否可区分。

## 4.2 贝叶斯视角统一各种方法

收集 D={(x_i,l_i)}。假设给定密钥与输入后，各次观测条件独立：

$$\Pr(K=k\mid D)\propto\Pr(K=k)\prod_i p(l_i\mid x_i,k).$$

取对数得到：

$$S(k)=\log\Pr(K=k)+\sum_i\log p(l_i\mid x_i,k).$$

这说明每条迹线提供一小段证据；对数似然把证据相加。若设备漂移、共享随机状态或其他因素破坏独立假设，简单相加可能过度自信，需改模型或分批验证。

CPA 使用很简化的幅度关系；模板攻击直接学习条件分布；学习方法估计类别概率或似然相关评分；代数分析再把局部概率放入运算约束。它们都在比较秘密假设，只是使用信息的方式不同。

## 4.3 两个假设什么时候根本分不开

如果在允许输入和观测下，对任意 x 都满足：

$$p(L\mid x,k_1)=p(L\mid x,k_2),$$

那么仅靠这个通道无法区分 k_1 与 k_2。再多样本也不会改变这个事实。这是**不可辨识性**，与噪声过大不同。

另一个较弱的情况是：实际分布可区分，但你的统计量不可区分。比如两个假设的预测只相差符号，而评分只取绝对相关，则它们可能并列。此时要增加有物理根据的极性信息、其他中间值或另一种特征。

这正是“模型选错后采再多也没用”背后的两种不同原因：通道本身不足，或者分析方法丢掉了区分信息。

## 4.4 为什么正确假设能够越积越强

考虑真模型 p 与错误模型 q。单次观测的对数似然比为 log(p(L)/q(L))。在真模型下，它的期望是 KL 散度：

$$D_{KL}(p\Vert q)=\mathbb E_p\!\left[\log\frac{p(L)}{q(L)}\right]\ge0.$$

若每次提供同分布、条件独立的证据，N 次的期望对数优势约为 N 倍。KL 为零意味着模型完全一样；KL 很小意味着要更多证据。

这个解释比“平均可以去掉噪声”更完整：很多攻击不是简单平均电压，而是累计不同假设之间的可区分性。若输入可选择，就可以寻找使候选分布更容易区分的输入，但必须把这种输入能力写入威胁模型。

## 4.5 相关、SNR 与样本量

在简化模型 L=aH+N 中，H 与噪声 N 独立，定义：

$$SNR=\frac{a^2\operatorname{Var}(H)}{\operatorname{Var}(N)}.$$

则：

$$\rho(H,L)^2=\frac{SNR}{1+SNR}.$$

推导只需利用 Cov(H,N)=0，Var(L)=a²Var(H)+Var(N)。若噪声相关、增益变化或泄漏非线性，这个关系不再完整描述问题。

对于均值差 δ、每组 n 条、两组方差均为 σ²的情形，均值差的标准误为 σ√(2/n)。若希望标准化差异大致达到 z，则：

$$n\approx\frac{2z^2\sigma^2}{\delta^2}.$$

这只是量级估算，未计功效、重复检验与真实分布。它说明在其他条件不变时，把有效幅度减半，所需数据可能约增四倍；把噪声标准差增两倍，也可能约增四倍。

若噪声高度相关，平均后的方差为：

$$\operatorname{Var}(\bar N)=\frac1{n^2}\sum_{i,j}\operatorname{Cov}(N_i,N_j).$$

只有交叉协方差足够小时，才退化成 σ²/n。慢漂移不会自动被“多采一点”消除。

## 4.6 信息论直觉与计算安全要分开

可以用 I(K;L|X) 表达观测对秘密提供的条件信息，用 I(K;L|X,C) 表达在公开输入输出之外的额外信息。但真实密码的传统安全通常是计算意义上的；信息论上给定足够输入输出甚至无限算力，密钥可能已被确定。

因此不要用一个互信息公式代替复杂度分析。课堂中它用于解释泄漏结构；工程中还要问：可用算法、时间、内存、采样预算能否利用这些信息？
