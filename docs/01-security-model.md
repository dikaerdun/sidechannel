# 第 1 章　先把“安全”所讨论的系统说清楚

[返回目录](../README.md) · [下一章](02-physical-leakage.md)

## 1.1 从一个思想实验开始

假设一个理想加密接口只有输入明文 P 和输出密文 C，内部计算 C=E(K,P)。经典密码分析问：知道很多 P、C，是否还能有效求出 K？设计良好的算法使这件事非常困难。

现实芯片还会输出一条电流曲线、一个完成时间、一组电磁辐射。现在观察对象变成 `(P,C,T,L)`。E 没有变，攻击者能获得的信息却变多了。安全结论必须覆盖新接口，不能只引用旧接口下的证明。

这也解释了“算法没有被破解，产品却丢了密钥”并不矛盾。攻击可能完全绕开破解整个数学映射这条路线，利用执行过程中的局部中间值。

NIST 的 FIPS 203 明确区分算法符合性与实现安全：符合标准不保证一个具体实现或整个系统安全。这里不是标准失效，而是不同层次的保证范围不同。[原文：FIPS 203，Qualifications](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.203.pdf)

## 1.2 用四个对象描述一次研究

| 对象 | 应说明什么 | 常见混淆 |
|---|---|---|
| 算法 | 标准版本、参数集、操作阶段 | 把 Kyber 旧实现等同于 ML-KEM 全部实现 |
| 实现 | C/汇编/RTL、掩码、调度、内存布局 | 只写“AES”而不写是哪种 AES 实现 |
| 平台 | MCU/FPGA/ASIC、编译或综合结果 | 把 CPU 指令漏洞推广到固定延迟硬件 |
| 对手 | 可知、可控、可测、可重复的内容 | 将可编程模板设备视为自然拥有 |

一个合格的结论应该类似：“在某版未掩码 RTL 的指定 FPGA 布局上，用已知输入和本地功耗观测，在指定数据预算下恢复了一个子密钥。”每增加一个限定，结论反而更有科学价值，因为它变得可证伪、可复现。

## 1.3 “非侵入式”与“被动”是两个维度

非侵入式通常意味着不通过开封、去层、微探针直接接触芯片内部电路。它不等于完全不接触设备，也不等于毫无外部操作。

| 技术 | 常见接触条件 | 本教程的位置 |
|---|---|---|
| 时序观测 | 本地接口或远程往返时间 | 核心 |
| 功耗观测 | 板级供电通路、电流探头或测量接口 | 核心 |
| 近场电磁观测 | 探头靠近器件或走线，可能移除外壳 | 核心 |
| 声学、温度、软件可读能耗 | 依设备与接口而异 | 补充 |
| 阻抗测量 | 向供电网络施加测量激励并分析响应 | 非侵入式但不是纯被动，扩展阅读 |
| 时钟/电压故障注入 | 外部扰动使计算偏离正常行为 | 主动攻击，非本教程主线 |
| 芯片开封与内部探针 | 直接接触内部节点 | 不属本教程范围 |

同样使用电磁设备，“接收辐射”和“注入电磁脉冲”是不同任务。研究设计应分别陈述，不要用一个“电磁攻击”名称混过去。

## 1.4 对手能力决定方法是否成立

必须回答以下问题：

- **秘密是什么？** 长期密钥、一次性随机量、会话密钥、消息，还是隐式拒绝标志？
- **输入是否已知？** 已知输入与选择输入不同；后者能主动制造容易区分的中间值。
- **秘密是否复用？** 跨多次操作的纵向分析通常依赖同一秘密关系；一次性随机数不一定有这个条件。
- **能否做模板？** 分析者是否有可控制秘密的同类设备？训练设备与目标是否相似？
- **一次操作内是否有重复结构？** 即使秘密只用一次，数百个系数、比特或乘法仍可能构成横向样本。
- **能测到哪一段？** 核心运算、装载、预计算、失败尝试和清零都可能具有不同可见性。

“单迹线攻击”通常指目标设备的一次观测足够，不意味着无需训练，也不意味着那条迹线只有一个采样点。

## 1.5 给安全建立三层问题

第一层问：在测量链输出中，是否存在与敏感变量有关的统计差异？这是**泄漏存在性**。

第二层问：已采用的模型、数据和计算预算，能否把差异转化为较好的候选排序？这是**可利用性**。

第三层问：候选排序是否足以恢复目标秘密，进而破坏具体协议或系统属性？这是**安全后果**。

三层之间需要论证。看见固定/随机分组差异，不自动等于恢复私钥；只恢复某次封装消息，也不能在没有进一步攻击链的情况下宣称恢复长期解封装密钥。

## 本章自检

1. 若一个攻击需要一百万条可选输入迹线，另一攻击只需一条目标迹线但使用了十万条训练迹线，能否只按“一百万对一”比较？
2. 一个模块所有操作周期数相同，它满足了哪种安全要求，还没回答什么？
3. 你自己的 IP 中，最有价值的秘密在哪些阶段进入、被转换、被存储和离开？

答案与思考线索见[学习指南](15-learning-guide.md)。
