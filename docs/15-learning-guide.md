# 六周学习安排与习题答案

时间是建议安排，可按您的基础压缩。学习目标是能够独立解释原理、判断证据并提出可检验问题。

## 建议精读顺序

先读 DPA，再读 CPA，接着读模板攻击与 TVLA；有了掩码直觉后读 TI/DOM；最后读 FIPS 203/204 的核心流程及 KyberSlash、掩码 Kyber 实现。入口见[文献表](16-references.md)。

每篇论文做三遍阅读：第一遍找对象、对手和结果；第二遍沿着关键公式走一遍推断链；第三遍找假设与实验边界。不要第一遍就陷入设备型号和优化细节。

## 核心习题与答案线索

### 题 1：固定周期为何不能防止所有功耗攻击？

周期数只约束何时完成；每周期的数据翻转、进位、毛刺与存储更新仍可依赖秘密。必须把控制流安全与数据相关模拟泄漏分别处理。

### 题 2：为什么 0000 的结果也可能消耗明显动态能量？

若旧值是 1111，则 HD=4。动态能量与转换相关，而非只由新值的重量决定。

### 题 3：相关降到一半，采样量一定增加四倍吗？

只在简化小信号、独立噪声、其他条件基本不变的近似下，有这种量级关系。模型误差、相关噪声、错误候选相关性和多重搜索都会改变结果。

### 题 4：为什么 HW(P⊕k) 的绝对 CPA 会有互补歧义？

因为 H_{k⊕255}=8−H_k，去均值后两条预测互为负值，绝对相关相同。加入可验证的极性信息或改用其他中间值，才可能区分。

### 题 5：互信息能捕获非线性，为什么完整 S 盒输出标签仍可能分不出密钥？

对任意 k，Sbox(P⊕k) 是 P 的双射。互信息在双射重标号下不变。要用合适的泄漏映射或附加结构，而不是把“强统计工具”视为无条件密钥判别器。

### 题 6：推导字节掩码中心化乘积的期望。

每个位在 X_j=0 时贡献 +1/4，在 X_j=1 时贡献 −1/4，不同位中心化交叉项为零。总和为 (8−2HW(X))/4。代码提供对所有 X、R 的枚举验证。

### 题 7：同一寄存器先装 R，再装 X⊕R，会发生什么？

HD(R,X⊕R)=HW(X)。在该转换泄漏模型下，一次更新就重新暴露秘密相关量，不能仅靠单份额分布证明安全。

### 题 8：恢复 q=17、ω=4 蝶形中的 a、b。

u=10、v=13，2^−1=9、(2ω)^−1=15。a=(10+13)×9 mod17=3；b=(10−13)×15 mod17=6。

### 题 9：小秘密的 NTT 系数也可以只猜五种吗？

不能。小系数先验处于原域；NTT 输出是多个输入的线性组合。可利用的是联合变换约束，而非错误地复制逐系数取值范围。

### 题 10：ML-KEM 解封装不用新算法随机输入，就不需要掩码随机数吗？

不成立。算法随机性与侧信道共享随机性用途不同。确定性算法也可以、也可能需要随机化其物理实现。

### 题 11：ML-DSA 泄漏 y 后为什么不能一律写 s_1=(z−y)/c？

实际在多项式环中计算；只有 c 可逆时才能这样整体求逆。否则保留线性关系，结合可恢复的分量、更多观测与先验。部分泄漏和错误标签更不能视作精确方程。

### 题 12：TVLA 没有越阈，应怎样写结论？

写明“在给定实现、测点、输入分布、预处理、统计阶数和数据预算下未检测到相应差异”。不要写“已经证明不存在侧信道泄漏”。

### 题 13：随机化签名是否阻断所有跨交易分析？

不一定。长期秘密的装载、预计算和某些秘密相关操作仍可能重复；其他攻击可对一次执行内的重复结构作横向分析。

### 题 14：公开算法处理秘密数据，算不算敏感模块？

算。保密属性应跟随输入和内部状态。例如同一个 Keccak 模块处理公开矩阵种子与处理秘密派生材料时，保护义务不同。

## 最终练习：用一页纸解释一个攻击

选择 AES CPA、掩码二阶、ML-KEM 简化判定模型中的任意一个，完整写出：秘密 → 中间值 → 位模式/转换 → 测量模型 → 统计评分 → 恢复结果 → 成立条件 → 防护机制。

能把这八项连起来，就已经从“知道名称”走向“理解攻击为什么成立”。
