# 第 2 章　为什么比特会变成模拟信号

[目录](../README.md) · [上一章](01-security-model.md) · [下一章](03-measurement.md)

## 2.1 从电容充放电推导动态功耗

CMOS 逻辑中的节点有电容。电压从 0 变为 V，需要从电源取得电荷 Q=CV。理想充电过程从电源取得的能量为 CV²，其中一半储存在电容中，一半在充电通路中耗散；随后放电时储存的那一半也被耗散。

若某节点每个时钟周期发生 0→1 充电的平均次数为 α，则平均动态功耗近似为：

$$P_{dyn}=\alpha C V^2f.$$

这里把 α 定义为充电活动率；如果采用“全部翻转次数”的另一种定义，系数会变化。应先约定定义，再比较不同资料的公式。

关键变量是 α。秘密相关数据可能改变哪些节点翻转、翻转次数和翻转时刻，于是改变电流。测量者并不需要知道每个晶体管，只需要捕获这些变化的某种投影。

芯片总功耗还含短路电流、静态漏电、时钟树、存储与其他模块的活动。上式只是理解动态机制的起点，不是整片芯片的完整测量模型。

## 2.2 汉明重量与汉明距离到底在假设什么

定义：

$$HW(x)=\sum_jx_j,\qquad HD(x,y)=HW(x\oplus y).$$

HW 数“1”的个数；HD 数两个状态之间改变的位数。

| 旧值 → 新值 | 新值 HW | 状态 HD | 说明 |
|---|---:|---:|---|
| 0000 → 1111 | 4 | 4 | 从零状态装载，HW 与 HD 一致 |
| 1111 → 1111 | 4 | 0 | 值相同，但动态翻转很少 |
| 1111 → 0000 | 0 | 4 | 新值全零仍可能产生明显动态信号 |
| 0101 → 1010 | 2 | 4 | 相同重量不意味着相同转换活动 |

硬件寄存器更新通常更自然地关联 HD。若旧值接近固定参考值，例如预充电为零，HD 就退化为 HW。这是一个模型条件，不是“芯片消耗的能量天然等于 1 的数量”。

CPA 的经典工作把未知但固定的参考状态纳入汉明距离模型。它的价值在于把物理假设与统计预测联系起来。[Brier、Clavier、Olivier，CHES 2004](https://link.springer.com/chapter/10.1007/978-3-540-28632-5_2)

## 2.3 更现实的泄漏表达

一个局部时刻可先写成教学模型：

$$L=a\,HW(v)+b\,HD(u,v)+\sum_jc_jv_j+G(u,v)+N.$$

u、v 是相邻状态；各比特的负载不相等，故有 c_j；G 代表组合电路内部毛刺等未被简单模型捕获的活动；N 是模型外扰动。

这不是要求攻击先估计所有参数。恰恰相反，简单 HW/HD 模型之所以有用，是因为在某些实现上，它们已经捕获足够多的结构。模型失败后，应追问物理解释，而非默认“算法安全”。

还有一个容易忽略的因素：一个逻辑值在不同表示法下会形成不同位模式。模 q 的 −1 可以编码成 q−1，也可能暂存为二进制补码 −1。数学对象相同，32 位寄存器里的位模式可以很不一样。Montgomery 表示、延迟约减、符号扩展都会改变模型。

## 2.4 毛刺：最终结果看不见的计算

设一个 XOR 门的输入从 `(0,0)` 切换成 `(1,1)`。开始和结束的输出都是 0。但如果第一个输入先到，输出会经历 `0→1→0`。

逻辑仿真若只观察稳定值，可能记录零次输出变化；真实电路却已经充放电。更深的组合网络会把多条路径的延迟差映射成短暂活动。秘密可能影响毛刺的数量、持续时间和传播位置。

对掩码尤其重要：设计者认为两个份额在稳定值层面被隔离，但某个瞬态组合可能依赖它们的联合信息。因而“功能正确”和“稳态节点独立于秘密”不足以给真实电路作完整担保。阈值实现的重要出发点就是把毛刺纳入保护思考。[Nikova、Rechberger、Rijmen，ICICS 2006](https://link.springer.com/chapter/10.1007/11935308_38)

这里不要把内部组合毛刺与外部故障注入混淆：前者是正常运算的传播现象，后者故意改变运行条件。

## 2.5 静态泄漏为什么也值得考虑

即使寄存器不再翻转，晶体管的状态也可能影响漏电、供电网络响应等模拟性质。因此“停钟后没有动态翻转”不代表“存储内容没有物理影响”。

本教程的功耗实验主要模拟动态泄漏，没有证明静态泄漏不存在。扩展研究 LeakyOhm 分析了寄存器内容与阻抗响应之间的联系；它需要施加射频测量激励，因此属于非侵入式主动测量，而非纯被动接收。[作者论文](https://arxiv.org/abs/2310.07014)

## 2.6 不要把物理必然性夸大成攻击必然性

计算发生在物理世界中，但“消耗能量”不等于“可区分的密钥信息一定能从选定探头恢复”。信号可能与秘密无关，可能被隔离或充分随机化，也可能低于实际预算下的可利用程度。

真正要评价的是：**在允许的观测与资源下，不同秘密是否造成可利用的分布差异？** 这比“有电流就一定能破”准确得多。
