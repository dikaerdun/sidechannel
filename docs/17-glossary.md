# 术语表

[返回目录](../README.md)

| 缩写/术语 | 中文含义 | 在本教程中的准确用法 |
|---|---|---|
| SCA | 侧信道分析 | 利用实现附带的可观测行为分析敏感信息 |
| Non-invasive | 非侵入式 | 通常不直接接触芯片内部电路，不等同于被动 |
| Trace | 迹线 | 一次或一组操作的时间序列观测，不等同于单个采样点 |
| HW | 汉明重量 | 位串中 1 的数量 |
| HD | 汉明距离 | 两个位串不同的位数，HD(a,b)=HW(a⊕b) |
| SPA | 简单功耗分析 | 利用操作形状、序列或明显结构差异 |
| DPA | 差分功耗分析 | 本教程主要指基于选择函数的组间差分；文献有时作广义称呼 |
| CPA | 相关功耗分析 | 比较候选泄漏预测与观测的相关性 |
| Profiling | 建模/模板训练 | 使用带标签的可控设备或数据估计条件分布 |
| Template attack | 模板攻击 | 利用学习到的泄漏分布给秘密候选评分 |
| MIA | 互信息分析 | 用统计依赖度量分析泄漏；仍有模型和可辨识性条件 |
| Horizontal | 横向分析 | 利用一次执行内部的重复结构 |
| Vertical | 纵向分析 | 利用多次执行中的相关位置和秘密关系 |
| SASCA | 软分析侧信道方法 | 结合局部概率与代数关系传播证据 |
| POI | 兴趣点 | 为分析选取的采样位置或特征 |
| SNR | 信噪比 | 必须说明信号、噪声和条件变量怎样定义 |
| GE | 猜测熵 | 多次试验中真实候选排名的平均，需说明排名基准 |
| SR | 成功率 | 在给定数据预算下达到预设恢复目标的比例 |
| TVLA | 测试向量泄漏评估 | 一类统计检测流程，不是完整密钥恢复或绝对安全证明 |
| Masking | 掩码 | 将敏感值分为满足局部安全要求的随机份额 |
| Hiding | 隐藏 | 改变信号强度、测量可见性或对齐难度 |
| Share | 份额 | 组合起来表示敏感值的随机化分量 |
| Gadget | 受保护基础运算组件 | 必须说明安全模型、随机要求和组合条件 |
| Glitch | 组合毛刺 | 输入到达时间不一致产生的短暂逻辑变化 |
| TI | 阈值实现 | 一类考虑硬件毛刺的共享实现方法 |
| DOM | 域定向掩码 | Domain-Oriented Masking，硬件掩码设计路线之一 |
| TRNG | 真随机数发生器 | 基于物理熵源产生随机材料 |
| DRBG | 确定性随机位发生器 | 从熵种子进行密码学扩展，需保护内部状态 |
| NTT | 数论变换 | 有限环/域中的可逆线性变换，常用于多项式乘法 |
| Montgomery 域 | 一种模数表示 | 用缩放后的剩余类表示提高模运算效率，影响位模式 |
| ML-KEM | 模格密钥封装机制 | FIPS 203 所规定的算法 |
| ML-DSA | 模格数字签名算法 | FIPS 204 所规定的算法 |
| Implicit rejection | 隐式拒绝 | 解封装内部选择后备密钥而不公开拒绝标志 |
| Hedged signing | 带外部随机输入的稳健签名方式 | 不等同于已完成抗侧信道掩码 |
| Oracle | 预言机/可查询判定接口 | 理想化的输入到响应关系，真实侧信道还需构造与验证 |
| Identifiability | 可辨识性 | 不同候选是否在允许观测下产生可区分的预测 |
| KL divergence | KL 散度 | 衡量两个分布之间的差异，可解释平均似然证据 |

同一个缩写在其他领域可能有不同意义。例如 CPA 在密码安全定义中也表示选择明文攻击；本文讨论功耗时特指 Correlation Power Analysis。
