## 本批对 PQC-H001 的机制改写

原直觉是“一个模值合并多个机器整数表示”。实测（开发+留出共 546 个不同机器字）显示该数据是 **1:1**：每个规范残数只对应一个机器字，没有合并歧义。可检验的差异因此变成**同一残数两个取值**（有符号 16 位字 vs 规范残数）各自的汉明重量：在选点 13812，前者的单列在四个留出文件上把 MSE 从 219–258 降到 23–35，规范残数版本只降到 189–199，错绑系数版本 218–254。改写后的主张只覆盖“固定实现下该 16 位表示更贴合该窗口”，不含寄存器/总线机制。

## PQC-H001：数学等价不等于物理等价

- 最初直觉：模 q 的一个值可能合并多个机器整数表示和执行前态；只有具体实现允许的表示才有意义。
- 跨学科对应：粗粒化 → 数学状态合并机器微状态 → 条件波形可能仍区分微状态。
- 实现变量：整数表示、位宽、约减位置、寄存器前态、资源复用；必须由固定源码和汇编/RTL 绑定。
- 旧模型：模值或其 HW。新模型：增加真实机器字与转换历史。
- 预测：控制公开操作、数学结果和采集条件后，新变量改善独立会话中的预定预测指标。
- 最小实验：同一数据预算和划分下比较旧模型、新模型和同容量基线；加入错误历史绑定对照。条件允许时增加功能等价实现对照。
- 竞争解释：采集顺序、漂移、公开活动、模型容量或预处理泄漏。
- 否定条件：收益不出现在预定独立数据上，或错误历史同样有效；检验能力不足则记证据不足。
- 上限：统计增益不自动证明寄存器机制，更不自动等于密钥恢复。
- 所需条件：真实波形、完整标签语义、固定实现、足够的表示/历史变化。数据集是否满足尚未核查。
- **2026-11-07 更新**：数据条件已核查（固定 PQClean clean 实现、固定密钥、变密文、六字标签）。状态升为“有限支持”，适用边界见 EXP-20261107-01；W 错绑对照成立，C 等容量规范残数对照不成立。物理机制与密钥恢复仍未测试。
- 相关来源：[SRC-001 / SRC-002](SOURCE_INDEX.md)。

## PQC-H002：弱局部观测与合法运算约束

- 最初直觉：多个局部模糊观测可能通过合法运算关系形成更有约束力的联合证据。
- 跨学科对应：图模型/约束满足 → 中间变量与模运算关系 → 联合一致性排除部分解释。
- 实现变量：具体运算图、各变量的真实表示和时间绑定、局部测量证据与相关噪声。
- 旧模型：逐窗口独立判别。新模型：用准确的运算约束组合经校准的软证据。
- 预测：在同一观测预算下，正确约束改善预先选定的联合推断指标。
- 最小实验：先在可精确求解的小问题上审计推断，再比较无图、正确图与错配绑定对照；检查相关观测消融。
- 竞争解释：重复计算同一证据、训练先验错用、评估真值流入或近似推断过度自信。
- 否定条件：增益只存在于重复证据或错误先验的设置；精确审计不符时先修实现，不直接否定机制。
- 上限：后验变尖或迭代收敛不证明恢复正确；完整秘密恢复另行验证。
- 所需条件：可审计运算图、局部模型、概率校准与独立测试。
- **2026-11-07 更新**：q=7 精确有理数算例（EXP-20261107-02）通过了六条预定逻辑预测：独立噪声下正确联合优于单观测（1.6947 vs 1.8177 nats），并与同边际独立近似**逐条件精确相等**（因此“联合更好”只相对单观测成立）；相关噪声下正确联合优于独立近似与错误第二绑定；复制观测计权会同时抬高兴望 NLL 与平均最大后验，但逐条件 MAP 不变。核验方的独立实现先发现了主实现对公开 B 的边际化错误，修正后逐格一致。状态为“有限支持”，仅限评分逻辑，**不**提供任何波形噪声依赖的量级。
- 新颖性：结构化侧信道分析已有研究；具体贡献需另行检索。[SRC-003](SOURCE_INDEX.md) 是相关入口，不是此候选已获支持的证据。

## PQC-H003：重试过程的物理记忆

- 最初直觉：ML-DSA 重试更新了数学随机变量，物理资源是否仍保留跨尝试状态？
- 跨学科对应：有记忆随机过程 → 隐藏物理状态连接相邻尝试 → 当前响应可能条件依赖执行历史。
- 实现变量：连续尝试中的寄存器、存储复用、时间间隔及测量响应；均为待核查的机制候选。
- 旧模型：给定当前操作和变量后，测量近似独立。新模型：加入受实现约束的历史项。
- 预测：排除公开流程信息及漂移后，真实历史比错误绑定提供额外的目标变量信息。
- 最小实验：按完整签名执行划分，比较独立与历史模型，加入流程长度、时间漂移、跨执行错配对照；受控实现可进一步改变尝试间隔或资源清理，检查副作用。
- 竞争解释：仅识别接受/拒绝、重试次数、采样位置或漂移，未增加关于秘密的信息。
- 否定条件：增益被上述公开/环境变量完全解释，或错配历史同样有效。
- 上限：最终公开签名的挑战不能直接赋给每次被拒绝尝试；未公开的临时量和掩码必须保持未知。
- 所需条件：含连续尝试的原始测量和可靠边界，可能需要新的受控采集。
- 新颖性：利用被拒绝尝试已有论文；本候选提出的是具体物理历史假设，仍需检索与验证。[SRC-003](SOURCE_INDEX.md)。

## 2026-11-11 批次的三张卡（EXP-20261111-01/02/03）

共同前提更正：`r10 ≡ Montgomery(a0·b1)`、`r00 ≡ Montgomery(a1·b1)`，400/400 全等。**标签里没有物理前态**，六个字全是 `b1` 的确定性函数，本数据只有一个自变量。

### PQC-H006：位点身份分裂

- 变量：`HW16(partial_hi)`（乘积高半部）vs `HW16(final)`（归约后终值）。
- 机制：乘法内部期与归约后终值期是不同事件；固定点 + 单 HW 列会把两者混为一谈。
- 预测：两点交叉，`|t(hi)|/|t(final)|>3` 与反向 >3。
- 实测（确认 A699/A799）：84.45 / 635.79 与 95.53 / 7.39，四文件同号。开发更强。
- 竞争：两点可能只是同一 live range 的两端。**未排除**——需新采集的同址/同 opcode 对照。
- 上限：局部变量层，无指令身份。
- 记录：EXP-20261111-01。

### PQC-H007：`sign` 通道的漂移排除

- 变量：`sign(b1)`，控行号二次趋势与全局电平。
- 预测：控判据 `|t|>3` 且两文件同号；错位 `sign(r00)` 不显著。
- 实测：−102.78 / −108.23；错位 −2.64 / −0.79；协变量与 sign 的 r ≤0.10。有限支持。
- 上限：`sign` 与 `partial_hi` 共线 0.88，只是粗代理；不能称“符号扩展机制”。
- 记录：EXP-20261111-02。

### PQC-H008：中间量不可见（失败）

- 原主张：P_final 对 `HW16(m)`、`partial_lo/hi` 不可见（`ΔR²<0.01` 且 `|t|<2`）。
- 实测：`m` 的冷 R²=0.734 / 0.706，**远超门**；lo/hi 通过。条件于 final 后 m 增量降到 6.5e−5 / −1.5e−3，即 final 非线性吸收 m（线性 r 仅 −0.11/−0.35）。
- 结论：原表述过强，判**当前实验不支持**；留存弱版本“P_final 的方差由 final 与 m 两个近正交列联合解释”。
- 记录：EXP-20261111-03。

## 跨层八方向审计（EXP-20261111-10）

brainstorm `2026-11-11-cross-layer-directions.md` 的 B01–B08 逐条判定，不新增候选。结论：B01 有限支持（三位码 BER=0、熵 2.99 bit、546→中位 65，但无公开条件变化）；B02 混合（交互 p≈0 但与位置同现）；B03 不可测（构建内顺序固定）；B04 有限支持（乘积高字在 2/4 通道 ΔR²≈1e−3，a 恒定故无独立自由度）；B05 不可测（无掩码）；B06 混合（位移零、幅度 1.1e−2 但与 y 共线）；B07 支持位置绑定（7/12 副本强度 0.63–0.999 且极性跨 6 文件恒定，4 个在机会水平）；B08 支持（尺度群 3328 倍可被任意读出函数吸收，单锚点唯一破除，HW16 别名类均值 49.6；该对称的通用破除见 T2H-09A 的已知加法偏移，本数据两次运算都是纯乘、无偏移故不适用）。
