# EXP-20261107-01/02/03：Reference-PPM 上的表示预测、精确逻辑算例与前史资格

日期 2026-11-07（Asia/Shanghai）。类型：**公开实测数据分析**（EXP-01）、**本地合成精确枚举**（EXP-02）、**资料资格核对**（EXP-03）。候选：PQC-H001、PQC-H002、PQC-H004。

## 状态与目标

- 状态：H001 有限支持；H002 有限支持（仅建模与评分逻辑，无波形证据）；H004 条件缺失。
- 结论最高层级：固定实现、固定剖析常值、四个留出文件上的**预测改善**；不涉及物理归因，不涉及任何密钥恢复。
- 本次要区分：同一数学残数的“有符号 16 位机器字”与其“规范残数”在波形预测上是否可区分；两局部观测的联合证据在噪声相关/复制时的评分行为；前史交互设计在本数据上是否具备最低前提。

## 实验前冻结（摘要；完整冻结协议 SHA-256 `cc4eac9f9ab2ccbb1ca858ee031ea4527b8b22e187413a439af29339ef8d4fe9`，本地批次保存原文，公开审查时删节本机路径）

- 来源：SRC-001，Zenodo 10.5281/zenodo.15352482，CC BY 4.0，作者称 Cortex-M4 STM32F3 7.372 MHz、CW308 + Lecroy 610Zi 500 MS/s、PQClean C `-O3`、固定密钥变密文、每行一次解封装局部采样；FIPS 203 算法 11–12 仅作数学背景。
- 参考实现：PQClean `0586a824` 的 clean `reduce.c`/`ntt.c`（`basemul` 中 `r[1]=fqmul(a0,b1)`、`r[0]` 首次 `=fqmul(a1,b1)`）。
- 划分：开发 A99/A199，留出 A499/A599/A699/A799（四文件从未参与选点、调参、候选生成）。每个 MAT 100 行 × 50 000 原始 `uint16` 采样，无滤波/对齐/中心化/缩放。
- 模型：基线 B 是**七列嵌套基线**（截距、b1/3329、符号、HW16(b1)、HW16(b1%3329)、HW16(fqmul(a1,b1))、HW16(fqmul(a1,b1)%3329)）。B 不是“公开信息模型”：它用训练时已知的 a1 派生的 nuisance 项，所以 B 的 MSE 只作为本实验的分母，不解释为攻击者可达的基线。A = B + HW16(fqmul(a0,b1))；C = B + HW16(fqmul(a0,b1)%3329)（等容量规范残数对照）；W = B + HW16(fqmul((a0+1)%3329, b1))（错绑对照）；I 仅截距（报告用）。真正等容量的是 A/C/W 相对 B 各加一列。
- 选点：双向开发折、三模型等权，最大化 `MSE_B − (MSE_A+MSE_C)/2`，并列取最小索引；增益 ≤ 0 即终止。
- 主门：四个留出文件上 `(B−A)/B`、`(C−A)/B`、`(W−A)/B` 均 ≥ 1%。
- 预算：≤ 600 行实测、≤ 50k 开发点搜索、计算 5 min。实耗 < 2 s。

## 结论与认识变化

- 支持：在本固定实现与固定剖析常值下，`HW16(fqmul(a0,b1))` 这一有符号 16 位表示的载荷比其规范残数更能预测该选点波形（四文件 68–77% 的相对改善），且错绑系数不成立（83–95%）；容量相同的基线七列不含此信息。
- 不支持/不能判断：物理机制（数据线/寄存器写回）、指令定位、跨实现/跨器件/跨密钥/跨会话泛化、任何密钥恢复；本实验无候选密钥评分。a0/a1 为剖析常值，且在 ML-KEM 语义下属秘密系数：**公开 MAT 本身含有这两个字段**，本仓库只是不重发其原值（本地开发工件含原值，未公开）。
- 认识变化：表示差异在本数据上**不是**“一个残数对应多个机器字”的合并问题（实测 1:1），而是同一残数两个取值各自的汉明重量差异——这与原始直觉的机制描述不同，需要在模型卡中改写。
- 开发侧行配对自洽（探索性，仅开发数据、未用留出）：A99 有 2 组重复 b1，同 b1 两行在选点 13812 的 |Δy| 为 1.0 ADC 码，而不同 b1 随机行对（1000 对）平均 16.2；A199 无重复 b1。样本只有 2 对，只能说明“未见明显行错配”，不能证明配对正确。
- 保留风险：选点是在 50 000 个采样点上最大化开发增益；留出上的改善量约为 B 的 MSE 的 84–91%（分母是 B 的 MSE，不是 R² 或解释方差），远大于 1% 门。这不说明该采样点对应哪条指令；行配对只依赖作者加载器“同编号同索引”的约定。
