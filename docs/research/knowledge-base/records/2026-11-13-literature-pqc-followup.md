## 改变后续阅读的问题

1. 单攻击迹线、完美预言机查询、真实波形及正确 hints 分属不同成本；摘要数字不能直接排名。
2. t-probing 模型有效而实现仍有攻击，是模型转移条件问题，需精读噪声、份额分布和观测预算。
3. 数值精度/功能正确性/密码学安全证明与物理侧信道安全分开；相邻主题继续保留可检索入口。
4. 直接下载被拒绝不等于未读取：预取期刊摘要与引言通过 web 工具读取，直接 HTTP 返回 403；来源记录明确无本地原始响应哈希。其他成功缓存来源保留哈希。
5. 一篇 Dilithium 组件论文的 Crossref 摘要缺开头，卡片明确记录该限制，未补猜缺失内容。
