## 改变后续判断的证据

BFId 不支持把“不同视角中可识别”扩大为任意跨视角迁移；HW-Spy 的词级/句级数值仍是校正后的字符比例。Swallow 的五样本成本只涉及微调，防护流量为模拟生成，其训练开销文字与所列秒数存在方向矛盾。DP 访问的分区级恢复不等于精确个体数据恢复，MegaBlocks 的复杂度依赖非对称字/块设置。

入口 README 的几处累计数字滞后于已有 JSONL：卡片标题已为 450，但范围、阅读层级及引用摘要仍使用更早统计。本批按实际记录统一更正，并为这些入口统计添加一致性检查；历史批次记录的当时数字继续保留。
