# 计算轨迹的防护编码 任务安全与物理可辨识性

日期：2026-11-13。供用户安排其他研究者验证。这里进一步改变三个研究对象：把防护对象从单个值推进到整段轨迹，把泄漏目标从完整密钥推进到明确任务，把模型评价从拟合能力推进到哪些解释能够被区分。三项均为待验证提案，手工推导待独立核对。

这批深化已有 BOLD 种子，不把重新组织问题计作新机制；种子总数仍为 40。它们分别连接 BOLD-08/20/30/38、BOLD-14/18/24、BOLD-19/22/37。研究增量必须落在新的条件、可检查的构造或可区别的预测上。

## 六个开放问题

| 构思 | 挑战什么前提 | 下一步可能得到什么 |
|---|---|---|
| 编码整段计算轨迹 | 每个时刻的份额安全，足以代表整次执行安全 | 面向指定时空观测族的编码与调度条件 |
| 泄漏一个任务所需的结构 | 系数恢复率或整密钥排名足以衡量泄漏价值 | 明确任务下的观测与计算成本曲线 |
| 给物理解释划出可辨识边界 | 波形预测准确，就能认定内部机制 | 不可辨识证明，以及消除歧义所需的独立锚点 |
| 自动寻找功能等价实现之间的最大泄漏分歧 | 编译和布局主要是性能选择 | 一对有功能等价依据、却使现有泄漏模型失效的最小实现 |
| 把防护策略的动作也列入泄漏 | 防护只需压低被监测的信号 | 防护触发、刷新、切换策略与剩余波形的完整观察模型 |

后三项保留为长期候选，分别接续 BOLD-13/19、09/39、22/原型 M。它们目前需要固定编译产物、可观测的防护策略，或跨内核且有干预记录的数据。本批只详细展开前三项。

## 让防护编码整段计算轨迹

**大胆设想：设计一种正确计算的表示方式，使秘密改变时，允许观察者看到的整段物理过程仍不能区分；空间上的份额分离与时间上的状态刷新一起成为设计变量。**

跨学科对应：编码理论中的随机编码与可观察投影 → 含份额、寄存器前态、刷新和调度的执行轨迹 → 单点隐藏不保证轨迹投影隐藏 → 改变编码和资源复用后，预先指定的跨时刻关系应改变。

最先需要修正的是“观察一个点”的含义。一个外部采样值可能汇集多根线、多个转移或测量链的历史响应。因此，要先限定观察族，包括空间覆盖、时间窗口、允许的混合函数、带宽、调用次数以及组合预算，再讨论编码的安全性。单点采样数不能直接充当逻辑探针数。

### 一个只说明时间关系的手工例子

对两个时刻 t=0,1，设秘密状态为 s_t，独立均匀掩码为 r_t，布尔份额为

\[
a_t=r_t,\qquad b_t=s_t\oplus r_t.
\]

每一份额的单独分布都与对应秘密无关。若理想观察者得到两条单比特转移

\[
u=a_0\oplus a_1,\qquad v=b_0\oplus b_1,
\]

则每一条转移单独仍是均匀的，两条联合却满足

\[
u\oplus v=s_0\oplus s_1.
\]

这里展示的是**两条观察之间的关系**，不是对一阶掩码安全性的反例。若 s_0=s_1，右侧恒为零，也不泄漏固定秘密；若 s_0 是公开状态，关系才可能成为关于 s_1 的信息。它更没有证明现实功耗能准确读取 u、v。若要主张一次模拟读出已经合并了两者，必须另外给出实际混合路径与测量预测。

这个例子提示：原有状态模型即使正确描述了全部单变量分布，也不能独自推出跨时刻联合分布。编码对象可以包括允许的状态转移和资源复用，而不只包括每个时刻的静态份额。

### 需要构造什么

可先在很小的内核上定义轨迹分布 E_s，以及有限的物理观察族 M。对具有相同允许公开信息的测试输入，检查各观察映射作用于 E_s 后的分布。这里可以做精确的有限模型分析；扩展到完整公钥算法时，应使用明确的安全游戏或可模拟泄漏定义，不能把固定公钥条件下的秘密熵直接当作计算安全性。

候选构造同时选择份额编码、刷新位置、存储布局和调度。它必须保留正确功能，并把随机数生成、初始化、算术与布尔表示转换、输出和清理纳入边界。任何被当成可信原语的阶段都要写明假设；不能把最难的操作藏在未建模的“安全刷新”里。

这并非从零发明有状态掩码。[Private Circuits](https://people.eecs.berkeley.edu/~daw/papers/privcirc-crypto03.pdf)已明确研究有状态计算及探针预算；[robust probing 工作](https://eprint.iacr.org/2017/711)已把物理缺陷与可组合性一起建模。候选增量是针对**有实现依据的时间窗口和物理混合观察族**，求出可构造的轨迹约束和资源代价，而不是把既有掩码换个名称。

### PQC 落点和最小鉴别

可选固定 ML-KEM/ML-DSA 实现中的小段模运算，或消息处理附近的算术与布尔表示转换。第一轮只要求验证者提交实际机器语义、资源映射、旧防护的适用观察族和一个超出它的具体观察，暂不要求实现整套新防护。

若存在合格载体，再比较两份功能相同的实现：尽量匹配逻辑阶数、随机量、运算数量和测量预算，改变预测会形成危险联合关系的资源复用或刷新位置。**事前预测应指向指定转移窗口的联合差异，且允许单点分布几乎不变。**对照包括错误时间配对、仅增加普通刷新、等成本既有防护和完整执行的边界观察。

如果现有 robust probing 或有状态防护已经覆盖该观察与构造，就应归入已有方法；如果收益只是增加随机数或延迟，不能归因于新编码；如果理想模型成立而真实路径不可观察，则记录实现条件缺失。长期成果可以是一种编码，也可以是一个“在给定资源和观察族下无法实现”的下界。

## 研究泄漏能否完成任务而不是先要求恢复完整密钥

**大胆设想：一个波形表示可能始终不够还原私钥，却足够解决某一类秘密相关任务。研究者应先问任务需要哪些关系，再问测量能否提供它们。**

跨学科对应：充分统计量与线性代数的商空间 → 波形保留的秘密函数以及指定任务 → 没有被观测到的秘密方向可能与该任务无关 → 在完整秘密仍有歧义时，任务表现已经改善。

### 一个有限域中的手工见证

设 s 在 F_q^n 中均匀取值，理想观察为 w=Cs，任务是计算 d·s。若 d 位于 C 的行空间，存在 λ 使 d=λC，于是

\[
d\cdot s=\lambda w.
\]

即使 rank(C)<n，完整 s 仍有 q^{n-rank(C)} 个候选，这个任务也可被精确完成。相反，若 d 不在行空间，则存在 v∈ker(C) 使 d·v≠0；s 与 s+v 给出相同观察，却给出不同任务值。

最小例子是观察 s_1+s_2：它没有单独确定 s_1 或 s_2，却已经完成“求两者之和”的任务。这个线性代数事实不是新攻击，也没有映射到实际 PQC 私钥。真实秘密分布、公开关系、模约减和噪声都会改变简单的行空间判据。

### 在 PQC 中什么才算有意义

首先把三类目标分开：预测某个内部量、改善一个协议安全游戏中的成功率、在一类输入上复现秘密相关功能。只有第一项成立时，不能写成已经破坏协议；第三项也必须限定输入族、泛化范围和总成本。

对于格实现，可以问一个真实可观测的聚合关系是否足够预测指定计算中的内积区间、舍入结果或其他明确任务，而不先恢复每个系数。对于签名实现，可以问学到的关系是否只识别内部流程，还是对预先定义的安全目标有增量。具体采用哪个目标，要由验证者绑定算法版本、公开转录和允许接口，不能用随意定义的隐藏标签冒充密码学目标。

公开信息基线尤其关键。有些“秘密函数”其实已能从公钥或公开输出高效计算；另一些在信息论上由公钥决定，却在计算上难求。因此要比较**相同公开信息和规定计算预算下**，有无物理观察的任务能力，不能只看互信息或候选集大小。

[LWE with Side Information](https://eprint.iacr.org/2020/292)已经系统研究提示与格求解成本，说明“部分信息也有价值”本身不是新点。这里的候选增量是把最终任务、观测表示和总计算成本一起定义，并允许得到一个比完整秘密更粗的、足以完成该任务的表示。

### 波形预测和最小鉴别

如果聚合关系确实有独立价值，那么在限定测量预算下，应能出现“逐系数预测较弱，任务预测较强”的分离。破坏与任务有关的真实跨运算配对，应损害任务表现；打乱无关的秘密方向则不应产生相同损害。逐系数指标不包含这种任务结构，无法单独判断它。

首轮由验证者提交一个有限问题：任务 T、全部公开信息 P、允许的观测 W、计算预算，以及一个说明 W 是否足以完成 T 的证明或反例。进入实际数据后，比较公开信息基线、逐系数推断后执行任务、直接任务模型和同容量通用模型。必须按完整执行和独立条件留出，并报告采集、剖析、校准与计算成本。

若任务可由公开信息同预算完成，所谓增量消失；若提升来自标签或同次执行泄漏到测试集，应否定评估；若直接模型只是在完成一个更容易的标签分类，则结果只支持该诊断任务。若推断保留的歧义刚好跨越任务边界，有限模型反例也足以否定当前方案。

长期成果可以是一组按任务划分的泄漏评价方法：同样的系数恢复率，为什么对不同任务意味着不同风险；某些关系又为何即使可测，也不足以造成预期的安全损失。

## 证明哪些物理解释无法仅靠波形区分

**大胆设想：研究系统应能够回答“这些数据永远不能证明你说的机制”，并给出最少还缺什么观测或干预。不可辨识结论本身可以是研究成果。**

跨学科对应：系统辨识与逆问题中的等价类 → 隐藏物理状态、读出映射及允许干预 → 不同参数描述可能具有完全相同的外部响应 → 继续增加同类数据仍不能固定内部解释，独立物理锚点才可能缩小歧义。

### 一个说明坐标歧义的手工例子

考虑理想线性状态空间模型

\[
z_{t+1}=Az_t+Bu_t,\qquad y_t=Cz_t.
\]

对任意可逆矩阵 T，令 z'_t=Tz_t，同时取

\[
A'=TAT^{-1},\quad B'=TB,\quad C'=CT^{-1},\quad z'_0=Tz_0.
\]

两种表示对同一输入序列给出完全相同的 y。即使数据无限多，也不能仅凭输入输出，把某个潜在维度唯一命名为“供电状态”或“寄存器残留”。

**换坐标本身不是两种物理机制。**如果把干预也一致地换坐标，等价性仍然存在。只有来自独立知识的物理约束，例如某个已知端口的作用、局部读出映射或组件参数变化，才可能排除错误的物理参数对应。不能人为让两个坐标系统采用不一致的干预，然后宣称发现了因果差异。

[双线性逆问题的可辨识性研究](https://arxiv.org/abs/1501.06120)已经按变换群讨论唯一性。上面的状态空间推导只是基础见证。拟研究的增量是：把具体 PQC 实现的离散运算约束、资源复用和可获得干预加入后，哪些等价仍然保留，哪些有安全意义的结论在所有等价模型下都成立。

### 从漂亮解释走向可反驳解释

应区分三种情况：只是同一模型的坐标变化；物理意义不同但在已有测量条件下等价的模型；以及能被允许干预区分的竞争机制。前一种无需强行选出“正确坐标”，后一种才有理由安排鉴别实验。

以 PQC 重复算术阶段为入口，可以让一个模型使用“与当前运算有关的电流响应”，另一个使用“前一阶段经测量链拖尾后的响应”。两者可能在固定流程中拟合同样好，但在有资格的顺序、间隔或读出干预下提出不同预测。修改操作顺序时必须保留算法依赖；修改测量链时还要核查是否改变了器件本身。

新模型的产物应是**哪些结论对整个等价类成立，以及哪项干预会使真正不同的解释分叉**。一个预测准确的潜在变量模型只能证明预测能力；它不能单凭注意力热图、潜变量分组或相关性证明物理部件身份。

### 最小鉴别和否定条件

先交两个有明确物理语义的模型、允许观察集合和等价关系。验证者独立核对：它们是否真的对全部允许输入等价，还是只对有限数据恰好拟合一致。如果是结构性等价，报告不可辨识范围；如果只是当前激励不足，提出能够提供新约束的最小干预。

在揭示干预数据前，固定各模型对指定波形窗口、恢复曲线或联合统计的预测。独立校准和组件知识可以作为锚点，但必须说明来源。若干预不能在物理上单独定位、两种预测始终相同、或者差异完全来自重新拟合的自由参数，就没有完成机制鉴别。

它明显偏离现有离线分类主线，值得保留一次小规模理论诊断。长期可以建立一份“仅凭哪些数据不能声称什么”的可辨识性清单，以及一套按现存歧义设计下一次测量的方法。

## 给验证者的首轮任务

| 对口人员 | 第一份交付 | 第一轮可以接受的否定结果 |
|---|---|---|
| 掩码理论与 RTL | 固定小内核、真实观察族、轨迹约束或不可能性见证 | 已有防护已覆盖；观察族没有物理载体；资源预算不可能满足 |
| 密码学与推断算法 | 明确任务、安全游戏或诊断层级、公开基线与可用信息关系 | 所谓任务已公开可算；剩余歧义仍跨越任务边界；无成本优势 |
| 系统辨识与电路测量 | 两个模型、等价范围、独立锚点及分叉预测 | 只是换坐标；允许条件下根本不可辨识；干预无法定位 |

大模型可负责列出变换、提出竞争解释和压缩反例；验证者负责独立重建推导、绑定实现和选择检验方法。首轮不要求三条都跑实验。任务安全的有限模型适合较快检查；轨迹编码需要理论与实现配合；可辨识性方向保留独立探索机会。这个顺序依据问题边界，不是成功率排名。

回传时分别记录数学推导、实现映射、实测预测和协议意义。任何一项通过，都不自动使另外三项通过。
