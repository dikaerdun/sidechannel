## B01：把粗粒度观测看作编码

**大胆问题：**即使每次只能读出很少的位，多个公开条件下的响应能否共同成为区分同一秘密的编码？

- 跨学科对应：量化测量/编码理论 → 公开条件 u 下的二值响应 b=g(s,u) → 多个 u 给同一未知 s 不同切分 → 联合码字具有可检验的区分能力。
- 新对象：候选之间的等价类、码字距离、误判混淆与后验覆盖，而非每次恢复一个精确幅度。
- 旧模型遗漏：只按单次幅度误差评估观测，未利用跨公开条件的共同秘密约束。
- 预测：保持单次分类器和数据预算不变，在实际合法的公开条件变化下，联合响应比机械重复同一切分更能区分候选。
- 首个交付：一个完全指定的小型模运算例子的码字碰撞表、噪声敏感性分析和信息量界限。先证明可辨识，再谈波形。
- 最有力反例：不同公开条件仍产生同一等价类；某些秘密永远碰撞；bit 错误相关或状态绑定不对，使联合置信度虚高。
- PQC 落点：NTT/模乘的离散结果特征、解码或比较的条件观测。但模回绕不能直接套用实数域一比特压缩感知的结论。
- 数据限制：当前固定剖析常值、单自变量数据只能检查局部读数；不能据它宣称未知秘密下跨条件编码已成立。
- 新颖性：少量泄漏结合代数约束不是新概念。需要论证的增量是具体实现、具体观测映射下的可辨识条件和误码鲁棒性。

## B02：把秘密视为测量系统的一个参数

**大胆问题：**秘密是否改变了电路对公开活动的响应，而不仅改变自身计算的电流？

- 跨学科对应：系统辨识/响应函数 → 持有状态 s 与公开活动 u → 响应 F(u,s) 随 s 改变 → 相同 u 在不同 s 下呈现不同增益、相位或衰减。
- 概念模型：y=F(u,s)+噪声。状态固定的短区间可尝试 y=h_s*u+噪声，但不能预设真实电路线性。
- 中间变量：状态相关等效阻抗、泄漏电导、负载与供电反馈；是否可测必须由实现确认。
- 预测：目标寄存器本身不发生切换时，公开操作窗口仍出现与持有状态相关的响应差异。
- 最小鉴别：在受控研究实现中交叉改变持有状态与公开活动，比较纯加性偏置模型和交互响应模型。控制装载残响、温度、时间漂移和仪器增益。
- 反例：差异只是静态偏置加上公开活动，或只来自先前装载的线性尾波；未出现状态×公开活动交互。
- PQC 落点：秘密多项式保持期间的公开搬运、固定调度活动或统一加速器其他运算。
- 所需条件：可控制保持状态和公开活动、明确地址与时序、新测量。旧标签没有这些操控，不能代替它。
- 与已有研究关系：静态功耗和主动阻抗探测已有实证。本文进一步提出“正常公开活动可否作为自然探针”的假设；主动注入阻抗实验不能证明被动场景已可行。

## B03：把运算顺序作为泄漏变量

**大胆问题：**两个功能上可交换的独立运算，在共享资源上是否留下可区分的执行路径？

- 跨学科对应：有记忆动力系统/路径依赖 → 资源前态与操作顺序 → 相同运算集合可能有不同路径响应。
- 中间变量：寄存器前态、总线残态、供电恢复、操作间隔。
- 预测：在普通 HW/HD 与线性测量拖尾之外，仍有随 AB/BA 顺序改变、且与目标状态相关的残差。
- 最小鉴别：只交换没有数据依赖的操作，保持功能输出及工作量一致，检查编译结果；匹配前态和时间间隔，先拟合可解释的线性叠加，再检验额外项。
- 反例：所有差异都能由操作位置、普通 HD、缓存或线性卷积解释。AB 与 BA 的原始波形不同本身不支持新机制。
- PQC 落点：独立蝶形、系数乘法与写回的合法调度。
- 与历史关系：是 PQC-H004 的干预式扩展，不能用旧数据缺失的前史字段进行拟合冒充验证。可测的非线性路径项不自动证明某个具体电路原因。

## B04：研究模约减“丢掉”的整数轨迹

**大胆问题：**数学只保留余数，电路处理过的商、进位、借位和修正轨迹是否形成额外约束？

- 跨学科对应：从商空间提升到整数表示 → t=qk+r 中的 k 与范围约束 → 相同余数可能经历不同整数路径 → 波形能否区分路径。
- 新变量：约减相关整数、截断高位、修正与进位链。这个等式只是概念；Montgomery 的 R、符号、溢出和修正必须按实际实现重写。
- 预测：控制结果表示和普通位活动后，路径变量仍有额外预测力；跨运算的整数一致性可提高联合约束质量。
- 最小鉴别：先在合法输入范围的小算术核中构造相同结果、不同整数路径的受控组，独立核对语义，再检查路径特征及负对照。
- 反例：所用实现/输入范围中路径变量只是已有标签的重编码；或低位/高位 HW 已完全解释增益。
- PQC 落点：约减、压缩、解压与舍入边界。线性代数中的模等价不自动保留机器表示。
- 所需条件：准确实现、足够输入自由度与新测量；当前单自变量标签不能证明有独立路径自由度。

## B05：供电系统能否将分离的掩码份额混合？

**大胆问题：**数字逻辑里的份额分离，是否被共享模拟供电响应部分破坏？

- 跨学科对应：非线性混频 → 两个份额的局部泄漏与供电反馈 → 测量出现联合项 → 同步方式影响可利用关系。
- 候选观测模型含 l(a)、l(b) 和交互 l(a)l(b)。纯线性叠加本身不能证明存在这种物理乘积项。
- 预测：在受控硬件中改变份额相对时序或供电隔离，联合泄漏随交互条件变化；变化超出单份额活动和线性测量链预测。
- 最小鉴别：同时校验功能与掩码语义，比较相位安排或供电耦合条件；排除仪器削顶和外部放大器非线性。
- 反例：效果仅由分析软件做高阶组合产生，或源于测量仪器失真；不能称作芯片内物理混合。
- PQC 落点：并行掩码 NTT、份额写回、算术/布尔转换。
- 所需条件：受控掩码实现、布局/电源信息与模拟测量。不能用无掩码公开包作验证。
- 新颖性边界：掩码份额通过供电耦合已有研究；潜在贡献须具体到 PQC 调度、转换与测量条件，而非“供电会耦合”这一泛称。

## B06：把对齐和校准参数保留为观测

**大胆问题：**数据预处理消掉的微小时移、幅度因子和恢复时间，有多少属于目标状态而非环境？

- 跨学科对应：潜变量与信息保留 → 对齐位移/尺度/尾波参数 → 这些参数可能是秘密作用的中介 → 丢弃它们可能丢失证据。
- 新对象：联合记录“校正后的波形 + 校正参数 + 公开环境变量”。
- 预测：在独立会话、固定预处理协议下，参数对目标仍有条件预测价值；改用公开参考对齐后能够判断是否只是算法选择偏差。
- 最小鉴别：在开发集冻结处理方法，比较波形、参数和两者联合；做错配标签、会话和公开输入对照。
- 反例：所有增益来自会话身份、样本顺序或用标签选对齐窗口；这些参数并未提供新的秘密信息。
- 所需条件：保留原始波形与采集元数据。当前 H015 的基线差分负结果不能直接否定全部参数，但也不能换名重跑同一差分方案。
- 上限：确定性预处理不能增加原始数据总信息；这里检验的是模型使用信息的能力，而非制造信息。

## B07：让编译器和资源映射成为因果实验工具

**大胆问题：**能否通过功能等价实现的系统变换，观察泄漏跟随“值”“指令”“位置”还是“历史”移动？

- 跨学科对应：因果干预/等变性 → 改变调度、寄存器分配、表示或地址 → 多个机制对泄漏移动给出不同预测。
- 新对象：跨实现的变化规律，而非单实现拟合分数。
- 预测：若假设为表示驱动，表示变而其他尽量固定时应有预定变化；若为位置/复用驱动，响应应跟随相应映射。
- 最小鉴别：先选择可单独改变的一个实现因素，核对二进制、功能、时序与工作量；逐项记录伴随变化，避免将优化级别整体变化当单一干预。
- 反例：无法控制伴随变化，或观察规律与多个竞争机制同样相容。
- PQC 落点：clean/ASM、in-place/out-of-place NTT、不同份额分配与写回组织。
- 所需条件：可重编译固件与新采集。只有原始波形而没有 ELF 时应保留该方向，不能伪造指令身份。

## B08：先研究“秘密是否可辨识”

**大胆问题：**泄漏模型越灵活，会不会越容易让错误秘密也解释同一批波形？

- 跨学科对应：逆问题可辨识性/对称性 → 秘密 s 与未知读出参数 θ → 不同 (s,θ) 可能诱导同一观测分布 → 拟合好仍不能区分秘密。
- 一个确切但非 PQC 攻击的玩具例子：若 z=p XOR k，y=f(z)，且 f 完全未知且任意，则对任意 k'，定义 f'(z)=f(z XOR k XOR k')，即可产生完全相同的 y。无限灵活的读出模型无法从这些观测识别 k。
- PQC 问题：具体模运算图中是否存在可被读出函数吸收的置换、符号或尺度变换？哪些物理共享约束可以破除它们？
- 预测：去掉某个真正必要的约束后，多个候选重新等价；加入正确而可独立核查的约束后，等价类才缩小。
- 首个交付：小问题上的等价类证明或反例，区分无限数据也不可辨识与有限噪声导致暂时困难。
- 最有力反例：新增约束仅通过真值选取，或只压缩了模型容量而没有区分目标秘密；结果可能是人为偏好。
- 实验上限：留出波形预测成功只说明统计泛化；仍需独立验证秘密与表示之间的绑定。
- 与大模型的关系：大模型可提出和审查约束，但不能通过生成复杂解释替代可辨识性检查。

## 原始研究背景及实际阅读范围

- [静态功耗泄漏，CHES 2014](https://eprint.iacr.org/2014/025)：本次读取摘要与元数据。其意义是计算切换之外的状态相关功耗已有实证，不证明本文 B02 的自然探针假设。
- [LeakyOhm](https://eprint.iacr.org/2023/693)：本次读取摘要与元数据。研究主动阻抗测量中的状态相关响应；不得将其主动激励条件隐去后当作被动功耗结论。
- [Single-Trace Side-Channel Attacks on Masked Lattice-Based Encryption，CHES 2017](https://eprint.iacr.org/2017/594)：本次读取摘要与元数据。局部观测结合 NTT 关系和格约束已有研究，B01/B04 的新颖性不能仅靠“使用结构”。
- [Rejected Signatures' Challenges Pose New Challenges，TCHES 2025](https://eprint.iacr.org/2025/214)：本次读取摘要与元数据。拒绝尝试及整数约束已有研究，不能将此母题重新宣布为新发现。
- [Advanced hardware security methods for modern integrated circuits](https://urresearch.rochester.edu/institutionalPublicationPublicView.action?institutionalItemId=38076)：本次只看到作者学位论文公开元数据检索结果，其中涉及份额和供电耦合。未阅读全文；B05 验证者需精读原始实验条件。
