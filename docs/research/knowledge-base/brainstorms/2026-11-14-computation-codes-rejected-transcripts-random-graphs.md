# 计算冗余 拒绝轨迹与随机计算图的侧信道研究

日期：2026-11-14。供用户安排其他研究者验证。三项提案把研究对象推进到完整计算的约束、算法舍弃的执行以及每次运行的实际依赖图。它们深化已有方向，不增加 BOLD 种子计数；均未获得本项目的新实验支持。

大胆目标是：**研究正确计算怎样帮助观察者纠正测量错误，以及怎样设计一种正确计算，让这种帮助受到明确限制。**

## 六个可以继续追问的问题

| 问题 | 要新增的对象 | 可能的成果 |
|---|---|---|
| 完整执行是否像纠错码一样补出局部看不清的信息 | 合法执行集合与真实观测通道 | 能预测未见实现的整体可辨识模型 |
| 被算法丢弃的候选去了哪里 | 拒绝前后及重试之间的完整物理转录 | 覆盖拒绝路径的泄漏契约 |
| 能否随机化计算关系本身 | 功能等价但内部依赖不同的图族 | 对数据与执行路线共同建模的防护 |
| 能否找出最少几个观察就足以固定全局关系 | 带物理观测条件的约束割集 | 小型证明或不能由静态图推出的反例 |
| 更高的算法维度是否反而增加可用冗余 | 自由度 约束数与观测相关性的共同缩放 | 有适用范围的规模规律 |
| 能否自动选择最不利的功能等价实现进行评估 | 实现变换与模型反例的联合搜索 | 附机器语义和物理预测的反例库 |

后三项暂存，不展开验证计划。前两项联系密码推断与实际执行，第三项保留一次偏离当前分类主线的理论诊断机会。

## A 把完整计算看作带噪声的受约束编码

**直觉：一个中间量可能读不准，但它在后续计算中的多个变形，可能共同把它确定下来。高维执行中增加的不是同样多的独立未知量。**

跨学科对应：纠错编码的合法码字集合 → 由真实程序产生的合法中间轨迹 → 各处的弱观察可借助计算关系互相约束 → 改变约束与物理读出的对应，应改变全局推断，即使单窗口分类成绩相近。

把固定公开输入记为 P，秘密测试输入为 S，合法随机性为 R，实现为 G。其离散轨迹写成 Z=C_G(S,P,R)。对每个 S，可能的轨迹是一整个集合，不能把掩码后的执行当作唯一确定码字。测量还经过物理状态 Q 和读出 H：Y=H(Z,Q)+ε。

这里的“编码”不要求轨迹构成线性码，也不保证秘密可恢复。关键问题是：不同秘密对应的轨迹集合，在真实观察之后还剩多少可区分性？哪些重复关系只重复同一份噪声，哪些确实增加约束？不能直接把每个窗口的似然相乘；共用电源、同一份掩码和仪器响应都可能破坏条件独立性。

SASCA 已经把泄漏与算法关系联合起来，ExSASCA 则研究精确推断；将信念传播融入 Kyber iNTT 多任务学习也已有直接工作。因此，“用图推断”和“让神经网络懂 NTT”都不能作为本提案的新颖性主张。[ExSASCA 官方摘要](https://proceedings.mlr.press/v235/wedenig24a.html)、[Kyber iNTT 联合学习摘要](https://eprint.iacr.org/2025/1917)

更强的研究目标是做一套**能预测实现变换后整体可辨识性如何变化的分析方法**。输入机器码或 RTL、真实资源映射与校准过的观测模型，输出：哪些计算关系被物理读出重复编码，哪些关系仍有别名，以及哪些实现变换会改变这种结构。它应在看到新实现的测试结果以前给出预测。

PQC 的入口可以是两个 NTT 层、重复约减或表示转换的小片段。必须包含实际整数宽度、模回绕、刷新随机量和资源前态；算法级等式本身不说明某条硬件连线可观测。

**波形预测：**两份正确实现即使具有相近的单窗口泄漏，跨窗口约束的一致性及秘密候选的重叠仍可能不同。若差异来自共享资源的历史项，改变复用映射后，变化应跟随该项；若仅来自算法约束，纯资源变换不应产生模型未包含的变化。

**最小鉴别：**验证者先给一个有限算术内核、两种正确实现、完整随机性和一个明确观测通道，在小模型中用精确推断确定基准，再比较简化图模型。随后才判断实测数据是否具备对应条件。错配跨窗口关系可作诊断，但它不是合法实现干预，不能单凭错配结果证明物理机制。

**什么会否定当前版本：**收益完全由更强的局部分类器解释；所谓独立约束其实来自重复使用同一测量；新增物理状态不能预测留出实现；或者已有 SASCA 模型已经给出同样预测。某个推断器失败只说明该推断器失败，不能据此宣称信息已消失。

第一份有价值的产物可以很小：一对局部指标相近、整体可辨识性不同的正确实现，以及一个能提前解释差异的模型。它承接 BOLD-06/14/37 和轨迹编码方向。

## B 为拒绝采样定义完整物理转录的保护目标

**直觉：算法通过丢弃候选来修正输出分布，但器件已经计算过这些候选。数学上的舍弃，未必等于观察者没有见过。**

跨学科对应：选择偏差与停止过程 → 被接受的样本 被拒绝的样本和停止时刻 → 输出分布相同不约束被舍弃路径的观察分布 → 接受结果与重试次数都相同的条件下，拒绝窗口仍可能有区别。

一个手工小例子只说明逻辑：秘密位 S∈{0,1}，每次独立取 Y 均匀分布于 {0,1,2,3}，令 Z=Y+S，仅当 Z∈{1,2} 时接受，否则重试。两个秘密下接受概率都为 1/2，最终输出都均匀分布于 {1,2}，重试次数分布也相同。但拒绝时的 Z 集合分别为 {0,3} 和 {3,4}。如果某种观察能区分 0 与 4，就可能得到输出和次数没有提供的信息。这是待独立核对的有限示例，不是 ML-DSA 的分布证明或实际功耗模型。

针对 Dilithium 拒绝候选的侧信道攻击已有直接先例，相关作者摘要报告了从拒绝挑战与响应提取约束的研究。因此，不能把“拒绝轨迹可能泄漏”再作为新发现。[Rejected Signatures’ Challenges 原始摘要及版本说明](https://eprint.iacr.org/2025/214)

更大胆的目标是反向设计：**在保持规定输出分布和正确性的前提下，让可见的拒绝过程也满足明确泄漏边界。**保护对象应包括候选生成、判断、拒绝后的清理、下一次采样和随机量补给，而不止最终接受分支。固定运行时长只能遮蔽其中一个维度，不能自动遮蔽被丢弃的值。

可先把一次调用的允许观察写成 T=(各轮波形、可见轮数、轮间间隔、清理与补给活动)。定义模拟器可使用的公开信息、最终输出及信息披露时刻，要求它解释完整 T 的联合分布。完整公钥方案应采用有计算预算的区分游戏；小例子中的信息论独立不能直接外推到实际 ML-DSA。

**波形预测：**若遗漏来自拒绝候选的驻留或转移，相关差异应出现在指定候选处理及清理窗口；仅补齐总时长可能保留差异。若来自随机数队列或恢复状态，则影响可能进入下一轮，此时“每轮分别安全”不足以描述联合观察。

**最小鉴别：**先由验证者独立检查小例子，再为一个固定版本的签名实现给出完整拒绝流程与观察边界。提出两种功能正确的候选保护，写出它们对同轮和跨轮观察的不同预测。以完整调用为单位记录和划分数据，避免只截取已知失败轮而隐含使用观察者得不到的标签。

**什么会否定当前版本：**所选实现的全转录已被已有证明覆盖；候选观察在边际化合法随机性后没有增量；变化仅来自更长观察时间；或所谓防护改变了要求的输出分布。阴性观测应约束具体通道与检测能力，不应被写成所有拒绝路径均安全。

长期产物可以是一个受限的全转录模拟器、一种保护构造，或给定资源预算下的不可行见证。它把 BOLD-10/16/20/30/33 推进到一个具体的算法生命周期。

## C 让计算图也成为每次执行的随机变量

**直觉：常见评估会把实现依赖图交给分析者，再研究各节点泄漏。能否生成一族正确实现，每次选择不同的内部关系，使观察者必须联合解释数值和计算路线？**

跨学科对应：潜变量模型与随机程序变换 → 每次执行的内部计算图 G → 对 G 的合法边际化可能改变秘密的可辨识性 → 揭示真实路线与隐藏路线时，完整观察的推断结果应呈现可解释差异。

公开算法、变换规则和图族都交给分析者；仅把每次运行使用的新鲜随机选择列为内部状态。目标不是依靠隐藏源代码。可以允许功能等价的代数分解、表示路径及资源绑定，而不只把互不依赖的操作重新排序。必须逐个证明机器语义中的正确性，包含溢出、模约减和异常路径。

代码多态已有侧信道防护先例。PolEn 结合运行时代码生成与代码加密，其作者摘要描述的是模拟器和工具链原型；这并不证明这里提出的图随机化具有实际芯片上的安全收益。[PolEn 作者预印本摘要](https://arxiv.org/abs/2310.07327)

真正待解决的问题是：**哪些图变换在完整观察后仍留下关于秘密的有效歧义，哪些只是产生很多容易识别的路线？**图族数量很大、路线识别准确率很低，都不能单独证明秘密安全。不同路线可能保留同一个秘密不变量；路线和秘密也可能在联合推断中一起被识别。

小模型中应从联合分布 p(S,G,R,T|P) 出发，正确边际化 G、R，再判断指定秘密任务。不能先用真值对齐路线、删除路由开销，然后声称测试了未知路线。随机选择的生成、路由与转换自身也属于 T。

**波形预测：**如果收益确实来自路线歧义，提供真实路线这一诊断信息，应在其他条件相同的情况下恢复一部分原先损失的推断能力；若不恢复，就需要另找解释。反过来，如果在原始波形中能无代价辨认路线，或存在无需辨认路线即可读取的秘密关系，这种保护的当前版本就失效。

**最小鉴别：**验证者先提交一个极小模运算、少量功能等价图及固定观察模型。用可精确分析的规模比较：已知路线、未知路线、从完整观察联合推断路线与秘密。随后与同总成本的普通掩码、打乱和延时比较；路由、刷新及新增活动不能从成本账本中删掉。

**什么会否定当前版本：**正确边际化后秘密后验并未改变；收益只是推断算法没有收敛；所有图共享同一可观测秘密关系；或路线选择泄漏抵消收益。一个有界模型中的失败也有价值，它可以说明某类随机变换无论有多少种，都不能改变既定观察下的安全性。

这项承接 BOLD-05/17/32 与动态表示方向，增加的是对实际图结构的联合推断和构造目标。保留一次小规模理论诊断，不要求先实现大型随机编译器。

## 交给验证者的首轮任务

| 方向 | 第一份交付 | 首轮可以接受的结果 |
|---|---|---|
| A 计算约束与物理读出 | 两种正确实现 完整随机性 观测模型及留出预测 | 找到整体差异；或证明现有模型已解释 |
| B 被拒绝执行的完整保护 | 有限示例核对 实际拒绝流程 允许观察与两种保护预测 | 明确遗漏；或得到已有保证及适用边界 |
| C 随机计算图 | 图族正确性 已知和未知路线的精确小模型比较 | 找到有效歧义；或给出不变量反例 |

验证者回传初始主张、最强反例、实际实现映射、观察者能力、旧模型预测、新模型预测、证据和剩余缺口。数学成立、物理可观察、秘密相关、密码任务有收益四件事分别判定。

大模型适合提出图变换和竞争机制、寻找更小的反例、组织约束；正确性证明、分布核对和测量证据由验证者独立完成。每项先提交一个能够失败的具体主张，再决定实验预算。

## 构思变化和来源范围

最初三个直觉是整体纠错、被抛弃的候选和随机路线。定位性阅读确认前两个已有直接先例，代码多态也有现成研究。因此本批增量改为实现变化的预测、完整拒绝转录的保护目标，以及图与秘密的联合可辨识性；未把它们计成新机制，已有 40 条种子的计数保持不变。

本轮阅读 ExSASCA、Kyber iNTT 联合学习、拒绝挑战及 PolEn 的上述原始摘要和元数据，未通读证明。NIST FIPS 204 官方页面已核对，但 PDF 打开超时；DATE 2026 的 Rejection Matters 出版页返回验证页面，保留为待直接补读线索，不依据搜索摘要复述其结果。本轮没有执行实验、仿真、训练、作者代码或独立数学复算，也没有派发任务。定位性阅读不修改统一文献库的正式卡片和覆盖统计。
