# 闭合路径 后续公开信息与可组合的物理泄漏界限

日期：2026-11-13。第八批，BOLD-20261113-28 至 30。用户要求进一步扩大构想，验证由其他人承担。以下均为**待验证的研究提案**；手工推导尚未独立核验，没有新实验或仿真。

这次把目标放到三个更大的问题上：电路执行一圈后还留下什么；观察者以后知道的事如何改变旧波形的价值；一个防护模块能否提供接入其他模块后仍成立的定量保证。

已有路径记忆、辅助输入、可模拟泄漏和差分隐私理论是出发点。三个题目都不主张首次提出这些概念；增量必须由具体实现映射和与已有工作的比较确认。

## 28 研究闭合路径的净响应

**直觉：把两个控制量沿一条闭合路线改变，最后代码状态、控制参数和静态读数都复原，累计响应却可能没有抵消。路线的方向和形状可能暴露恢复动力学。**

跨学科对应：经典系统的几何泵送 → 两个公开可控参数与一个恢复状态 → 恢复时间随受保护状态和控制参数改变 → 闭合路径产生可预测的净响应。这不要求量子效应。

### 一个能交给别人检查的小模型

令 S 表示受控测试中的受保护状态。u、v 为两个可独立改变的公开控制参数，x 为可读出的物理状态。假设：

\[
\dot x=-\frac{x-u}{\tau_S(v)},\qquad \tau_S(v)>0,\qquad Y=x.
\]

这里 u 与 x 同量纲；τ 是时间常数。在任何固定的 u、v 下，稳态都是 x=u，**不同 S 的静态输出完全相同**。不同之处只藏在恢复时间里。

沿闭合控制路径运行，测量相对已校准静态基线的积分：

\[
Q_S=\int_0^T [Y(t)-u(t)]\,dt
    =-\int_0^T \tau_S(v(t))\,dx(t).
\]

当物理状态也闭合，即 x(T)=x(0)，若 τ 是常数，则 Q 必为零。在变化足够慢、τ 及其变化有界且瞬态已经处理的条件下，x 接近 u，领先项为：

\[
Q_S\simeq-\oint \tau_S(v)\,du.
\]

若局部近似 τ_S(v)=a_S+b_S v，则：

\[
Q_S\simeq b_S A,\qquad A=-\oint v\,du.
\]

A 是规定方向下的有向面积；量纲由 u、v 和 b 共同决定。两种状态的预测差异是 (b_S−b_{S'})A。**只要 b 没有秘密相关差异，这个模型就没有目标泄漏。**

这是一个经典的一阶时变恢复模型，不是已经发现了新物理。它比“总活动相同”多了一个明确约束：恢复参数随路径上的第二个变量变化。能正确建模这一点的旧状态空间模型应当预测到相同结果。

### 为什么值得往 PQC 上推

可以先问：存放多项式测试状态的资源，是否改变了某个实际可观察恢复模式；两个正常范围内的公开负载或配置，能否独立调节该模式的平衡点与恢复速度？这需要电路或系统辨识证据，不能直接把 NTT 的两层循环当作 u、v。

如果映射成立，就不必先把每次运算的瞬时峰值解释成某个系数，而可研究**整圈响应对秘密状态的约束**。研究者能编排测试代码的能力与真实观察者能控制的输入必须分开列明。

比“换个顺序波形不同”更强的预测有三个：

- 慢变化区间内，反转路径方向应使领先净响应反号。
- 小闭环的响应应随有向面积近似缩放；退化为零面积的路径应消去该领先项。
- 每圈积分可能趋于有限值，但平均响应 Q/T 随周期变长而减小；积累的噪声、准备时间和总采集时间必须一起计算，不能据此声称无限放大。

还应与同预算的普通阶跃响应辨识比较：闭环协议可能帮助抵消基线或检验模型，但不会凭空增加同一完整观测中的信息。若直接测恢复时间已经覆盖全部收益，成果应归为一种诊断协议，而非新的泄漏通道。

### 最小鉴别与否定条件

先交付 τ 的实际载体、两个合法控制量、静态输出匹配证据，以及方向/面积/速率的事前预测。若具备测量条件，再比较正向、反向、零面积路径及未用于拟合的路径；保证功能结果正确并记录完整恢复窗口。

最强竞争解释是边界裁剪、普通固定时间常数的尾迹、仪器高通响应、总负载不匹配或温漂。窗口里 x 没有真正闭合时，常数 τ 也能产生非零边界项；这不能当作几何效应。

若真实 τ 不依赖受保护状态、预定方向/面积规律失效，或差异完全由这些竞争解释说明，则否定当前版本。没有可独立控制的两参数或恢复状态不可观测，记条件缺失。

经典随机系统中的几何泵送已有理论先例。[Sinitsyn 与 Nemenman，原始摘要](https://arxiv.org/abs/q-bio/0612018v2) 该论文不证明 CMOS 或 PQC 存在这里的机制。相对 [BOLD-17 的执行编排](2026-11-12-observation-as-computation.md)和 [BOLD-26 的端口响应](2026-11-13-spatial-modes-port-response-noise-geometry.md)，本项新增的是闭环约束和方向—面积—速率预测。它是本批最偏离现有数据主线的探索项。

## 29 让安全模型携带“什么时候知道什么”

**直觉：随机化可以让一段波形单独看没有区分力，但最终签名或其他合法公开信息，可能给它增加解释坐标。真正应审查的是整个交互中的联合观察。**

跨学科对应：带辅助信息的统计推断、条件关系与因果模拟 → 早期波形 W、稍后公开的转录 C、受保护变量 S → W 与 C 各自无用但联合有用 → 正确绑定的公开信息提高旧波形的利用价值。

### 一个逻辑见证

令 S、R 为独立均匀比特，早期观察 W=S⊕R，稍后公开 C=R。则 W 和 C 各自均与 S 独立，但 S=W⊕C。

这个例子只说明“分别无泄漏”不能推出“联合无泄漏”。**它不声称 ML-DSA 会公开硬件掩码，也不把未来信息解释成改变过去的物理过程。** 若 C 与所用随机量无关系，或联合分布仍与 S 无关，所谓解锁就不存在。

### PQC 中可核查的具体入口

FIPS 204 的内部签名过程有关系 z=y+c·s₁，最终签名编码包含承诺哈希、z 和提示；c 可以由承诺哈希通过规定采样过程得到。[FIPS 204，正文第 24–25 页、Algorithm 7](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.204.pdf)

因此可建立一张精确的时间图：y 何时产生和使用，哪段波形可能与它的实现状态有关，最终公开量何时可得，接受与拒绝尝试如何对应。这里不假设从签名就能直接得到 y，也不能拿最终接受的 c、z 去绑定任意被拒绝尝试。

利用有效及被拒绝尝试的联合侧信道已经有直接研究。[作者摘要](https://eprint.iacr.org/2025/582) 本项进一步想交付的是**公开信息时间表与可组合的观察模型**，不是把已有 nonce/随机量泄漏换个名字。

### 再向前一步：事后拟合与在线模拟是否在说同一件事

可以尝试构造一个只使用允许公开信息的波形生成器，检查哪些物理结构必须引入额外秘密才能解释。可模拟泄漏本身已有正式密码学先例，且其具体保证有适用范围。[Standaert 等，原始摘要](https://eprint.iacr.org/2013/370)

要区分两个任务：

- 固定输入的事后联合分布检验：生成器可按事先定义使用最终公开转录。
- 自适应交互检验：观察者可能根据前段波形选择后续动作。此时必须定义在线模拟器当时可获得的信息或理想接口；事后拿到全部结果才生成波形，不能直接证明在线交互安全。

更大胆的产出是：为签名、解封装及跨模块调用建立**按信息公开阶段分解的泄漏契约**。某阶段“可视作随机”的结论，要说明它在允许后续公开什么的条件下仍成立。

### 最小鉴别与否定条件

第一份交付物是固定实现中的“随机量—物理操作—公开信息—时间绑定”图。随后若验证，保持同一波形和总资源预算，比较仅公开转录、仅波形、正确绑定的联合输入，以及保持合法分组条件的错配对照。

冻结划分时以完整执行、密钥和声称的泛化维度为单位。分类或求解的收益应出现在留出执行中；确认过程中不能读入隐藏 y、掩码或拒绝尝试真值作为实际观察者的输入。

若收益只来自最终输出直接给出的答案、额外训练预算、错误分组或评估真值泄入，则否定该方案。若波形只是改善计算效率，也应如实记录为计算收益；公开密钥可能已在信息论上约束秘密，不能只靠条件互信息大小裁决实际安全。

本项承接既有 [T2H-04 的阶段关系](2026-11-11-two-hour/04-randomness-rejection-and-boundaries.md)与 [T2H-08 的计算收益](2026-11-11-two-hour/08-computation-and-learning-symmetries.md)。新增目标是按时序明确模拟器与观察者的能力；具体新颖性仍待全文比对。

## 30 给物理实现一个能组合的泄漏契约

**大胆目标：像器件规格写明电压、温度和时序范围一样，为一个小模块写明，在什么观察条件、什么前史和多少次交互下，受保护状态仍有怎样的区分上限。**

跨学科对应：差分隐私的条件分布界与组合 → 每段物理观察在已见历史下的概率比 → 模块保证覆盖可达历史和环境 → 多段交互可按明确规则组合。这里研究的是安全定义及防护设计，不是一种新的恢复算法。

### 从一个刻意有限的契约开始

先选一个受控子模块和明确的受保护变量 S，固定允许公开上下文 C，以及需要比较的状态对 (s,s')。它们必须与 C 兼容。令 Y₁,…,Yₙ 为规定观察预算下依次得到的结果。

在共同支持、密度存在等条件下，链式分解给出：

\[
\log\frac{p(Y_{1:n}\mid s,C)}{p(Y_{1:n}\mid s',C)}
=\sum_{i=1}^{n}
\log\frac{p(Y_i\mid s,C,Y_{<i})}
         {p(Y_i\mid s',C,Y_{<i})}.
\]

若对所有允许的历史和观察，每一项的绝对值都不超过预定 εᵢ，则整段的绝对对数似然比不超过 Σεᵢ。这里的求和只是条件分布链式法则的后果，不是新定理。**难点在于能否让真实模块满足逐条件的前提。**

仅有每次调用的边际分布界不够；历史可能改变温度、资源前态、随机源状态或可见辅助信息。对自适应动作，还必须将动作策略和历史纳入同一交互模型。纯界过强时可以研究近似或 Rényi 形式，但不能沿用未经证明的参数换算。

### 不能跳过的密码学边界

“邻近数据库只差一条记录”不能直接替换成“两个私钥只差一位”。实际公钥或允许输出可能已经区分这些私钥；条件于完整公钥后的候选支持也可能退化。只比较毫无敏感差异的兼容状态，会得到没有意义的保证。

所以应分两层推进：先为有明确比较任务的模块建立统计契约；再用允许公开输出的计算安全游戏或模拟关系，证明它怎样接入完整 PQC 协议。ε 不是密钥安全位数，也不能从一次分类器失败反推出 ε 很小。

差分隐私与定时通道已有联合输出、执行环境及组合框架；其对象是 DP 程序，不能直接当作 ML-KEM/ML-DSA 的物理安全定理。[Ratliff 与 Vadhan，摘要及 §1.1](https://arxiv.org/html/2409.05623v2)

### 为什么它会改变防护设计

这会迫使设计者回答：刷新是否同时处理了相关物理状态；清理和等待自身有没有产生新观察；随机活动是否能被辅助通道估计；下一模块能否借同一状态放大差异。

有价值的成果可能是一个很小但诚实的模块：给出输入状态关系、可达前史、传感器及带宽、环境范围、允许公开信息和组合定理。也可能是一个明确反例，证明某个看似合理的局部契约无法组合。

相对 [BOLD-20 的跨调用物理记忆](2026-11-13-interventions-memory-device-diversity.md)，本项要求把“有记忆”变成组合前提；相对 [BOLD-24 的防护排序](2026-11-13-predictive-states-criticality-security-order.md)，本项寻求可证明上界，而不是只比较几个已实现分析器的表现。

### 最小鉴别与否定条件

先让理论验证者写出一个非空、非平凡的状态关系与一条完整组合命题，让电路验证者指出前提中哪些量真实可控、哪些只能观测、哪些不可界定。

之后的测量首先用于**反证模型假设**：改变合法前史，检查留出条件下的联合响应是否违反预定模型；覆盖启动、清理、刷新和辅助读出。经验分类器可以给出攻击证据或区分能力下界，有限样本未发现差异不能单独证明普遍上界。

若契约只覆盖孤立调用、假定了现实没有的物理重置、依赖不可获得的真实噪声标签，或将公开输出已提供的区别混入保护目标，就应撤回该版本。若理论有界但参数在实际调用次数下毫无用处，也应报告这一限制，不能称作可部署保证。
