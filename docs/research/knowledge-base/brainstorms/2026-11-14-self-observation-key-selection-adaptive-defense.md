# 自我观察 密钥选择与动态防护的安全边界

日期：2026-11-14。三个待验证研究方向，由用户安排其他研究者核查。本轮把问题从单次计算扩大到设备能否判断自己的保护状态、密钥生成是否需要考虑器件，以及持续变化的防护怎样面对长期观察。三项深化已有种子，不增加 BOLD 编号，也不主张首次提出相关技术。

| 方向 | 挑战的前提 | 新增的研究对象 | 验证者第一份产物 |
|---|---|---|---|
| A 自我观察 | 内部指标正常足以说明外部观察安全 | 内部传感器与外部观察之间的覆盖关系 | 一个监测盲区反例，或受限观察族下的覆盖条件 |
| B 密钥选择 | 物理上更难测的密钥也一定更安全 | 器件条件下的生成分布及选择转录 | 筛选后的完整分布与密码学后果 |
| C 动态防护 | 防护变化快就能阻止长期学习 | 秘密、策略状态与观察历史的联合过程 | 包含切换痕迹的策略模型及竞争预测 |

## A 芯片能否判断自己的保护条件正在失效

**大胆直觉：让密码模块带着一个有适用范围的物理监测契约运行。温度、器件变化或资源竞争使契约失效时，模块能够识别需要恢复、切换或停止的条件。更激进的问题是，哪些保护状态原则上就不可能由内部传感器判断？**

跨学科对应：控制系统的可观测性与运行时保证 → 局部电流、供电模态、时序裕量及内部传感器 → 内部观测必须覆盖会改变允许外部读出的状态差异 → 盲区中的变化可能让内部指标保持正常，而外部区分能力发生变化。

先看一个有限的线性说明模型。q 是实际活动或电流模态，内部读数 M=Aq+ξ，外部读数 Y=Bq+ε。若存在一个物理上允许的差分 v，使 Av=0 而 Bv≠0，则该差分对内部传感器不可见，对外部观察却可见。对于需要从 Aq 重建所有 Bq 的无噪声线性问题，必要且充分的条件是 ker(A) 包含于 ker(B)。实际问题还要考虑噪声、条件数、时变参数及允许状态集合；这个线性条件本身不是密码安全证明。

一个手工见证是两支路电流分别为 (a+δ,a−δ) 或 (a−δ,a+δ)，其中 a>|δ|。总电流都是 2a，但差模读数分别为 ±2δ。它仅说明总电流恒定不能排除空间差模，不证明具体 PQC 芯片存在相应秘密路径。若监测器还拥有代码、布局或额外状态信息，必须把这些信息纳入契约，不能把它错误地限制为只知道总电流。

**PQC 落点：**从固定掩码算术模块或 NTT 蝶形的资源分配开始，明确内部传感器的端口与频段，以及外部观察者允许的功耗、EM 或其他读出。要求模型解释：哪些秘密相关活动变化会进入监测读数，哪些可能只改变外部空间或频率模式。现场没有秘密标签时，不能直接把实验室中需要分组的统计检测照搬为逐次报警。

**可观测预测：**若指定盲区真实存在，匹配内部读数后，外部某个预定模式仍有可重复的条件差异；增加针对该模式的传感器或切断耦合，会按模型改变差异。温漂、前端增益和公开输入直接造成的变化是竞争解释。

**最小鉴别：**先交内部与外部的观察映射、允许状态差分，以及一个监测等价但外部可区分的候选执行对。然后判断能否补传感器或缩小契约范围。若要主张安全上界，还须定义观察预算、秘密任务和参数不确定集合，并证明从监测条件到风险上界的关系。仅验证告警分类准确率不够。

**否定条件：**所谓盲区不对应合法执行；外部区别由公开信息完整解释；补充已知硬件信息后反例消失。反过来，如果提出的证书对所有状态都只能给出“可能不安全”，它虽可保守正确，却没有实现有用的自检目标。无法证明宽泛契约时，保留一个有范围的监测能力或不可能性结论。

实时监测与自适应缓解已有直接先例。Kiaei 等人的 2021 年文章提出此架构；其正文区分了已制作的片上传感器与仍需研究的通用泄漏指标，并指出普通 TVLA 分组无法直接用于其在线目标。[原文 II–IV 节](https://arxiv.org/html/2107.01725v1)。所以候选增量是**内部可见性究竟支持何种外部保证**，不能把已有架构当作新发明，也不能把这篇早期工作写成通用安全已获验证。

这一项连接已有的[空间电流](2026-11-13-spatial-modes-port-response-noise-geometry.md)、[观察者反作用](2026-11-13-self-calibration-hidden-encoding-observer.md)和[泄漏契约](2026-11-13-closed-loops-delayed-disclosure-leakage-contracts.md)。它偏离当前局部算术波形主线，保留一次可观测性或反例诊断的机会。

## B 能否为一块芯片选择更安全的密钥分布

**大胆直觉：密钥与芯片可能存在物理上的不匹配。若允许生成器主动避开容易泄漏的组合，能否显著改善安全？但这种选择也可能把原本困难的密码问题变成更有结构的问题，甚至把挑选过程本身变成侧信道。**

跨学科对应：选择偏差与分布设计 → 合法密钥生成、器件参数 D、接受规则及其运行转录 → 物理风险筛选改变条件分布 → 波形可能更难区分，同时代数结构或选择记录提供新的推断能力。

设固定器件 d 上，原始秘密变量 K 的分布为 p(k)，候选接受概率为 w_d(k)，总接受概率为 α_d>0。仅在原始 K 与 D 独立、规则与器件条件固定的简化模型下，接受后的分布为

\[
p_d(k\mid\mathrm{accept})=\frac{p(k)w_d(k)}{\alpha_d},\qquad
\alpha_d=\sum_k p(k)w_d(k).
\]

由于 w_d(k)≤1，不含其他转录的这个模型满足

\[
H_\infty(K\mid\mathrm{accept},D=d)
\ge H_\infty(K)+\log_2\alpha_d.
\]

这是一个概率重加权的手工推导，不是 PQC 安全定理。均匀密钥空间中的确定性筛选达到该表达式的等号，但 ML-KEM 的展开秘密不能直接假定在所有系数组合上均匀。公钥、筛选测量、拒绝次数、被丢弃候选的残留及器件校准信息一旦可见，都需要进入完整分析；不同选择过程也不保证拒绝次数独立于最终输出。

更关键的是，保留较多最小熵不等于保留原问题的计算困难性。例如，偏向稀疏、特殊系数排列或低翻转轨迹的规则，可能偏向密码分析者能够利用的结构。这是待研究的风险路径，不是对任何现有标准密钥的漏洞结论。

**PQC 落点：**以标准密钥生成作为对照，先审查一个器件条件下的候选接受函数会如何重加权种子、公钥、秘密与误差的联合分布。[FIPS 203](https://csrc.nist.gov/pubs/fips/203/final)是 ML-KEM 基线标准；这里的筛选是待分析的新构造，功能正确不使它自动继承基线的安全结论。

**可观测预测：**若存在可迁移的密钥与器件交互，筛选应改善同一器件上、未用于选择的输入和会话中的物理风险，且换器件后可能改变收益。与此同时，接受后的可计算结构统计或选择转录可能产生区别。必须同时评价这两面，不能只公布更低的相关峰。

**最小鉴别：**先交一个明确接受规则及其精确或可审计的条件分布分析，再提出三个同预算对照：保持标准密钥分布；只按非秘密的器件校准选择实现；按秘密与器件共同筛选密钥。固定风险评估方法，并在留出输入、会话和器件上区分泛化收益与挑选测试集的过拟合。第一轮可以只交理论反例，无须生成或部署新的正式密钥。

**否定条件：**收益来自过拟合；选择成本和转录泄漏抵消收益；规则制造可利用结构；或者只调整实现就能获得相同收益。若某个筛选失败，只否定该规则，不能据此宣布一切物理条件化生成都不可能。

长期目标可以是证明一类受限重加权保持所需困难性，也可以是证明某类“低泄漏筛选”必然付出代数或信息代价。它深化了[密钥与器件的交互](2026-11-13-key-device-seeds-scaling.md)，把旧提案留下的生成分布问题正式变成研究对象。

## C 持续变化的防护能否抵抗持续学习的观察者

**大胆直觉：密码模块可以在多种正确的物理实现之间切换；观察者也会持续学习当前实现。研究对象应包括双方的历史，而不能把每次换配置都当作重新开始。真正有价值的目标是，在完整观察转录下找到仍然有效的动态防护策略，或者给出它必然失效的条件。**

跨学科对应：部分可观测动态博弈 → 防护配置 Q_t、内部反馈 M_t、公开输入 U_t 与外部历史 Y_{1:t} → 防护策略与观察策略相互适应 → 单次混合分布的安全表现可能不同于完整序列的表现。

一个候选状态模型为

\[
Q_{t+1}=\pi(Q_t,M_{\le t},R_t),\qquad
Y_t=G(K,U_t,Q_t,H_t)+\varepsilon_t.
\]

H_t 表示真实物理历史，R_t 是有明确定义的新鲜随机性。策略可以固定，也可以按反馈变化；若 M_t 受秘密活动影响，策略动作就可能泄漏。完整转录还要纳入可见的配置特征、切换时刻、停顿、刷新、清理和公开输出。配置不直接公开也不表示无法由波形推断。

一个手工反例说明应检查什么。秘密位 S∈{−1,+1}，独立均匀模式 Q∈{−1,+1}，读数 Y=QS。在无其他观察时，Y 的分布与 S 无关；若另一个读数 C=Q，则 CY=S。加入噪声会改变可恢复程度，但不会消除分析联合转录的必要性。这个例子不是芯片上的新机制；真实版本必须找到 Q 的载体和 C 的来源。

**PQC 落点：**候选配置可以改变正确算术的资源绑定、份额布局或合法调度。实现必须先证明功能与保护前提仍成立，特别是配置间搬运和刷新阶段。然后检查模式痕迹来自何处：独立的校准阶段、不同资源的响应、切换停顿，还是反馈阈值。不能假定“换得比模型训练快”就防止了联合推断。

**可观测预测：**固定模型在混合配置下的区分能力下降；若模式可读，条件化或序列推断可能恢复其中一部分能力。若策略确有额外收益，该收益应在计入模式推断、策略公开、切换窗口及全部采样成本后仍然存在，并能预测留出切换规则的效果。具体哪种结果成立由模型决定，不能把两者同时当作支持。

**最小鉴别：**先给出有限配置集合及转移规则，比较固定配置、独立随机切换、历史反馈切换三种策略。观察模型同时包含数据通道与模式通道，并分别分析模式已知、可部分推断和确有依据的隐藏三种条件。对比必须匹配功能、时间、能量、随机数和可见窗口；更慢的实现不能靠少做任务获得虚假的优势。

**否定条件：**所谓收益在完整转录下消失；反馈动作直接暴露目标关系；切换只是现有随机化的等价重述；或者优势仅来自未计入的成本。若提出有保证的策略，则安全游戏还须限定观察者计算能力和任务，不能由某一学习算法训练失败推导安全。

已有移动目标防护先例：[RandOhm 的作者摘要](https://arxiv.org/abs/2401.08925v3)描述以运行时配置随机化缓解 FPGA 阻抗侧信道；[Cazzola 的硕士论文摘要](https://digitalrepository.unm.edu/ece_etds/623/)描述 AES 的动态部分重配置及不同多样性组合。它们说明配置变化已有研究，不能仅凭摘要判断其完整长期安全。这里的候选增量是**带物理记忆、策略反馈和配置侧信息的持续观察模型**，不是重新命名动态重配置。

这一项连接已有的[随机计算图](2026-11-14-computation-codes-rejected-transcripts-random-graphs.md)和[硬件适应](2026-11-14-adaptive-hardware-simulation-rare-paths.md)。后者研究机器如何留下秘密相关适应状态；本项研究防护者主动改变机器时，哪些策略收益在完整历史中仍成立。

## 交给验证者的第一轮任务

| 方向 | 适合的验证视角 | 第一轮只需交付 | 值得保留的负结果 |
|---|---|---|---|
| A | 模拟电路 测量 控制理论 | 一个真实端口模型与监测盲区，或一个受限覆盖证明 | 明确哪些外部观察不能由现有内部指标保证 |
| B | 密码学 概率论 实现分析 | 一个接受规则的分布推导及密码学后果 | 证明物理筛选造成结构偏差，或其收益可由改实现替代 |
| C | 随机过程 信息论 硬件防护 | 一个含模式痕迹的动态模型与两种分叉预测 | 证明某类切换收益完全来自忽略侧信息或成本 |

三项都应先交机制与反例，再决定是否值得采集数据。A 保留一个偏离现有主线的小规模理论诊断。验证者可以直接否定当前版本，不要求先得到攻击成功或性能提升。

## 构思修订与证据范围

最初的“芯片给自己发安全证书”收紧为有覆盖范围的监测契约；“选最安静的密钥”收紧为生成分布与转录的联合分析；“不停变换就无法学习”收紧为双方都有历史的策略问题。三项仍是提案，手工等式只是有限模型中的推导，没有实测支持。

本轮定位性阅读包括 Kiaei 等人的原始摘要及 HTML 正文 II–IV 节、RandOhm v3 摘要、Cazzola 学位论文的机构摘要，以及 FIPS 203 官方发布页。FIPS PDF 只读到开头说明，对算法编号的定位请求超时；本提案没有据此声称逐行核对密钥生成流程。2021 年 7 月的监测工作在当前冻结的近五年窗口之前，仅作为基础先例。上述阅读没有新增正式文献卡片，也不构成完整新颖性检索。

本轮没有实验、仿真、训练、独立核验或任务派发；验证由用户安排。既有文献普查和实验接续状态保持不变。
