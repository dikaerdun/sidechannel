# 更大胆的六个研究方向：从单次波形走向关系、供给与器件变化

日期：2026-11-12。状态：**研究提案，全部待验证**。本轮只做构思、旧记录对照、相关来源核查与文档交接；没有运行新实验，也没有邀请独立核验者。用户将另行安排验证。

本文承接[此前的十三篇理论专题](2026-11-11-two-hour/README.md)，扩大选题空间，不替换既有实验结论。下文“新”指相对于指定基线增加的变量或问题，**不代表已证明文献首创**。近五年论文库的系统检索、逐年覆盖核对与引用追踪仍未完成。

## 六个种子

|---|---|---|---|

## 01：掩码的关系图中，是否存在“消掉随机性却留下秘密”的组合？

### 直觉及明确对应

图上的循环流 → 中间量对随机变量的依赖 → 某些组合消去随机项 → 留下可辨识的秘密函数。

暂用有限域上的线性片段说明：

\[
z = A s + B r,\qquad w^\top B=0.
\]

于是：

\[
w^\top z=w^\top A s.
\]

只有当右侧在合法候选之间确实不同，而且攻击者能获得对应观测时，才形成有用约束。若右侧恒为零、只含公开量，或者所有合法候选上相同，就没有秘密区分力。

一个直观模型是边量 \(z_{uv}=x_{uv}+r_v-r_u\)。沿有向闭环求和，顶点随机量抵消。但真实 NTT 执行图通常是有向无环结构；这里的“环”可以只是因子依赖中的闭合关系，**不能凭图像相似就认定实际存在这种公式**。

### 最有可能成立的版本

从固定的掩码转换、刷新、寄存器复用或跨模块接口出发，追踪每个随机变量的真实来源和生命周期，确定候选矩阵 B；再寻找少量、确实能联合观测的线性组合。目标是发现局部审计遗漏的组合条件，或证明这些条件已被现有安全证明覆盖。

这不是新的掩码破解定理。重构多个份额、随机性抵消和安全复用都有既有研究。可能有价值的增量是：**把算法中的随机性依赖、编译后的资源绑定、测量允许的联合观测放到同一张可审计图中**。[随机性生成研究](https://eprint.iacr.org/2023/1134)讨论了不当生成方式带来的抵消风险；[安全复用研究](https://casa.rub.de/en/research/publications/detail/randomness-optimization-for-gadget-compositions-in-higher-order-masking)则说明“复用”本身不等于漏洞。

### 新旧模型区别

逐点模型只看每个观测的分布是否随秘密改变。关系模型额外检查：它们共享哪些随机量、允许组合哪些观测、组合后剩下什么。若现有基线已准确覆盖这些联合关系，本方向就不构成模型增量。

数字中间量满足线性公式，**不意味着几个功耗样本可以直接相加或相减得到同一公式**。实际读出可能是非线性的、位置相关的、带相关噪声的；这层映射必须单独验证。

### 最小鉴别与反例

1. **先做静态资格检查：**在一个具体实现片段中导出随机变量依赖，找出候选 w，并证明对应秘密函数不是公开常量。没有映射就停止该版本。
2. **再做受控比较：**原实现与切断指定依赖的版本比较；匹配调度、随机位预算和观测机会，并记录无法匹配的副作用。
3. **独立比较：**单窗口基线、正确关系模型、错误关系绑定；先用可精确求解的小问题核对推断逻辑，再考虑实测。

否定条件：不存在所需关系；剩余量无区分力；关系不在实际观测预算内；或结果完全由独立份额泄漏、仪器混合及错误计权解释。

更强的理论产出也可以是一个**不可行性证书**：在给定随机依赖、观测阶数和读出模型下，不存在这类可用组合。有限域线性部分的证书不能冒充整个非线性电路的安全证明。

## 02：防护系统“怎样领取随机数”，会不会成为额外的传感器？

### 直觉及明确对应

排队论 → 随机位生产者、缓冲和消费者 → 需求时序影响资源状态 → 补给活动或等待提供间接观测。

变量包括缓冲占用 \(Q_t\)、生产量 \(R_t\)、请求量 \(D_t\)、等待事件 \(W_t\) 和公开执行上下文 P。重点检查：

\[
\Pr(W_{1:T},R_{1:T}\mid S,P)
\]

是否随秘密 S 改变。

**缓冲被用空不等于密码学熵耗尽。** 这里不假设能预测安全伪随机发生器的输出，而是研究供给和消费的元数据。已有研究确认随机位生成是掩码硬件的真实成本；并未因此证明本方向的秘密相关排队机制。[来源](https://eprint.iacr.org/2023/1134)

### 最有可能成立的版本

某个实际实现中的自适应刷新、转换、尝试边界或资源竞争，导致需求时序与秘密相关的内部过程耦合。目标可以是掩码 ML-KEM/ML-DSA 的完整实现，但必须先找到具体耦合位置。

新增观测可能来自随机数生成器自身的功耗、共享供电上的补给活动、内部等待，或者保护模块与运算模块之间的相位关系。当前单一模乘公开数据没有这些状态，不能用它直接验证。

### 新旧模型区别

常见局部模型把随机位当成随取随有的外部输入。新模型把随机位供应作为有状态的系统组成部分，检查保护成本是否向外传递了执行关系。

重要的强反例：若需求、补给和队列初态在给定公开上下文后均与秘密独立，则仅观察这些元数据不能凭空得到秘密。随机需求只依赖公开阶段的实现不满足本候选的核心条件。

### 最小鉴别与反例

1. 在固定实现中记录请求时序及其数据依赖；先判断差异是否只由公开输入、允许输出、尝试次数或其他已知流程解释。
2. 在保持算法输出和随机值质量的前提下，对比原供给方式与固定速率、隔离缓冲等受控版本；不把简单增加随机位数造成的变化当作机制证明。
3. 同时保留随机供给观测与运算区观测，预先规定跨执行划分和错配时序对照。

预测：效应应跟随指定供给瓶颈变化，而不是仅跟随公开工作量。否定条件：需求过程与秘密条件独立；隔离供给不改变效应且其余路径已排除；或只有公开阶段分类能力。

需要的条件：有随机接口说明、可追踪消费位置、可修改供给策略的 RTL/固件，以及相应观测。先提交资源依赖图，不要求第一步就进行密钥恢复。

## 03：计算会不会逐渐改变芯片，使芯片成为历史的记录？

### 直觉及明确对应

材料的迟滞与老化 → 器件参数缓慢变化 → 历史活动改变以后如何响应 → 用统一的公开程序读出过去留下的差异。

此前“物理记忆”主要讨论寄存器前态、短时供电恢复和调用间历史。本方向进一步把**读出通道自身的参数**列为随时间变化的对象：

\[
\theta_{n+1}=F(\theta_n,X_n,E_n), \qquad
Y_{\mathrm{probe}}=G(P_{\mathrm{probe}},\theta_n)+\epsilon.
\]

X 为实际内部活动，E 为温度、供电等环境，\(\theta\) 为待识别的器件参数，\(P_{\mathrm{probe}}\) 是事先固定的公开探测程序。公式只是建模框架，不是已校准的老化定律。

### 已知事实和真正要补的问题

SRAM 的数据相关老化留痕已有直接研究，UnTrustZone 在其条件下展示了通过加速老化与上电状态读出存储秘密。因此“芯片会记住秘密”本身不是新的发现，也不能由加速条件推断正常运行中的实用泄漏速率。[作者项目页](https://forte-research.com/UnTrustZone/)

更具体的待研究问题是：

- 秘密只在计算中短暂出现、没有长时间静态驻留时，是否仍形成有偏的长期作用？
- 公开输入不断变化、总运行时间与总能量匹配后，不同秘密是否产生可重复的参数变化？
- 更新密钥和清除数字状态后，旧工作负载是否仍影响统一公开程序的响应？
- 地址轮换、掩码刷新、均衡驻留时间分别改变哪一种历史效应？

这里首先寻找工作负载相关的持久变化。能区分两种历史工作负载，仍不等于能恢复具体秘密。

### 最小鉴别与反例

1. **先检查活动分布：**若可用模型中不同秘密诱导的相关驻留/应力过程完全同分布，该模型下的长期积累不能产生区分。不得用“时间够长”回避这个条件。
2. 使用多器件、基线测量与随机分组，对比等时长、尽量匹配环境和工作量的两类历史；考虑老化不可逆，不能把普通交叉实验当成已消除历史影响。
3. 清除数字状态、完成预定恢复等待后，运行统一公开探测程序。控制静态存储驻留，并单独比较固定地址与地址轮换。
4. 跟踪效应随使用量、恢复时间和器件变化的曲线，排除普通温漂、批次差异及采集顺序。

否定条件：效应随短时冷却消失；只反映静态存储驻留；与秘密相关活动无关；或跨器件不超出预设检验能力。低于检测限时报告上界或条件不足，不能断言任意时间尺度上不存在。

这是明显偏离当前主线的保留方向。第一轮小规模诊断应是活动分布和存储驻留审查；长期硬件测量需另设预算，不在本轮执行。

## 04：内部“纠正过的错误”是否泄漏，而外部结果始终正确？

- **跨学科对应：**可靠性工程与生存分析 → 内部纠错/重放事件及等待时间 → 出错概率或恢复路径依赖内部状态 → 成功执行的尾部分布仍可能不同。
- **具体对象：**带存储 ECC、错误重放或补偿机制的硬件。这里的 ECC 指硬件纠错码，不是椭圆曲线，也不默认等同于 PQC 算法中的译码过程。
- **预测与最小鉴别：**在已确认存在相关机制的实现中，记录全部尝试的事件、输出正确性、延迟与恢复能量；比较固定公开上下文下的条件分布，并验证效应是否与实际纠正事件对应。
- **否定条件：**没有相关硬件；事件率只依赖地址/环境；或效应仅由筛掉失败执行所产生的选择偏差解释。不能只保留成功样本而隐藏失败率。
- **已有边界：**ECCploit 已展示其平台上纠错事件可带来时间差异；迁移到 PQC 内部状态并形成可利用约束仍是提案。[作者项目页](https://www.vusec.net/projects/eccploit/)

## 05：不还原排列，直接研究匿名运算图能留下多少秘密约束

- **跨学科对应：**群作用与商空间 → 打乱排列产生等价执行 → 研究排列不改变的关系 → 只用关系观测压缩候选。
- **新增变量：**层内值或读出类别的多重集合、重复关系、可核查的层间关联；不先要求知道“这是第几个系数”。
- **预测与最小鉴别：**在一个合法的小型 NTT 实例中，精确计算只给匿名关系时的候选等价类，再逐步引入真实观测误差；与恢复排列的基线比较。实际测量需证明关系来自数据，而不是物理位置。
- **否定条件：**这些关系在合法候选间完全相同；只恢复一个仍很大的对称等价类；或关系读取实际上已要求完整中间值。打乱执行也可能改变物理前态，不能默认波形只是被纯粹排列。
- **已有边界：**打乱 NTT 的层间匹配、shuffle node 和图推断已有工作。可研究的增量是“完全不恢复排列时还剩什么，以及何时已足够”，不是重新宣称图攻击。[原始论文摘要](https://eprint.iacr.org/2022/555)

## 06：是否存在由约束布局决定的“集体可恢复门槛”？

- **跨学科对应：**统计物理与渗流 → 局部不确定变量及连接它们的运算约束 → 局部证据跨关键连接传播 → 联合恢复出现陡峭变化。
- **新增约束：**泄漏落在哪些节点、哪些连接仍可用、噪声如何共同相关。两个布局可以拥有相同观测数和单点质量，却不提供相同的联合约束。
- **预测与最小鉴别：**在固定的小型推断问题上，比较均匀、聚集、跨层连接等观测布局；先用精确求解校准，再测近似推断。匹配局部通道，并加入错配图、重复证据与相关噪声对照。
- **否定条件：**所谓门槛只来自 BP 停止规则、模型容量或重复计权；精确结果不显示预定差别。固定尺寸上的陡坡不能直接称为热力学意义的相变。
- **已有边界：**SASCA 的编码论视角已有成熟研究。本问题应明确限定为具体 PQC 运算图上的布局与有限规模效应；也不能把完整公钥下的无界 Shannon 信息与有限算力恢复难度混为一谈。[原始论文摘要](https://eprint.iacr.org/2018/498)

## 怎样交给验证者

第一批只建议三项资格检查，不宣布实验已经启动：

| 交接项 | 第一份应交回的产物 | 通过后才做的工作 |
|---|---|---|
| 01 随机依赖关系 | 固定代码/RTL 版本、随机变量来源、候选组合及非公开剩余量，或不可行反例 | 验证真实联合读出及受控干预 |
| 02 随机位供给 | 消费/补给依赖图，给定公开上下文后的独立性分析 | 供给隔离与时序测量 |
| 03 长期器件变化 | 相关活动分布、秘密驻留位置、短时与长期机制的区分方案 | 多器件受控测量与恢复曲线 |

建议验证报告只回答：假设的哪一环有证据，哪一环不成立，哪些条件尚未具备。不要为“整体想法”投赞成票，也不要把运行报错记成物理机制被否定。

当前 Reference-PPM 数据不足以直接验证上述三个方向：它不提供掩码依赖、随机供给队列或长期器件状态。对 04–06 也须重新做数据资格核查，不能因为已有波形就默认可测。

## 认识如何变化

| 初始直觉 | 本轮补强/修正 | 当前保留理由 |
|---|---|---|
| 环可以让掩码消失 | 限定真实随机依赖、可观测组合、非公开剩余量；承认普通份额重构已有理论 | 可形成跨代码、资源与测量的审计对象，也可能产出严格反例 |
| 随机数供应可能泄漏 | 区分随机值安全与供给元数据；明确条件独立即排除机制 | 把防护系统的实现成本纳入测量对象 |
| 芯片会被秘密“写入” | 老化留痕已有论文；进一步区分静态存储和动态运算造成的长期改变 | 跨越单次执行的时间尺度，仍值得保留 |
| 输出正确就没有故障信息 | 区分内部纠正与外部正确，并检查选择偏差 | 可靠性机制可能扩大观测对象 |
| 必须解乱序才能利用关系 | 先求匿名观测的等价类；承认既有 shuffle/BP 工作 | 能给出“无需恢复哪些东西”的明确边界 |
| 更多好采样点必然更好 | 研究位置和依赖布局；用精确求解区分推断失败 | 连接物理测量预算与代数约束结构 |

没有独立 Agent 在本轮提出、补强或复算这些想法；上表是主 Codex 的构思与来源核查修订，不伪装为多方共识。
