# 从物理观察出发重新设计密码研究

日期：2026-11-14。供用户安排其他研究者验证。将已有构思推进为三个规模更大的研究目标：改变密码算法的设计起点、寻找运算结束后的关系读出、让模型修订本身成为可复现的方法。它们是已有方向的深化，不新增 BOLD 编号，也不表示机制已获验证。

## 先保留六个大胆问题

1. **能否设计一种后量子算法，让完整物理观察只暴露一个仍然困难的问题？** 把物理接口列入算法设计条件，而不仅在固定算法外面加保护。
2. **秘密能否不在寄存器里，却仍留在机器对下一次公开操作的响应里？** 从当前值改研究历史状态与受控响应。
3. **能否从模型失败的最小反例，自动发现下一版安全模型需要增加的状态？** 大模型提变量，独立验证者检查可辨识预测。
4. **能否保护某个秘密任务，而允许波形具有很强的可预测结构？** 区分“能预测波形”和“能计算秘密”，继续研究任务与观察预算。
5. **能否让防护改变物理关系的结构，而不只是降低每条观测的信噪比？** 检查关系的方向、秩、环与共享误差；不得把重复测量误算成独立约束。
6. **是否存在一个资源边界，越过它以后某类安全实现根本不存在？** 在固定观察模型与合法实现族内找无解证书或反例，不预设普遍的物理定律。

下面只深化前三项。第一个明显偏离当前局部算术波形主线，保留一次理论资格检查；其余问题继续留在种子池。

## A 从物理泄漏接口倒推密码算法

**核心挑战：密码方案与物理实现可否从一开始共同设计，使允许的完整观察本身也是安全定义的一部分？** 更强的目标不是声称“波形没有信息”，而是证明从波形获得的计算能力没有超过一个明确、仍被认为困难的接口。

跨学科对应：密码学归约与统计实验模拟 → 完整执行转录 Y、公开上下文 P、允许接口 L → 存在只用当时可见的 P 与 L 的高效模拟器 → 观察 Y 不应再提供模拟接口之外的有效区分能力。模拟器不得读取秘密、隐藏误差或尚未公开的未来量。

可从候选带噪关系 L 开始，但“形如 LWE”远远不够。需同时规定秘密和误差分布、输入选择、跨调用相关、样本总量与密码任务，再证明实际操作没有另行暴露误差或秘密读取过程。对于公钥方案，公钥可能已在数学上确定秘密，不能用无计算限制的条件熵代替计算安全游戏。

**PQC 落点：**先设计一个小型解密或份额转换模块的接口，并允许改变算法结构、表示和随机化位置。证明抽象构造存在之后，再比较它与固定 ML-KEM 内核的资源和保护成本。不能由小参数算例宣布计算安全，也不能直接把修改后的构造称作标准 ML-KEM。

已有具体先例：[POLKA 的 NIST 2022 演讲说明](https://csrc.nist.gov/Presentations/2022/towards-leakage-resistant-post-quantum-cca-secure)介绍围绕泄漏保护重新设计后量子加密，使用刚性、随机化解密、可掩码计算及物理学习假设。本轮仅读该说明，未核对完整证明；它支持这一设计路线已有先例，不支持本提案的全执行保证。

**最小鉴别：**验证者交一个允许接口、完整调用时间图、候选实现与模拟器，或一个最短反例。随后才考虑观察实验：给定 P 与 L 后，预先冻结的检验是否仍能从剩余波形改善指定任务？独立的算术、随机源、刷新与清理窗口全部属于观察预算。

**否定当前版本：**额外观察可消掉接口噪声；合法输入破坏所需分布；模拟器需要秘密；或者所谓构造依赖一个被悄悄排除的大型安全模块。有限检验通过只能支持受测范围，不能替代归约。

这深化[困难问题泄漏接口](2026-11-13-resource-bounds-lwe-leakage-counterfactuals.md)。目标是一个有明确模型的候选构造或不可能性结果；不把已有泄漏韧性研究重新命名为新方向。

## B 让公开操作成为秘密历史的显影剂

**核心挑战：敏感计算结束、软件状态清理以后，机器是否还保存了一种只能通过后续响应读出的秘密关系？** 研究对象是状态如何影响响应，而不是把同一段波形换个分类器。

跨学科对应：系统辨识与受控探测 → 供电恢复、资源队列、空闲状态及公开后续操作 → 两种已清理执行仍有不同物理状态 H → 同样的公开操作 U 产生不同的响应 Y。候选结构是 H 的转移规则与读出函数，而不是一个能够记住批次的任意隐变量。

**强版本：**先找到旧模型判为等价的两段合法准备历史；它们具有匹配的指定架构状态与公开结果，却对两个后续公开操作给出不同的条件响应。仅找到历史分类信号不够：新的 H 必须同时预测改变等待时间、操作顺序或指定重置后的变化，并解释其中哪些差异与秘密相关。

**PQC 落点：**固定模乘、约减或掩码刷新之后，研究公开短操作对残余状态的读出。要求明确准备历史是否实际可达、秘密是否固定以及观察者能否选择后续操作。由研究者主动安排探测的实验，不能直接称为被动攻击。

[IdleLeak 的官方摘要](https://www.ndss-symposium.org/ndss-paper/idleleak-exploiting-idle-state-side-effects-for-information-leakage/)展示空闲状态可以参与微架构观察和隐蔽通信。这是查找遗漏状态的具体先例；它不证明清理后的 PQC 秘密留痕，也不证明功耗恢复机制。

**最小鉴别：**先提交“准备历史—等待/重置—公开操作”的因果图，以及两种机制对未测后续操作的分叉预测。之后由验证者用独立采集链、随机化批次和仪器响应对照判断：差异随设备状态消失，还是随采集系统改变？若干预同时改变其他资源，应保留混杂解释。

**否定当前版本：**效应由仪器滤波或公开上下文完全解释；候选状态无法预测另一种公开操作；指定重置不产生预期变化；或者所谓秘密历史其实没有合法实现。负结果应说明排除了哪种机制和时间尺度。

这深化[物理遗忘](2026-11-14-physical-forgetting-spacetime-reversible-computation.md)与[状态发现](2026-11-13-three-research-programs.md)，新增交接重点是通过两个不同的后续操作检验同一个状态模型。

## C 让研究系统发现现有安全抽象缺少什么

**核心挑战：能否把“算法状态相同，物理结果却不同”变成可自动搜集、压缩和修订的研究证据？** 长期产物是一套能够提前预测实现改动后果的抽象，而不只是一个在旧数据上准确的预测器。

跨学科对应：反例驱动抽象修订与因果模型选择 → 旧状态映射、模型等价的执行对、真实资源干预 → 旧映射遗漏影响观察的变量 → 加入少量状态后能预测整份留出实现的响应变化。

工作单位可以是一对合法执行及一个差分：寄存器前驱、共享资源、缓存一致性、功耗管理状态或份额的相对位置。大模型提出至少两个竞争解释，编译或 RTL 检查确认差分真实存在，验证者冻结预测。新增状态不得只是执行编号、秘密标签或全历史的无解释拷贝；它应在声明范围内压缩历史，并支持新操作的预测。

**PQC 落点：**从同一模乘或蝶形的四个正确实现出发。前三份用于固定模型，第四份组合两种实现变化并留出。模型要事前预测指定窗口中的差异方向、消失条件或范围；不能看到第四份结果后再换解释或重选窗口。

已有工作提供不同层面的基础。[BliMe 摘要](https://www.ndss-symposium.org/ndss-paper/blime-verifiably-secure-outsourced-computation-with-hardware-enforced-taint-tracking/)报告简化 ISA 的机器检查证明；[TEE-SHirT 摘要](https://www.ndss-symposium.org/ndss-paper/tee-shirt-scalable-leakage-free-cache-hierarchies-for-tees/)报告缓存层次的形式化模型。这些保证必须按其观察语义解释，不能由标题推成整机模拟功耗安全。本提案要研究的是如何发现、验证并记录抽象与物理观察之间缺失的部分。

**最小鉴别：**验证者先返回旧模型等价条件、真实实现差分和两个不同预测。若所有可实现干预下预测都相同，当前机制尚不可辨识，应修改实验问题；不能由模型投票决定哪一种物理机制是真的。

**否定当前模型：**第四份实现上预测失败；新增变量无法跨操作使用；或所谓机制只识别设备/采集批次。失败应回写成最短反例，明确下一版增加了什么假设，不能只把网络做大后覆盖旧结论。

这深化[跨实现反事实预测](2026-11-13-resource-bounds-lwe-leakage-counterfactuals.md)。通用的抽象修订不是新概念；候选增量是固定物理状态、实现变换、观测条件与独立留出预测之间的可检查联系。

## 交接次序与认识变化

| 优先项 | 第一份交付 | 保留理由 |
|---|---|---|
| A 理论资格检查 | 接口、安全游戏、实现和模拟器，或最短反例 | 最可能改变算法设计起点，也最容易暴露循环假设 |
| B 物理资格检查 | 真实状态载体、两个读出操作与重置预测 | 能直接检验“当前逻辑状态足够”的前提 |
| C 方法资格检查 | 四份正确实现、两种竞争机制与冻结预测 | 无论正负结果，都能沉淀可复用的模型边界 |

从“波形看起来像难问题”收紧为完整转录模拟；从“运算后还有波形”收紧为设备状态与仪器记忆的鉴别；从“模型懂电路”收紧为对整份未见实现的预测。三项都可以先交理论反例或实现资格报告，不要求第一轮就得到攻击成功。
