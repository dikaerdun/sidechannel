# 02：从“消耗多少能量”转向“怎样响应共同扰动”

> 2026-11-11；理论发散第 2 轮。以下推导可供检查，但未做数值实验、硬件测量或独立复核。文献报告与本次假设分开标明。本文不声称发现新漏洞或证明 PQC 实现可被攻击。

## 核心转向

通常把波形写成“秘密相关信号 + 与秘密无关的噪声”。另一种可能是：

`公开或随机激励 → 秘密状态改变的物理通道 → 目标波形`。

这时秘密不一定增加一段独有的电流脉冲，而可能改变已有扰动的增益、相位、时延或恢复过程。研究对象从一个电流值变成一个条件响应函数。

“状态会影响阻抗”已有实验研究；“自然扰动能否在本项目中充当可用的参考激励”是另一项尚未验证的假设。两者不能合并成一个已知结论。

## T2H-02A：两个各自无信息的通道，联合起来有信息

### 可检查的极简构造

令秘密 S 等概率取 −1、+1，N 是与 S 独立的标准正态变量：

`Y = S·N，R = N。`

由 N 的对称性，Y 在两个秘密下分布完全相同。因此：

`I(S;Y)=0，I(S;R)=0。`

但 N 非零几乎必然成立，观察 Y、R 后可以由 Y/R 确定 S：

`I(S;Y,R)=1 bit。`

这是人为构造的信息协同例子，说明“参考通道单独无法分类秘密”不构成丢弃它的理由。它不证明芯片电路会实现符号翻转，也不声称该数学现象新颖。

加上互相独立的零均值测量噪声：

`Y=S·aN+ε，R=N+η。`

当 a≠0、N 方差非零且各噪声方差有限时，两个秘密下的边缘方差仍相同，而条件协方差为：

`Cov(Y,R | S=s)=s·a·Var(N)。`

两个联合分布因协方差不同而可区分；噪声使完美识别消失。该结论只针对上述模型，不保证有限样本可行。

### 从构造转向可能的物理对应

| 原概念 | 本问题变量 |
|---|---|
| 随机共同驱动 N | 同时影响电路与参考传感器的电源或其他小扰动 |
| 通道选择 S | 存储状态或执行阶段改变的局部小信号响应 |
| Y | 目标电路附近的电流、电压或电磁观测 |
| R | 对同一扰动的独立、同步参考测量 |
| 联合信息 | 状态相关的互相关、交叉相位或条件响应 |

在一个状态可近似保持不变、局部平稳的窗口中，假设：

`Y(ω)=H_s(ω)N(ω)+E(ω)，R(ω)=N(ω)+η(ω)。`

定义交叉谱为 `S_YR=E[Y R*]`。若 E、η 与 N 以及彼此的相应交叉项为零，则：

`S_YR(ω)=H_s(ω)S_N(ω)。`

若两个状态的 H 只有相位差，目标通道功率谱可能相同，而交叉相位不同。**功率谱相同一般不等于整个波形分布相同**；对高斯平稳过程等附加条件才可以作更强推断。

另一种理想例子是 Y(t)=N(t−τ_s)：对平稳过程，孤立观测 Y 的时间平移不改变其分布，但同步参考 N 能揭示时延。真实状态是否产生足够大的时延差，尚不知道。

### 最小鉴别设计，交给验证者

先在可控制状态的测试载体上确认共同激励和同步参考确实存在，比较“目标单通道”“参考单通道”“联合通道”，并使用相同采集批次与未参与模型选择的测试状态/会话。

需要的反证与控制：

- 把参考通道错配到另一条轨迹。如果所谓联合增益不变，优先怀疑标签、会话或处理流程信息。
- 改变同步延迟，检查增益是否随物理相干关系消失；不要把扫描后最好的延迟当作预先确认结果。
- 用与秘密状态无关的测试负载检查探头和仪器串扰。
- 检查参考本身是否含状态泄漏；若含有，结果可能仍有用，但不再是“两个边缘均无信息”的机制。
- 在新的会话与至少两个可控状态族上复核；固定秘密下预测公开输入不等于秘密可辨识性。

**否定条件：**在足够灵敏的测量条件下，联合分布不随状态变化；或全部增益可由会话、同步错误、仪器耦合解释。一次低信噪比失败只否定该条件下的可用性，不证明所有器件均不存在此效应。

### 四个容易偷换的前提

1. 若 R 只是从同一份完整 Y 中确定性计算出来，加入 R 不增加原始信息；可能只改善有限模型的表示能力。
2. 前一段公开计算不是后一段白噪声的同步参考。必须存在跨段相关的激励或足够长的物理记忆。
3. 测到的电源电压可能已被芯片电流反向影响。此时它是反馈系统的一部分，不能直接当作外生输入估计因果传递函数。
4. 实际加密过程通常非平稳。局部频谱模型只是一种近似，不能把整段不同操作拼接后声称测得同一个 H_s。

## T2H-02B：状态的“易响应程度”，可能比状态的静态值更可辨识

**原始直觉：**两个状态静态平均电流相近，但对同一个公开小扰动反应不同。

**跨学科对应：**材料的响应系数 → 电路状态相关的小信号增益/导纳 → 公开扰动与秘密状态存在交互 → 条件响应不同。这里只借用“响应系数”的建模思想，不把数字芯片当作热平衡材料。

候选局部模型：

`I(t) ≈ I₀(s)+G_s·v(t)+C_s·dv(t)/dt。`

这些符号表示可拟合的局部响应项，不自动等于某个唯一晶体管的电导、电容。封装、供电网络、稳压反馈和探头都会影响观察到的系数。

设 m(s,u) 是状态 s、公开激励 u 下的平均观测。对两种状态和两种激励，定义：

`Δ=m(1,1)−m(1,0)−m(0,1)+m(0,0)。`

若旧模型是完全可加的 `m(s,u)=a(s)+b(u)`，则 Δ=0。受控条件下 Δ≠0 排除该可加模型，但**不能单凭它判定交互发生在芯片而非仪器**。

### 为什么值得保留

传统 HW/HD 标量模型常假定读取映射固定；此方向允许映射随一个可说明的状态改变。它可能让“公开活动”成为测量秘密状态的载体。潜在贡献应是具体的新预测、适用条件或更好的模型，而不是重新命名已知阻抗侧信道。

### 鉴别难点

- 不同保持状态要经过不同写入历史；观察到的差异可能是写入瞬态尾迹。
- 等待时长改变既可能消除尾迹，也可能改变温度或功耗管理状态。
- 停钟或门控后的电路不是正常执行中的同一工作点。
- 外部主动激励与自然扰动是不同条件；不能把前者的可行性直接外推给后者。
- 若只改变输入而秘密固定，交互项可能完全由公开计算解释。

**最小设计：**状态、公开激励与准备顺序分别控制；记录等待时长和工作点；在相同测量链中加入独立测试负载。预先规定比较的响应量与带宽。

**否定条件：**状态改变只引入可解释的加性电流偏置，交互项在控制准备历史与仪器非线性后消失。此时应退回静态/动态加性模型，不坚持“响应系数泄漏”的命名。

## T2H-02C：公开活动可以充当内部载波，但必须确认真实耦合路径

**原始直觉：**被视为背景的时钟、公开总线活动或通信载波，可能比秘密操作本身的直接泄漏更容易测量。

物理机制至少有三种，不能混在一起：

1. 秘密相关电流直接叠加在公开波形上：是普通加性泄漏，公开活动只是背景。
2. 秘密状态改变公开波形的幅度、相位或延迟：是条件响应假设。
3. 两个子系统经非线性或反馈耦合产生混合项：需要独立说明耦合位置与阶次。

简单候选模型为：

`Y(t)=P(t)+L_s(t)+α_s P(t)+ε(t)。`

其中 α_s P(t) 是待检验项；仅仅拟合出乘积特征不说明芯片中存在乘法器式耦合。

**旧模型为何遗漏：**只做背景减法的模型可能把 P 及其参数整体当作无关量，没有保留它与状态的相互关系。

**最小鉴别：**在功能等价、时序可核对的条件下改变公开载体，检查状态相关差异是否按预先规定的载体幅度/相位关系改变；同时测量独立负载，排除仪器产生的调制。

**反例：**公开载体改变使程序调度、温度、供电状态一起改变，任何差异都不足以定位到 α_s。若关闭载体后差异不变，也不能继续把它叫作该载体搬运的信息。

**保留条件：**需要同一载体与敏感状态真实共存。现有单通道固定实现文件未证明存在这一条件。

## T2H-02D：校准可能把模型需要的参数一起删掉

此条是测量保存原则，不单独宣称新物理通道。

设原始观测为 W，处理过程得到归一化波形 T(W) 与参数 θ(W)，例如偏置、尺度或时移。只保存 T(W) 可能造成不可逆信息损失；若原始 W 可由二者重建，保存二者可避免这一步的损失。

但若 θ 与文件编号、操作者、采集时间相关，θ 的预测力可能只是数据集混杂。不能把“归一化前更准确”自动解释为秘密改变了物理增益。

应比较的不是哪条曲线最好，而是：

- 参数是否在独立会话和新秘密/状态下仍有条件区分力；
- 加入完整公开输入、设备与会话条件后，剩余关系是否存在；
- 归一化操作是否使用了测试标签或跨越数据划分拟合；
- 原始记录、转换参数和处理版本能否追溯。

**否定条件：**参数的所有增益都由公开输入或采集会话解释，或新会话中消失。

## 本轮认识变化

- 起点：“噪声可能有信息。”
- 改进后：“秘密未必改变噪声源；它可能改变共同噪声到目标观测的响应，而同步参考使该变化可辨识。”
- 关键分歧：参考是外生激励的代理，还是被芯片影响的反馈节点？两种模型的因果解释不同。
- 最强反例：目标与参考都只携带会话指纹，或联合增益由仪器串扰造成。
- 继续保留：联合参考方向具有清楚的数学构造与可否定预测，值得在具备双通道与受控状态的载体上验证。
- 当前状态：四条均为待验证设计；未对现有数据宣布支持。既有单通道分析失败也不能代替此处所需的专门测试。
