# 从对称性破缺 交互路径与集体推断寻找跨层规律

日期：2026-11-14。状态：**构思与验证交接，三个方向均待验证，由用户安排其他研究者开展。**

本轮把已有想法推向三个更大的目标：建立数学对称性到物理差异的对应表；发现能解释连续波形泄漏的交互路径；研究局部读出与整体秘密歧义之间的结构规律。它们深化既有 BOLD-32、08/31、05/06 及研究主线，不另计为新机制，40 条种子计数不变。

## A 用数学对称性寻找电路打破了什么

**大胆命题：算法允许的等价变换，可以成为一组有明确语义的物理诊断工具。** 如果计算含义按已知规则变化，波形却按另一套规则变化，二者的偏离可能暴露算法抽象没有描述的资源、表示或历史。

跨学科对应：物理学中利用对称性及其破缺辨认相互作用 → 密码运算的合法变换 g、代码与电路的实现 I、读出 W → 数学等变性并不保证物理等变性 → 改变表示和改变资源映射，应产生不同的、事前可预测的响应。

这里的“破缺”指实现或观察不保留某个指定变换关系，不预设发生了自发对称破缺或相变。

一个可检查的入口是环 Rq=Zq[X]/(Xⁿ+1)，n 为 2 的幂，q 为奇数。对与 2n 互素的奇数 a，σa(f)=f(Xᵃ) mod (Xⁿ+1) 是环自同构，因此

`σa(fg) = σa(f) σa(g)`。

这提供一组多项式乘法的受控变换：变换输入、执行乘法、逆变换输出，可以恢复原结果。**它只保证该环运算的功能关系。** 不能直接延伸到整个 ML-KEM/ML-DSA 的采样、压缩、编码、检查与协议接口；变换和逆变换的成本与泄漏也必须纳入。

已有[不变量提案](2026-11-13-schedulers-invariants-selection.md)问的是“随机化始终藏不住哪些量”。本次换一个问题：**一组合法变换能否像受控探针一样，把表示效应、位置效应和前驱效应拆开，并预测未见过的实现？**

先构造四种正确配置：原表示/变换表示 × 原资源映射/另一资源映射。公开测试值足以完成第一轮机制诊断；这并不假定观察者在真实攻击时能够任意改变未知密钥。验证者要说明哪些实验控制属于实验室，哪些属于所声称的攻击能力。

旧模型若只使用当前值的汉明重量、前后值的汉明距离和已知活动数，应先给出它在四种配置下的预测。环上的等价不自动意味着这些基线相同：带符号置换会改变机器字与转换活动。只有基线已解释或已匹配后，才能把剩余差别归于新增变量。

**候选新增变量：**同一资源的前驱值、连线与地址位置、归约表示、转换阶段和恢复状态。新模型应冻结这些变量的作用，再预测一个留出变换或留出布局。

**波形区别：**表示机制预测差异跟随变换后的机器表示；位置机制预测差异跟随物理资源；历史机制预测差异随合法调度或间隔变化。仅发现“两条波形不同”没有区分力；任意重新训练一个模型也没有完成迁移预测。

**首先交给验证者：**一个小型正确内核、变换恒等式、四种配置、旧模型预测，以及两个竞争物理解释在留出配置上的分叉预测。无需先实现完整密码系统。

**否定当前版本：**变换不保持目标功能或分布；差异全来自变换开销和简单 HW/HD；所谓位置变化同时更改了未控制的编译行为；或者新增变量不能预测留出配置。

长期产物可以是一套“安全编译的物理等价规则”：哪些程序变换可以保留已知泄漏性质，哪些必须附带新的证明条件。这里提出的是研究目标，尚未得到这套规则。

## B 一个观测点 可以在此前经过多少次关系计算

**大胆命题：风险可能取决于份额之间怎样沿物理路径汇合，而不只取决于份额数、探头数或单个局部模块的非线性次数。** 目标是从连续电路与测量链中找出可核查的组合条件。

跨学科对应：非线性系统的级联与交互项传播 → 份额活动、共享供电状态、恢复状态与测量响应 → 局部低阶作用经过级联后形成覆盖更多份额的有效项 → 改变某条路径或时间间隔，会按模型改变对应联合泄漏。

一个纯逻辑见证：S∈{−1,+1}，Z1、Z2 为独立均匀符号，Z3=S Z1 Z2。任意两个 Zi 的联合分布都与 S 无关。然而两级关系计算

`U=Z1 Z2，Y=U Z3`

给出 Y=S。每一级都是二元乘法，最终却出现三份额关系。**这不是对探测安全定理的反例**：Y 已经是合并多个份额的观察，不能把它当作原模型中只访问一个独立份额的合法探针。这个见证只说明必须追踪观察的来源。

在真实 CMOS 或测量链中，不能把上式的乘法凭空安进去。必须找到可测的状态方程。例如：前两个活动通过某条共享路径产生一个小扰动，该扰动在有记忆的节点上保留，再调制第三段活动的响应。系数需要正确的单位、工作范围和非零证据；连通并不保证作用存在，多个路径还可能抵消。

**PQC 落点：**受保护模乘、份额转换、随机数使用和共享总线之间的边界。优先问“数字逻辑上隔离的东西，在模拟状态里在哪里再次相遇”。目标不是泛称电源噪声，而是提交一个真实节点、两条进入路径和一个读出路径。

旧模型若把每段活动视为无记忆、独立叠加，只能预测局部项。候选模型增加明确的跨段交互项。若假定相关状态按单时间常数 τ 衰减，那么间隔 Δ 的变化应给该项带来模型指定的衰减；只有实际状态方程支持时，才使用 exp(−Δ/τ)，不能事后挑一个曲线解释所有结果。

**最小鉴别：**验证者先给出极小电路/状态模型及观察范围，证明其确实产生目标交互项；随后提出两种保持算法功能的配置，分别保留和切断指定路径，冻结联合统计与时间预测。竞争解释包括仪器自身非线性、时钟对齐、未建模的直接单份额读出及普通线性拖尾。

**否定当前版本：**所需路径不存在或强度不足；差异来自仪器而非所声称的器件节点；切断路径不改变预测项；只改变了总活动；或真实掩码边际化后交互完全消失。

可组合掩码与物理缺陷并非空白领域。robust probing 已经把组合性与物理缺陷放在同一框架内研究。[原始论文摘要](https://eprint.iacr.org/2017/711) 本项的增量必须是：明确哪些连续状态和测量交互已被现有模型覆盖，哪些额外条件需要纳入，再给出可验证的构造或反例。

长期产物可以是带物理语义的交互图检查器：输入实际资源和状态方程，输出一条泄漏关系的来源路径，或在限定观察族内证明某类关系不可能出现。它需要系数与可观察性条件，不能只做图上的可达性判断。这项保留一次偏离当前离线分类主线的理论诊断机会。

## C 局部完全模糊 整体能否只剩极少数秘密候选

**大胆命题：某些实现中，局部分类质量不足以描述风险；真正起作用的是弱观测通过运算约束连接后，整体还剩多少自由度。** 更远的目标是建立“约束结构—可辨识性—求解成本”的对应规律。

跨学科对应：纠错编码与统计物理中的集体约束 → PQC 中间变量、物理观测似然与运算关系 → 多个局部模糊量共同约束同一组未知量 → 保持局部观测条件和总预算时，改变真实关系结构会改变整体歧义。

一个手工可查的小例子：m 个独立均匀秘密位组成 S，图的每条边给出 Ri,j=Si XOR Sj。对任意单独秘密位，单条边的结果没有区分力；但对整个 S，边本身已经携带关系信息，不能说“从零信息创造信息”。

无噪声时，若图有 c 个连通分量，包括孤立点，全部边关系留下 2^c 个相容秘密。原因是每个分量内的相对位确定，但整体翻转仍不变；约束矩阵的秩是 m−c。每个分量再有一个合法绝对锚点，才消除该分量的翻转歧义。

闭环的边不继续增加这项无噪声秩，但其一致性可以用于发现某些观测错误；能否纠正还取决于图、错误分布和译码方法。因此，**连通、冗余与可计算性是三个不同问题**。

这个例子不是 ML-KEM 的泄漏模型。推向 NTT、模乘图或编码型 PQC 时，验证者必须找到真实可观察的关系，明确秘密先验、公开条件、允许的打乱以及每条观测的似然。若噪声共享同一物理来源，就不能未经核查把各局部似然直接相乘。

**新旧预测的区别：**只汇总单点 AUC 或逐系数成功率的评价，可能看不见整体候选集合的变化。结构模型应预测：加入哪类真实关系会消除哪类歧义；增加同质量重复读出、加入错误关系以及加入真正独立约束，应产生不同结果。

**最小鉴别：**先提交一个有限实例，精确列出秘密等价类及允许观察；再比较局部质量、观测数量和计算预算受控的关系配置。物理验证阶段只能使用功能正确的实现，不能为了得到漂亮图结构任意重接密码算法。小实例的精确答案用于区分信息不足、算法求解失败和错误的观测模型。

**否定当前版本：**所需关系不可观察；增益只是重复计权或更多观测；算法使用了测试秘密标签；对称性始终留下任务所需的歧义；或采集与求解总成本没有收益。有限规模的成功率陡变只能称为转折，严格相变需另给规模族及渐近命题。

SASCA 已将实现及其泄漏联系到纠错编码，NTT 的去打乱研究也已经使用图中的联合推断。[编码视角](https://eprint.iacr.org/2018/498)、[NTT 打乱研究](https://eprint.iacr.org/2022/555) 因而“用图”和“用 BP”本身不构成新增贡献。本项要争取的是能迁移到不同正确实现的结构预测，或者告诉防护设计者：在同等资源下，应切断哪些物理关系，才能保留与秘密任务有关的歧义。

## 给验证者的三份首轮交付

| 方向 | 先交什么 | 先尝试推翻什么 | 长期目标 |
|---|---|---|---|
| A 对称性诊断 | 合法变换、四种正确配置、留出预测 | 全部差异是否已被 HW/HD 与变换开销解释 | 有物理条件的安全编译规则 |
| B 交互路径 | 状态方程、真实节点、断开路径的预测 | 所需交互是否不存在、抵消或只来自仪器 | 物理交互的组合条件与检查器 |
| C 集体推断 | 有精确答案的小实例、等价类、观测预算 | 是否只是信息重复或算法偏好 | 结构与秘密歧义的规模规律 |

优先让 A 提供跨实现的预测，让 C 提供可精确审查的理论基线，同时给 B 保留一次小规模机制资格检查。首轮结果可以是反例或不适用结论，不要求验证者证明设想成立。

统一回传四项：数学命题是否成立；代码/RTL 是否存在对应结构；允许的波形是否能观察该结构；它是否改善预先定义的秘密任务。四项分别标注，不把模型意见一致、分类改善或数学恒等式当成物理攻击成功。

现有 Reference-PPM 包不具备 A 的受控变换与资源配置、B 的份额及模拟节点干预、C 的受控关系图族，不能直接完成三项验证。
