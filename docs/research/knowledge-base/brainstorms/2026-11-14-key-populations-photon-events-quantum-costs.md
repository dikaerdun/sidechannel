# 跨密钥物理关系 光子事件与后量子求解成本

日期：2026-11-14。用户希望扩大构思，并自行安排其他人验证。本轮把三个默认前提拿出来检查：密钥是否可以逐把评估，测量是否应该先压成幅度曲线，物理泄漏是否可以只用剩余候选数来评价。以下均为待验证提案，不继承已有实验的支持。

大胆之处在于改变研究对象：从一把秘密变成秘密之间的关系，从平均强度变成事件之间的时间关系，从泄漏量变成利用泄漏所需的完整计算资源。三项承接已有关系、空间观察和求解成本方向，不增加 BOLD 种子编号。光子方向保留一次远期资格诊断。

## A 独立密钥会不会被共享硬件连接成一个关系网络

**最初直觉：换掉密钥，不一定切断旧执行与新执行之间的物理关系。算法上互不相关的秘密，可能在同一个寄存器、存储单元或共享恢复状态中相遇。**

跨学科对应：网络中的相对测量与坐标锚定 → 多把独立秘密对应节点，跨调用资源转换对应边 → 局部关系可能保留绝对取值的歧义，但一个合法已知节点可能消除部分歧义 → 物理清理或资源隔离应改变关系边，而不仅改变某一把密钥的单独分类成绩。

这里要研究真正独立生成的密钥，先与同一主密钥派生会话密钥的情况分开。既有重密钥研究已讨论联合利用多次计算的泄漏；例如 ISAP 研究在指定汉明重量模拟条件下比较联合与独立分析。因此，“跨调用联合更强”本身不是新发现。本提案要追问的是：**没有算法层密钥关系时，物理资源转换是否制造了可观察的关系。**[ISAP 重密钥论文摘要](https://cic.iacr.org/p/2/1/34)

### 一个需要验证者独立检查的有限例子

令 K1、K2、K3 是独立均匀秘密位，观察 E12=K1⊕K2、E23=K2⊕K3。对任一单独的 Ki，两条边仍留下全局翻转的歧义；但它们约束了三个秘密的联合取值。若随后合法获得 K1，两条边便确定 K2、K3。

这个例子不证明实际芯片泄漏异或，也不证明单密钥评估必然漏检。它说明要明确评估的是单个秘密、秘密的联合关系，还是某个节点披露后的其余秘密。对于多个机器字，汉明距离只给位差总数，远弱于逐位异或；不能把这个位级例子直接放大成真实密钥恢复。

### 可落地的物理版本

选择一个自有 PQC 加速器或受控软件内核，让不同测试密钥的运算顺序经过同一资源。真实变量应写成实现确定的机器字 W_i=f(K_i,P_i,R_i)，而非直接写成 K_i；公开输入 P_i、掩码 R_i、位宽及前态都必须保留。候选边可以来自旧字到新字的 HD，也可以来自已经证明存在的恢复状态。是否存在边需要源码、汇编或 RTL 与测量共同确认。

挑战的旧模型是“每次调用给定本次数据后相互独立”。新模型增加的是实际发生的跨调用转换，不是把来自不同执行的波形随意拼接。

**波形预测：**在控制本次操作和公开输入后，紧邻转换窗口的条件响应会随前一个测试秘密对应的机器状态改变；改变执行邻接关系时，候选关系应跟随真正的邻接边。若共享资源被独立分配或确实清理，关系项应按模型减弱。清理本身的波形也要纳入观察，避免只是把关系移到清理阶段。

**最小鉴别：**先交三节点或四节点的精确小模型，说明无锚点和有合法已知节点时分别剩下什么歧义；再提交一份固定实现的资源转换图，以及同资源、隔离资源两种功能正确实现的分叉预测。由用户决定是否进入采集。已知节点的来源必须明确，不能默认某个未知密钥已经泄漏。

**优先寻找的反例：**实际硬件每次都预充到公开常值；合法掩码边际化后关系完全消失；联合收益只来自不同调用的公开输入；所谓恢复状态仅是可由公开活动解释的温度变化。即使有相对关系，也可能始终留下足以保护目标任务的对称性。

可能产物是一种覆盖密钥轮换和多上下文切换的物理隔离判据。它深化 BOLD-20、29 和已有回路关系方向，但把对象扩展到独立秘密的联合安全。

## B 平均发光相同 光子事件的相对时间是否不同

**最初直觉：器件发出的少量光子可能携带位置和时刻。把它们先平均成一张亮度图，可能消掉真正有区别的事件关系。**

跨学科对应：光子计数与带标记点过程 → 发光位置、到达时刻及其联合统计 → 秘密可能影响两个物理区域的相对活动，而各区域平均计数保持不变 → 同次执行内的事件时差分布可能不同，平均亮度图却相同。这不要求光子纠缠或量子相干。

光学侧信道已有实验和建模先例。Waterloo 的学位论文报告了微控制器 SRAM 的光子泄漏研究；ISPD 2025 工作则将发光模型接入物理设计流程，在模拟的时间分辨图上评估 AES，并用实测累计图比较模型。因此，候选增量不能只是“用光看芯片”，而应是**联合事件统计能否发现累计图和单区统计遗漏的秘密关系，以及它是否值得实际光子预算。**[SRAM 光子泄漏论文摘要](https://www.uwspace.uwaterloo.ca/items/856078db-9365-45df-b83d-905321c76755)、[ISPD 2025 作者机构摘要](https://www.athene-center.de/forschung/publikationen/photonic-side-channel-analyzer-enabling-security-a-5434)

### 一个只证明统计可能性的例子

设周期分四个时间格，每次在两个区域各记录一个事件。第一事件的位置 T 均匀取 0、1、2、3；第二事件在秘密 S=0 时位于 T+1 mod 4，在 S=1 时位于 T+2 mod 4。两个区域各自的事件时间均匀，计数也相同，但模周期时差区分两种情况。

这是待独立核对的点过程例子。它没有证明 CMOS 发光率足够高，没有证明掩码电路产生这种关系，也没有把数字操作时刻直接等同于光子到达时刻。真实观察应包含发射概率、光学传播、探测效率和时间抖动。

### 对真实实现增加的要求

PQC 落点可以是两组 NTT 运算单元、两个份额的资源区域或同一归约器前后的物理活动。首先必须指出哪个真实路径让相对活动依赖目标变量；如果只有公共时钟同步，便没有所需秘密信息。新观察记为各区域计数过程 N_i(t)，候选统计是同次执行中的联合到达关系，而非只看平均强度 E[N_i(t)]。

**可观察预测：**控制公开指令、总计数、采集条件和可解释的时钟抖动后，指定区域对的事件时差仍可能区分类别。若因果路径被改变，变化应跟随路径。单纯空间位置、整体强弱或时钟相位已经解释全部差异时，就不支持这个较强版本。

**最小鉴别：**先交一个能产生目标时序关系的合法小电路和光子预算估算，计入同次执行双事件的获得概率。再列出暗计数、探测器死时间、后脉冲、串扰和公共时钟等竞争解释。只有这些条件允许区分预测，才值得请求时间标记光学采集。不能把不同随机掩码执行中的两个事件当作同一次执行的联合事件。

**优先寻找的反例：**真实信号在条件化公共活动后成为秘密无关的独立事件；采集到的关系来自探测器串扰；需要的同时事件在允许曝光和执行预算下不可获得。最后一种情况否定当前测量方案的可行性，不能证明所有光学观察都安全。

这一方向需要具备光学测量能力的合作方；当前 Reference-PPM 功耗包不能直接检验。它承接 BOLD-25 和联合观察方向，保留为远期诊断，不能据此提出采购需求或声称新增攻击通道已成立。

## C 把物理泄漏转换成后量子求解的真实资源账本

**最初直觉：两种泄漏即使留下相同数量的秘密候选，也可能让后续计算处于完全不同的位置。对 PQC，关键还包括约束结构能否被经典或量子算法实际利用。**

跨学科对应：带辅助信息的搜索与计算复杂性 → 从真实波形获得的带误差约束、候选表示和校验程序 → 约束的几何结构、可生成性及访问成本可能改变算法选择 → 相近局部指标的两类观测，可能对应不同的完整求解成本。

侧信道辅助量子密钥搜索已有明确先例。SAC 2017 作者版本将侧信道后的候选枚举组织为可用于量子搜索的批次；2026 年一篇预印本进一步提出含深度预算的评价框架。故本提案不主张首创“侧信道加量子计算”，也不将预印本摘要中的复杂度结论当成已独立核实的定理。[SAC 2017 作者摘要](https://eprint.iacr.org/2017/171)、[2026 年预印本摘要](https://arxiv.org/abs/2610.20537)

更值得做的增量是：**对带模运算、相关软证据和错误标签的 PQC 约束，建立从实际观察到可执行求解器的完整资源模型。**从对称密码的分块后验迁移到 PQC，不能默认各系数独立，不能把高维候选集合免费排序，也不能把经典后验数组视为免费可相干访问的量子存储。

资源至少分别记为：采集次数、经典预处理时间与内存、量子逻辑门数、逻辑深度、逻辑量子比特数、成功概率。若进一步换算物理设备成本，应显式加入纠错假设。不同单位不能直接相加；比较应先固定成功率及预算，或声明成本换算规则。每次相干校验的可逆计算、辅助空间和反计算也必须记账。

**一个可交接的问题：**选择同一个有限格问题或编码问题，给出两种现实上有来源的带噪约束，例如局部系数信息与跨系数关系。先测定它们在有限模型中的实际信息量和候选结构，不预设“信息相同”；若要检验等信息量下的差别，再做明确匹配。比较无泄漏、最佳已知经典利用方式与资源受限量子候选方式，查找结构引起的成本差异。

**这里不会凭空预测一种新波形。**这是连接测量与安全评价的理论方向：物理模型负责预测波形给出什么约束，本模型负责预测这些约束改变哪一项计算成本。它提出的可检验差异是，在固定采集与成功率预算下，完整资源估计可能不同于只报告候选数、单点 AUC 或互信息的判断。

**最小鉴别：**验证者先交一个小型可精确核对的约束实例，写出候选生成和校验接口，再为两类方法逐项记账。理论资源估计可以先行，不需要购买量子设备。只有算法与物理映射均成立，才讨论大规模参数；小实例的优势不能直接外推到标准参数。

**优先寻找的反例：**状态准备或数据访问抹平量子优势；经典求解器已更便宜；优势来自不公平的成功率或预算；使用了目标设备不允许的相干查询；把某个先验上的平均收益当成每一个实例的保证。否定量子增益仍有价值，它能为安全评价删去一个未经支持的乘数。

它深化 BOLD-14 和已有总求解成本方向，增加经典信息接口与量子实现成本之间的约束。PQC 在这里仍可以运行在经典芯片上；测量设备和被测算法不因此变成量子系统。

## 交给验证者的首轮任务

| 方向 | 合适的验证者 | 第一份交付 | 最先寻找的否定证据 |
|---|---|---|---|
| 跨密钥关系 | 掩码与体系结构 关系推断 | 有无合法锚点的小模型 实际资源转换图 隔离干预预测 | 边际化合法随机性后没有跨秘密关系 |
| 光子事件 | 半导体光学 测量统计 | 合法关系电路 点过程观察模型 同次执行光子预算 | 公共活动或探测器效应解释全部联合统计 |
| 求解成本 | PQC 密码分析 量子算法 | 一个有限约束实例 三类方法的接口与完整资源表 | 访问 校验或准备成本使优势消失 |

三项先各交一份短资格分析。它可以是可检验预测，也可以是严谨反例，不要求第一轮就恢复秘密。用户负责安排验证者；本轮没有派发任务。

## 构思如何被补强与修正

- 从“密钥轮换后还可能漏”收窄为“独立秘密之间是否有真实物理边”。保留无锚点时的全局歧义，避免把关系恢复写成绝对秘密恢复。
- 从“换一个传感器”推进为“同一执行的事件关系是否超过单区统计”，同时把光子稀疏性与仪器伪相关作为首要反例。
- 从“量子计算会放大侧信道”改为明确的资源比较。已查到 2017 年直接先例，新增问题放在 PQC 相关约束和非免费接口，而非重复提出量子搜索。

## 来源与阅读范围

本轮阅读下列原始页面的摘要与元数据，未通读或复核正文证明。它们只约束已有先例和本提案的增量，不构成本项目的实测证据，也不代表完成系统新颖性检索。

1. [Grosso 与 Standaert 的 ISAP 重密钥分析](https://cic.iacr.org/p/2/1/34)：指定串行实现和 HW 模拟条件，不能推广为所有重密钥方案失效。
2. [Ebrahimi Sadrabadi 的 SRAM 光子泄漏论文](https://www.uwspace.uwaterloo.ca/items/856078db-9365-45df-b83d-905321c76755)：2023 年学位论文，支持光子观察已有先例，不支持本提案的事件时差机制。
3. [Photonic Side-Channel Analyzer 的作者机构页](https://www.athene-center.de/forschung/publikationen/photonic-side-channel-analyzer-enabling-security-a-5434)：ISPD 2025，区分模拟时间分辨图上的评估与累计图的实测比较。
4. [Montanaro 的 Quantum search with advice](https://arxiv.org/abs/0908.3066)：辅助分布下的搜索问题；摘要中的平均查询收益不能直接变成单实例物理成本。
5. [Martin 等的 Quantum Key Search with Side Channel Advice](https://eprint.iacr.org/2017/171)：页面明确标注 SAC 2017 接受作者版，提供本方向的直接先例。
6. [Kotukh 的 Quantum-Aware Key Rank for Side-Channel Attacks evaluation](https://arxiv.org/abs/2610.20537)：2026-10-14 提交的预印本，所述深度预算及资源结论有待全文审查；不用于本轮作数值安全承诺。
