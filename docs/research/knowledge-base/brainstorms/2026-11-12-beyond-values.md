## 07：把噪声本身当成需要解释的动力学

**最初直觉：平均电流和波动幅度都相同，波动的快慢是否仍然不同？**

跨学科对应：随机过程的生成机制 → 器件陷阱的俘获/释放、状态相关的随机切换 → 内部状态改变转移速率 → 从停留时间与相关性识别差异。

### 一个可检查的数学见证

令 X(t) 为两状态连续时间马尔可夫链，0→1 的速率为 α_s，1→0 的速率为 β_s。取：

\[
\alpha_s=c_s\alpha_0,\qquad \beta_s=c_s\beta_0,
\quad \alpha_0,\beta_0,c_s>0.
\]

在各自平稳初态下，任一时刻的分布都是：

\[
\Pr(X(t)=1\mid s)=\pi=\frac{\alpha_0}{\alpha_0+\beta_0}.
\]

因此所有单时刻统计量都相同；但对于非零时差：

\[
\operatorname{Cov}(X(t),X(t+\tau)\mid s)
=\pi(1-\pi)e^{-c_s(\alpha_0+\beta_0)|\tau|}.
\]

若 c_s 不同，路径分布仍不同。这是手工构造的可辨识性例子，不是实际 CMOS 参数定律，也不假设真实俘获与释放速率恰好同比缩放。

### 真实电路中可能对应什么

器件研究已观察到随机电报噪声的俘获/释放规律与偏置、温度有关。[器件论文摘要](https://snu.elsevierpure.com/en/publications/characterization-of-random-telegraph-noise-in-gate-induced-drain-/)支持这种物理可能性，**没有证明能从完整 PQC 器件上读出秘密**。

候选链条是：秘密相关内部状态 → 局部偏置/活动占空比 → 某个随机过程的速率 → 可观测时间相关性。最有可能先看清的载体可能是小型状态保持单元、可控算术单元或时钟门控后的局部电路；之后再判断 NTT、模约减或秘密操作数驻留是否提供足够长的窗口。

这与此前“共同噪声加同步参考”的区别是：07 研究噪声源自身的条件动力学，不预设一条能测得同一外部扰动的参考通道；也不同于长期不可逆老化。

### 交给验证者的第一步

先判断真实器件的随机过程时间尺度、目标状态驻留时间和仪器带宽是否相容。若中间态只存在极短时间，不能直接套用平稳模型；重复运行也不自动等于把同一状态延长。

资格成立后，比较预先指定的停留时间/相关性模型与均值、方差、普通有色噪声基线。秘密条件在同一器件、不同会话交叉安排；温度、公开活动和仪器状态单独记录。不同器件上的缺陷时间常数可以不同，不要求一组固定频率能通用。

**预测：**区分力随实际状态驻留与相关时间发生可解释变化，而不是只跟随采集日期。**否定该版本：**没有可观测的相关时间差异；差异完全被环境解释；或只有器件身份区分。带宽不够或状态驻留过短时，记录条件缺失与检测上限。

保留理由：它直接挑战“噪声只会把信息冲淡”的简化前提，且与当前单点模乘主线明显不同。

## 08：从“几个份额”追问到“它们在哪里被合在一起”

**最初直觉：数字分析要求做的高阶组合，会不会已经被物理读出链做了一次？**

跨学科对应：非线性系统的混频 → 份额活动在芯片、供电或测量前端相遇 → 出现交叉项 → 原本在联合统计中的差异进入某个更容易测量的量。

### 一个说明阶数不能混用的例子

令 s 为一位秘密、r 为独立均匀掩码，定义两个理想化的中心化活动量：

\[
u=(-1)^r,\qquad v=(-1)^{s\oplus r},\qquad L=au+bv.
\]

则：

\[
E[L\mid s]=0,\qquad E[L^2\mid s]=a^2+b^2+2ab(-1)^s.
\]

若后续读出为 Y=L+γL²+η，且 η 条件均值为零，则：

\[
E[Y\mid s]=\gamma\big(a^2+b^2+2ab(-1)^s\big).
\]

当 γab≠0 时，Y 的均值已经随 s 改变。线性 L 的**完整分布原本就有区别**，因此这里没有创造信息。一个物理采样点已经同时接触两份额，也不能当成只探测了一个份额。

该例只说明逻辑份额数、统计矩阶数、物理观测范围必须分别描述；不能直接搬到模 q 的算术掩码上。真实 ML-KEM/ML-DSA 实现需要按实际表示、份额时序与读出函数重新推导。

### 文献先例迫使我们把问题再向前推

外部放大耦合 EAC 已经研究了测量条件对掩码有效安全阶数的影响，并有 ASIC 结果。因此“外部测量耦合能削弱掩码”应归入已有知识。[EAC 论文与摘要](https://cris.bgu.ac.il/en/publications/an-in-depth-evaluation-of-externally-amplified-coupling-eac-attac-2/)

此外，USENIX Security 2026 的 Injected and Leaked 报告了非线性硬件把低频信号搬移到注入载波的机制；其摘要中的实验证据主要涉及音频、设备功耗和传感信号，不能据此宣布攻破 PQC 掩码。[官方论文页](https://www.usenix.org/conference/usenixsecurity26/presentation/yan-haoran)

值得继续的问题是：在一个具体 PQC 实现中，**联合活动在哪一段混合？混合位于带宽限制和主要噪声之前还是之后？改变份额重叠为何改变可观测关系？**

### 最小鉴别与关键反例

先交回一张观测链图：份额活动、片内耦合、板级供电、探测前端、滤波/采样、数字处理，标出哪些节点有依据、哪些是假设。

在相同功能和明确随机性条件下，分别改变份额相对时序与测量链的一个已校准环节。预测交叉项随真实重叠和相关非线性变化；模型必须考虑物理记忆，不能仅凭指令时间错开就宣布相互隔离。对照应包含高质量原始采样后进行相同数字非线性处理的版本，以判断优势是否只来自后处理。

若原始 L 被无损记录，之后计算 L² 不会超过原始数据的信息。可研究的实际差异来自可取得的带宽、噪声加入位置、量化或被测器件反馈，必须明确其中哪一个成立。

**否定条件：**所需交叉项不存在；差异只由削顶或量程错误造成；或者普通联合泄漏模型已完整解释结果。若效应来自仪器而非芯片，要准确定位，不能将其误报为算法或片内机制。

保留理由：有直接的既有物理先例，适合形成针对 PQC 的观测链审计；本批没有确认其新颖性或可利用程度。

## 09：看系统如何补偿，可能比看它剩下多少误差更有用

**最初直觉：受控输出很稳定时，为维持稳定所付出的动作是否仍有结构？**

跨学科对应：控制理论的扰动抑制 → 电压/频率/时钟控制器 → 内部活动驱动补偿 → 从执行器轨迹观察负载。

### 一个最小的闭环模型

在一个稳定、局部线性的标量负反馈模型中，设 d 是输入等效的内部负载扰动，G 是被控对象，C 是控制器，y 是受控量偏差，u 是输入等效的补偿动作：

\[
y=G(d+u),\quad u=-Cy,
\]

从而在该模型有效的频率范围内：

\[
y=\frac{G}{1+GC}d,\qquad u=-\frac{CG}{1+GC}d.
\]

在稳定闭环的高增益频段，u 可以近似 −d，而 y 被抑制。因此只审计 y 的波动，可能漏看 u。但控制动作必须实际可观测，d 也必须具有秘密相关结构；控制器不能把独立于秘密的负载变成秘密信息。

### 如何落实到 PQC

候选观测包括稳压器的调节活动、频率变化、相位修正或可公开观察的吞吐变化。先确认具体平台存在对应控制环，不能给没有这些机制的微控制器强加一个隐形控制器。

Hertzbleed 及其后续研究已经展示数据相关功耗经频率机制传到时序，因此这种跨物理量传递本身已有先例。[作者项目页](https://www.hertzbleed.com/)

本方向进一步研究：**当平均功耗和总运行时间接近时，NTT/模约减等阶段的负载时间组织，是否在控制器的记忆、恢复时间或执行器轨迹中留下可重复区别？** 这里不假设控制环有能力分辨每个系数。若它只能保留公开阶段信息，就不能推成秘密恢复。

### 最小鉴别与关键反例

第一份产物应是控制环框图与时间尺度对照，说明 u 可以从哪里观察，哪些参数有器件资料依据。然后用受控测试载体比较两种已知控制策略，匹配公开工作量与运行环境，分别记录 y 和候选 u。秘密与会话需要交叉安排。

**预测：**响应的频段或恢复时间应随控制环参数按模型改变；公开负载校准得到的传递关系应能预测未参与拟合的条件。只看到“换设置后泄漏变大”不足以证明控制器机制。

**否定条件：**没有可观察执行器量；补偿只反映公开工作量或温度；调节机制的实际带宽排除了假设中的时间结构；或改变控制策略的效应能由普通频率/幅度缩放完整解释。

保留理由：把“被稳定住的输出”和“用于稳定的动作”一并纳入安全边界。它不是所有反馈系统必然泄漏的定理，也不推出所有恒定时间 PQC 实现都存在此通道。

## 10：把“通常泄漏很少”与“偶尔暴露很多”分别建模

- **跨学科对应：**可靠性中的稀有模式、混合分布 → 执行器或保护电路偶尔进入不同状态 → 泄漏通道切换 → 少数窗口提供高置信度信息。
- **遗漏与预测：**模型 p(y|s)=(1−p)P₀(y)+pQ_s(y)，其中 P₀ 与秘密无关。即使 Q_s 的均值、方差相同，其分布或路径仍可不同；只看低阶平均可能遗漏。若每次模式事件独立且概率为 p，N 次执行至少遇到一次的概率是 1−(1−p)^N；这只描述事件机会，不是密钥恢复成功率。
- **PQC 候选：**保护状态切换、特定随机资源碰撞或控制器模式。必须找到真实状态标记，不能把普通 ML-DSA 拒绝次数换名当作本方向。
- **最小鉴别：**先冻结不使用测试秘密真值的事件识别规则，报告全部执行的模式频率、条件性能和总成本；保持跨会话确认。若无法观察事件，不能假装已知道何时使用 Q_s。
- **否定条件：**所谓稀有信息只由事后选峰、采集批次、删掉失败样本或公开流程解释。需要独立事件预算，而不是只展示几个漂亮波形。

## 11：从“翻转了几位”走到“哪些路径先汇合”

- **跨学科对应：**时序电路中的传播竞争 → 路径到达时刻与汇合点 → 端点相同的操作仍产生不同脉冲持续时间 → 预期波形随相对时延改变。
- **遗漏与预测：**架构级指令、结果 HW/HD 与总周期相近时，乘法、约减或转换电路的内部波形仍可能依赖数据。重点预测内部脉冲的时间结构，不把架构端点相同误说成所有门级活动相同。
- **最小鉴别：**从有真实时延信息的门级实现中识别候选汇合路径，提出改变相对延迟而保持功能的对照，预测哪段波形如何移动或消失；验证者先检查是否违反设计时序。没有网表/映射时保持机制假设。
- **否定条件：**差异可由普通转换计数、资源复用或全局时移解释；候选路径在目标实现中不存在。毛刺与转换泄漏已有模型，本方向的价值需落实为具体 PQC 电路的新预测，不能重新命名既有结论。

## 12：把编码型秘密视为影响传播的结构

- **跨学科对应：**网络辨识与成对响应 → 迭代译码中的校验连接、阈值与更新过程 → 两个扰动共同作用时出现非加性 → 从响应关系约束隐藏结构。
- **候选观测：**按迭代组织的活动量、可靠识别的更新关系或粗粒度轨迹；不是默认攻击者能读取全部综合征、错误位置或秘密校验矩阵。
- **数学入口：**在能够定义合法扰动的测试模型里，研究 R(i,j)=m(i,j)−m(i)−m(j)+m(0)，其中 m 是预定的可观测统计量。先判断它提供的关系是否超过各自响应、已知综合征重量和公开信息。
- **第一个硬问题：**真实公开输入是否能产生所需内部扰动？若只能在知道秘密后设置内部状态，结果属于仪器化研究，不能称为可实施攻击。QC-MDPC、BIKE、HQC、Classic McEliece 的译码结构不同，不能因都属于编码型就互相套用。
- **先例与边界：**QC-MDPC 的距离谱、综合征重量与时序攻击已有研究，而且早已不限于失败样本。[PQCrypto 2018 原始摘要](https://eprint.iacr.org/2018/256)因此应作为强基线。新的待答问题是可观测的多步/成对响应是否增加了计算上可利用的约束。
- **否定条件：**关系只反映公开码结构；大量秘密在允许观察下等价；收益只来自已有重量泄漏；或实际输入无法实现所需扰动。不用完整公钥下的无界互信息替代有限算力下的恢复收益。

| 模拟非线性可能消掉掩码 | EAC 已有先例；收紧为混合位置、带宽和噪声顺序，区分三种“阶数” | 具体 PQC 实现中是否有未被基线解释的增量 |
| 稳定输出意味着信息被隐藏 | 闭环方程提示执行器也是观测对象；Hertzbleed 已有物理量转换先例 | 补偿轨迹的可见性与秘密相关性 |
| 只要足够多采样就能见到稀有泄漏 | 遇到事件不等于恢复秘密，必须记录筛选规则与全部成本 | 可复现模式及其条件信息 |
| 模型只需数翻转 | 端点统计不能确定所有传播时延，需真实路径映射 | 可预测的路径干预效果 |
| 从关系可恢复编码型结构 | 距离谱/重量攻击已成熟；必须先检查输入可达性和关系增量 | 超过已有强基线的计算收益 |

以上属于主 Codex 的自审与来源核查修订，不构成双方讨论或独立核验。数学见证也应由验证者独立检查。
