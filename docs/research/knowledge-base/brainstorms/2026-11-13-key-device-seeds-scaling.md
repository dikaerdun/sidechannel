# 密钥与器件的交互 种子展开与防护的规模边界

日期：2026-11-13。第十批，BOLD-20261113-34 至 36。三项均为待验证提案，交由用户安排其他研究者核查。目标是把问题扩大到密钥总体、完整秘密生命周期和防护规模；已有 33 条种子及 RP-A 至 C 继续保留。编号用于追踪提案，不意味着发现了三个独立新机制。

这次最想挑战的三个直觉是：同一实现对不同合法密钥的风险大致相同；高维中间状态应当逐项研究；提高逻辑防护阶数足以预言真实硬件的收益。它们都可能在明确条件下成立，也都值得寻找有解释力的反例。

| 提案 | 大胆命题 | 需要新增的变量 | 预期可观察差异 |
|---|---|---|---|
| BOLD-20261113-34 | 某些密钥只在某些器件或资源映射上容易泄漏 | 密钥诱导的活动结构与器件读出结构的交互 | 同一批合法密钥的风险排序，随已知资源映射发生可预测交叉 |
| BOLD-20261113-35 | 高维 PQC 实现的主要风险可能集中在短种子的展开与重建阶段 | 秘密来源、展开次数、驻留时间、缓存和清理策略 | 改变同一密钥的存储策略后，风险随预言的阶段迁移 |
| BOLD-20261113-36 | 增加掩码份额的收益可能受整个物理系统的资源配置限制 | 随机供给、共享资源、空间隔离、运行时间和观测范围 | 部件级收益与整机收益出现有机制依据的差异；隔离指定资源改变该差异 |

## 34 寻找密钥与器件共同决定的风险结构

**最初直觉：可能不存在一张脱离芯片的“容易泄漏的密钥名单”。一把密钥的活动模式，只有碰上某种资源布局和测量响应，才特别容易被看清。**

跨学科对应：交互效应与模式匹配 → 密钥 K 诱导的运算活动、器件 D 的资源与响应 → 两者共同决定泄漏可用性 → 仅用密钥平均难度与器件平均质量预测不了风险排序。

具体候选链条是：合法密钥的系数及变换域结构 → 在固定公开输入分布下的有符号表示、翻转位置或路径重叠 → 固定资源映射 → 空间与时间读出。必须逐段绑定实际代码和电路；“共振”只能在确有振荡模态时使用，不能拿来代替这条映射。

令 R(K,D) 表示在冻结的观察、剖析、输入选择和计算预算下，指定评估程序对目标秘密函数的推断表现。它是该评估程序的表现，不是最优攻击风险。简单基线为：

\[
R(K,D)=a(K)+b(D).
\]

候选增加交互项 h(K,D)。一个最小的手工诊断是比较两把密钥和两种器件条件：

\[
\Delta=R(K_1,D_1)-R(K_1,D_2)-R(K_2,D_1)+R(K_2,D_2).
\]

可分加性模型预测 Δ=0；非零 Δ 只是交互证据，不自动证明某个物理机制。更强的目标是用明确的活动与资源描述，事先预测未见密钥和未见器件上的变化方向，尤其是风险排序交叉。

**波形预测：**匹配平均活动、公开工作量和测量质量后，预定窗口或空间模式中的条件区分度仍依赖“哪把密钥放在哪种资源映射上”。改变映射后，变化应跟随所提出的活动结构，而非采集顺序。器件总体增益变化是必须比较的简单基线。

**交给验证者的最小任务：**先提出一个能从固定实现计算的活动描述、一个独立校准的资源描述，以及风险交叉的预测，再设计密钥与器件的交叉安排。密钥必须来自合法生成过程；同一密钥在各条件重复，使用新鲜合法随机性。公开密钥、密文和允许输出进入公共信息基线；直接识别公钥或给不同密钥编号分类，不算秘密推断收益。

**否定当前版本：**风险差异被平均信噪比、公开输入、器件身份或已有局部模型解释；交互不能在留出组合重现；资源变换没有预定影响。只能发现个别坏批次，则转为测量问题。阴性结果须带检测能力，不能外推全部合法密钥。

最有价值的长期产物是“密钥分布上的实现风险”，连同未测密钥的外推边界。更远可以研究能否改变实现以压平风险尾部。若想通过丢弃部分生成密钥来降低风险，则会改变密钥分布，需要单独证明密码学后果；本提案不据此修改生成算法。

与旧方向的增量：BOLD-10 关注稀有运行状态，BOLD-21 关注器件提供的互补观察；本项要求在合法密钥总体与器件条件之间寻找可迁移的交互规律。已有 Kyber 研究表明输入与实现选择影响泄漏利用，尚不能据此认定本项的密钥—器件规律存在。[作者机构摘要](https://research.birmingham.ac.uk/en/publications/magnifying-side-channel-leakage-of-lattice-based-cryptosystems-wi/)

## 35 沿秘密的来源寻找关键暴露阶段

**最初直觉：高维密码计算会生成很多系数和状态，但它们的秘密来源可能很集中。最值得观察的时刻，可能发生在进入 NTT 或模乘主循环之前。**

跨学科对应：数据溯源与计算图中的支配关系 → 种子、展开状态和派生密钥 → 少数阶段连接大量后续秘密计算 → 改变这些阶段的执行频率，应系统地改变完整生命周期中的泄漏机会。

这是一个具体的实现选择：NIST 的 PQC FAQ 允许 ML-KEM 和 ML-DSA 使用密钥生成种子作为私钥的替代格式，并允许相应解封装或签名接口接收种子，要求组合实现产生与正确展开私钥时一致的输出。它没有规定每次调用都重新展开，也没有给出侧信道等价保证。[NIST FAQ，相关条目修订于 2026-06-16](https://csrc.nist.gov/Projects/Post-Quantum-Cryptography/faqs)

可用一个抽象描述：秘密来源 S 经过展开得到 K=Expand(S)，后续状态为 Zᵢ=Fᵢ(K,P,R)，其中 P 是公开上下文，R 是明确区分来源的新鲜随机性。Z 的维数增大，不表示目标秘密的独立熵随之增大；但**短种子也不表示从局部泄漏反求种子容易**。安全伪随机展开可能使这种反求极其困难。

因此强版本应研究三个政策的完整成本与风险：保存展开密钥；保存种子并按指定策略重建；缓存一部分派生状态。关键变量包括每个生命周期的展开次数、实际秘密驻留、总调用次数、刷新与清理活动，以及哪些阶段在观察范围内。

**波形预测：**如果主要风险来自重建阶段，那么随明确的重建频率变化，相应阶段的联合观察价值应增加；缓存策略应把观测差异移到驻留、搬运或清理阶段。若某项收益只来自多看了更长时间，在匹配总观察时间后可能消失。重复展开也不自动提供独立样本，跨调用相关性要纳入模型。

**交给验证者的最小任务：**为一个固定 ML-KEM 或 ML-DSA 实现画出秘密来源和生命周期图，并提出两种功能正确的存储政策。先提交“哪一阶段会改变、变化方向是什么、怎样核查同一秘密”的预测，再考虑测量。分别报告启动暴露、单次业务成本和多次调用的累计成本；攻击者若看不到启动阶段，就不能把该阶段计入其能力。

若使用“关键割集”的语言，必须列出覆盖的全部秘密来源。随机带、已有秘密寄存器、DMA 或其他旁路会破坏图的前提。静态依赖割集不能直接当成物理信息容量界，更不能推出保护几个节点就保护了全部后续计算。

**否定当前版本：**所选实现没有假设的重复展开；阶段观测只能说明公开流程；展开阶段没有比普通算术阶段更高的同预算利用价值；或者风险迁移完全由总暴露时间解释。即使某阶段泄漏派生量，也应分别判断能否恢复原种子、某个功能等价密钥或仅一个局部量。

长期目标是把保护资源按“秘密在哪里产生、复制、重建和销毁”配置，给出可检查的完整生命周期比较。它承接 BOLD-16 的清理与 BOLD-20 的跨调用状态，新增的是种子格式与重建政策这一可控实现轴。现有 Reference-PPM 波形不覆盖这段生命周期。

## 36 寻找防护阶数在真实系统中的收益边界

**最初直觉：增加逻辑份额时，我们也增加了随机位搬运、资源连接、执行时间和布局压力。整个系统可能因此改变了观察者接触份额的方式。**

跨学科对应：规模分析与受约束设计 → 份额数、随机供给和物理连接共同增长 → 逻辑保证的前提不一定在不同规模间保持 → 整机评估可能呈现与孤立部件不同的收益曲线。

NIST 对掩码的说明区分了限制数量的逻辑线探测与真实聚合功耗观察，强调物理效果依赖实现。[NIST 技术说明](https://csrc.nist.gov/projects/masked-circuits) 安全随机数生成的成本也已有专门研究，其作者同时指出高效生成可以支持并行化；这不能被歪曲成“随机供给必然抵消掩码收益”。[随机性生成论文摘要](https://eprint.iacr.org/2023/1134)

候选机制必须具体：例如，更多份额迫使同一算术资源更密集复用，或改变了共享供电路径的时间重叠。物理端口的一份观测可能混合多个逻辑位置；其范围应从布局、时序与读出函数导出。随机队列耗尽、总面积增长或电流变大本身，都不足以证明秘密相关泄漏。

定义 R(d,C,O) 为掩码阶数 d、实际资源配置 C、观察与计算预算 O 下，冻结评估程序的表现。**不预设 R 随 d 必然下降或上升。** 提案要找的是：哪种具体资源变化能使收益偏离基线，哪些隔离条件可以恢复预期收益。

需要分开两类比较。一类允许资源随阶数增长，核查相应的物理观察边界；另一类在固定面积、随机吞吐或延迟预算内比较可实现的设计。固定预算里某个高阶设计不存在，是可实现性结果，不能编造其泄漏性能，也不能讨论有限资源下任意大的阶数。

**波形预测：**在所提出的共享资源成为限制因素时，整机的预定联合统计或跨调用关系出现可解释变化；改用隔离资源、调整时序重叠或改变布局后，变化按机制预测减弱。孤立算术部件与包含随机供给、搬运和清理的整机评估，可能给出不同收益。单纯方差增加或 t 值变大不能代表成功推断更多秘密。

**交给验证者的最小任务：**选择一个小型、已有逻辑安全说明的模块族，提交两个以上可实现阶数的资源表、具体共享节点与观察边界，给出能区分“局部随机泄漏”与“指定资源交互”的预测。先核查结构，再决定是否做硬件评估。总采集时间、剖析成本、运行次数和计算预算一并列出，不能只比较每条轨迹的指标。

**否定当前版本：**所需交互不存在；已有联合观察模型完全解释结果；风险变化来自不正确的掩码实现或不合格的随机源；在预定范围内没有可重现的收益偏离。有限阶数的正反结果都不能直接变成所有高阶防护的结论。

长期目标可以很大胆：建立“什么资源条件支持什么物理保证”的可证边界，甚至寻找特定成本与观察模型下的不可行性结果。任何下界都必须写出读出模型与噪声假设；不能从热耗散、总功耗或 Landauer 原理直接推出秘密泄漏下界。

本项继承 BOLD-02、08、27、30 的供给、混合、噪声和组合条件，新增的是随防护规模变化的资源模型与可实现性边界。它是本批偏离当前局部算术数据主线的长期探索项。

三项可以分别交给统计与电路研究者、PQC 实现研究者、掩码与硬件设计研究者。验证者先回传最强反例或最小资格证明；数学有效、实现对应、物理可见、最终密码任务收益分别判定。大模型适合生成竞争机制和下一次能区分它们的干预，不用其置信语气充当证据。

自审把三个直觉收紧了：从“弱密钥”改为依赖评估预算的密钥—器件交互；从“短种子所以更容易”改为完整生命周期中不同阶段的同预算比较；从“高阶可能更差”改为有明确资源条件和反例的规模问题。尚无独立核验意见或实验反馈，也未完成新颖性检索。
