# 安全容差 保密物理核验与诱饵执行

日期：2026-11-14。供用户安排其他研究者验证。三个研究目标分别改变安全保证的表达方式、波形的用途和防护生成观察的方式。均为待验证提案；不把已有鲁棒掩码、侧信道监测或诱饵思想计为原创，也不增加既有 BOLD 种子编号。

## 六个值得保留的问题

| 问题 | 需要增加的研究对象 | 第一个可交付成果 |
|---|---|---|
| 安全证明能否附带物理容差 | 模型偏差与观察预算共同决定的安全退化 | 一个有单位和适用域的扰动模型及上界或反例 |
| 波形能否帮助核验计算而保护秘密 | 正确性证据与秘密观察的联合分布 | 有限作弊族下的核验与隐私命题 |
| 能否主动生成多个难以区分的执行解释 | 真实路径、诱饵路径、结果选择与公开验证 | 包含选择阶段和公开信息的完整观察游戏 |
| 同一数学算法换物理载体后 安全条件如何翻译 | CMOS、存储内计算等实现的状态与读出映射 | 两种具体载体的共同抽象及一个失效映射 |
| 安全保证能否随器件老化而更新 | 参数漂移、校准历史及证书有效域 | 能预测留出工作条件的失效边界 |
| 能否找到防护不可同时满足的资源要求 | 能量、延迟、随机性、面积与允许观察 | 有限实现族的可行解或不可行证书 |

后三项保留为长期问题，分别延伸跨实现模型、器件历史与资源下界方向。本轮只展开前三项；第二项明显偏离现有局部算术读数路线，保留一次小规模理论诊断机会。

## A 让安全保证具有可测的物理容差

**最初直觉：**工程系统有工作范围，侧信道保证是否也能说明，某一项耦合、时序偏差或随机源相关性增大到哪里，已有保证开始退化？

跨学科对应：鲁棒控制的模型不确定性 → 实现参数 θ、允许观察族及总预算 B → θ 在已定义集合内变化时，指定秘密任务的优势受控 → 模型提前预测改变布局、等待时间或器件条件后的安全退化。这里的“容差”必须对应可测变量，不能仅把观察分布之间的距离重新命名成硬件参数。

**一个手算见证，待独立核对：**设秘密位 S 取 ±1，新鲜随机份额 A 均匀取 ±1，另一份额为 Bₛ=S·A。单独观察 A 与 S 无关。若某个超出原观察契约的混合读出是

`Y = A + ε A Bₛ + Z = A + ε S + Z`，

其中 Z 为独立零均值噪声，那么条件均值相差 2ε。若每次 A 和 Z 独立刷新且噪声方差为 σ²，样本均值的信号噪声尺度涉及 `N ε² / (1 + σ²)`。这只是该玩具模型下均值检验的尺度，既不是最优攻击复杂度，也不是测量结论。关键在于：小的单次偏差可随观察预算累积。

该见证并未推翻掩码证明。若证明已经覆盖这样的联合读出，安全实现就应排除这个秘密相关项。实际研究必须找到代码、布局或电路支持的耦合来源，不能凭一个乘积项宣称 CMOS 必然实现了它。

**PQC 入口：**选一个固定模乘或算术到布尔转换内核，找出旧模型允许的读出、刷新规则和真实资源映射。提出两种不同的物理偏差，要求它们对留出布局或工作点产生不同预测。

**补强后的目标：**给出“实现条件—扰动集合—完整观察预算—任务优势”的可检查联系。在每个自适应历史上均有条件分布距离界 δ 时，用逐步替换得到随调用次数累积的界只是基础记账；真正困难的是从物理条件推出 δ，并处理状态依赖。对公钥密码还须使用计算受限的安全游戏，不能用无计算限制的密钥熵直接代替安全性。

**最小鉴别与否定条件：**验证者先交一个真实扰动参数、一对竞争读出模型，以及未测实现的预测。若参数变化不能解释留出响应，或只能事后调整参数，当前映射失败；若界在可用观察预算下始终平凡，当前安全证书没有实际用途。

已有 [robust probing](https://eprint.iacr.org/2017/711) 联合处理物理缺陷与可组合性；[Robust but Relaxed Probing Model](https://casa.rub.de/en/research/publications/detail/robust-but-relaxed-probing-model)进一步细化实际发生的毛刺。待研究增量是可测扰动到定量任务界的桥梁，而非首次考虑非理想硬件。

## B 让物理观察核验计算并保护秘密

**最初直觉：**同一段波形能否回答“规定的计算确实发生了”，却不给观察者更多计算秘密的能力？

跨学科对应：零知识中的可验证性与可模拟性 → 允许公开的信息 P、待核验执行性质 C、完整观察 Y → 正确执行可被核验，而 Y 可由 P 高效模拟 → 在声明的作弊族内识别违约执行，同时不额外泄露秘密。这是候选目标，尚不是一个物理零知识协议。

先把 C 限定得很小，例如某个模运算内核是否执行了规定的步骤。若目标升级为“每个结果都正确”或“随机数必然新鲜独立”，必须重新提供论证。识别代码路径不能自动证明算术正确，更不能单凭有限波形证明随机源独立性。

**PQC 入口：**由验证者指定一个掩码模乘或刷新模块，先列出跳过操作、重复旧操作及错误数据路径等有限不合规实现。明确观察者可见的端口、带宽、公共挑战、结果及时间范围；秘密输出不能被悄悄列入 P。

**补强后的目标：**同时提交两项保证：诚实执行的接受率与作弊执行的误接受上界；同一观察预算下，完整原始波形相对允许公开信息的秘密任务增量。保护一组筛选后的特征不够，攻击者也能使用其他窗口、端口和核验动作的痕迹。

最危险的反例是“用另一段计算制造相同波形”。因此需要界定作弊者能否替换硬件、重放信号或控制外部发射源，并说明挑战的新鲜性和物理绑定。另加一段公开心跳若与实际运算无绑定，不能成为计算证据。可信监测器自身也不能偷偷承担全部计算后再把结果当作波形证明。

**最小鉴别：**先在一个有限实现族中寻找满足两项要求的构造，或给出一对输出及全部允许观察都无法区分、但 C 不同的执行。后一结果可直接排除该观察模型下的核验目标，不必先采集大数据。

**否定条件：**不合规执行可重放或仿造可接受观察；检测依赖秘密标签；加入联合观察后出现额外秘密区分；或核验器只识别了编译版本和采集批次。

[Zeus 的原始论文摘要](https://arxiv.org/abs/1708.09099)展示用电磁辐射监测 PLC 控制流的先例，页面列为 CCS 2017。它不提供上述秘密保护或任意计算正确性保证。候选贡献是二者的联合条件、权衡或不可能性结果。

## C 让防护生成具有竞争力的物理解释

**最初直觉：**防护能否主动产生结构化执行，使观察者即使建立了准确的物理模型，也难以判断哪部分对应敏感计算？

跨学科对应：诱饵分布与统计实验设计 → 真实轨迹、诱饵轨迹、物理混合、结果选择和公开验证 → 多种执行解释在完整观察下仍难以有效区分 → 最佳可用推断的任务增益下降，而非只让某个神经网络分类错误。

**首先承认一个强反例：**对有公开验证条件的密码任务，少量“像真的假密钥”可能被逐一排除。增加 M 个诱饵不自动增加 log₂M 位安全性，甚至只增加 M 次廉价检查。真实计算和诱饵共用器件时，最终选择正确结果的过程又可能泄露路径身份。

**补强后的目标：**研究对象应是完整观察通道的改变。诱饵生成、资源调度、输出选择、随机源和清理全部纳入成本与转录；观察者知道防护设计，并可使用公钥、公开输入输出及多次执行。候选方案必须说明它降低了什么任务的有效优势，或增加了什么可量化的求解成本。

**PQC 入口：**从极小模算术内核开始，先比较真实计算加结构化诱饵与同能量、同延迟预算的普通随机活动。完整系统随后还须面对公钥一致性检查。不能以小内核的多个解释推断 ML-KEM 或 ML-DSA 的长期密钥安全。

**最小鉴别：**验证者先写出有限通道及其全部允许辅助信息，比较加入诱饵前后的最优判别，而不是先训练大模型。再检查真实资源映射能否实现该通道。若效果来自禁止观察选择阶段、限制攻击者知道防护结构，或忽略跨调用关联，当前方案不合格。

**否定条件：**公开验证快速排除诱饵；结果选择暴露真实路径；换一个读出或推断方法增益便消失；或在相同成本下与普通噪声、掩码、打乱相比没有额外作用。证明某类诱饵在特定公开验证条件下无效，同样是可交付成果。

[Honey Encryption 作者页面](https://pages.cs.wisc.edu/~rist/papers/honeyenc.html)提供错误密钥产生合理假明文的概念先例；其消息分布和辅助信息条件不能直接搬到公钥侧信道。这里尚未完成对硬件诱饵和结构化隐藏工作的系统新颖性核查。

## 交给验证者的首轮任务

| 方向 | 适合的验证者 | 首轮只需交付 |
|---|---|---|
| A 安全容差 | 掩码理论与电路测量 | 一个真实偏差参数、一个预算相关界和一个留出预测，或反例 |
| B 保密物理核验 | 密码学与程序验证 | 明确性质与作弊族，一项联合构造或观察不可区分反例 |
| C 诱饵执行 | 信息论与实现研究 | 含公开验证和结果选择的有限通道比较，或不可能性结果 |

大模型用于提出构造、列竞争解释和检查假设是否遗漏；验证者独立核对推导与实现资格，再决定是否开展测量。三项先交不同的理论或实现产物，不共享测试结果来调节各自的成功条件。用户安排验证，本轮没有派发任务或启动实验。

## 构思修订与证据范围

A 从“安全有容差”收紧为可测扰动、状态依赖及预算累计；B 从“波形证明正确”收紧为有限性质、作弊能力与全观察隐私；C 从“制造假答案”收紧为公开验证条件下的通道设计。这些反例使研究目标更清楚，也可能直接终止某个版本。
