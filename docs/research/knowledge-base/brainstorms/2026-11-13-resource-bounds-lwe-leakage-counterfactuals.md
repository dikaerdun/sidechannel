# 安全资源下界 难问题泄漏与跨实现预测

日期：2026-11-13。状态：待验证。验证由用户安排其他研究者承担。

把研究目标再推进一步：能否证明某类物理安全需要付出哪些资源；能否设计一个允许泄漏、但泄漏内容仍受密码困难性约束的实现；能否让物理解释提前预测另一份正确实现的波形变化。三项分别深化 BOLD-36、RP-C 和原型 M，不增加 BOLD 种子计数，也不声称已找到新机制。

| 研究问题 | 挑战的前提 | 首份可判定产物 |
|---|---|---|
| 安全资源下界 | 局部模块安全便能在给定资源内组成安全实现 | 一个有限资源模型中的下界证明或反例调度 |
| 难问题泄漏 | 有用的防护目标只能是让可见信号不依赖秘密 | 一个允许泄漏接口、条件安全游戏及完整执行反例 |
| 跨实现预测 | 拟合当前波形便足以说明机制 | 两个竞争机制对未测实现的不同预测 |

## 安全实现有没有必须支付的资源成本

**直觉：算法的依赖图可能迫使数据跨越某些物理边界。真正需要保护的对象，可能包括不可省略的搬运、重用与刷新。** 如果只审计孤立算术模块，就可能漏掉实现组合所需的代价。

跨学科对应：I/O 复杂度中的红蓝石子游戏 → PQC 运算图、有限寄存器及存储搬运 → 数据依赖限制可选调度 → 某些安全约束只能通过额外存储、刷新或时间满足。Hong 与 Kung 的模型已经研究计算图和存储容量如何约束 I/O；它没有给出秘密泄漏下界，不能直接把 FFT 的结论改名为安全 NTT 定理。[原论文](https://www.eecs.harvard.edu/~htk/publication/1981-stoc-hong-kung.pdf)

一个具体的起点是固定的小型掩码蝶形计算图。除运算依赖外，给每个状态标明份额身份、实际机器字、寄存器位置及前驱；给每次写入、搬运、清理、重算和随机刷新规定成本。观察模型另行规定能看到哪些转换、一次可联合观察多少位置、跨调用保留多久，以及噪声分布。

最简单的风险见证是两个布尔份额 a=r、b=r XOR s：若某次实际转换的读出确实等于 HD(a,b)，它就等于 HW(s)。这个恒等式只说明某种复用为何危险，既不是新发现，也不说明这种复用不可避免。加入公共预充电、独立存储或重新分享，可能就构成反例；必须把这些操作及其全轨迹观察计入模型。

**大胆目标：对明确限定的实现族，找到资源预算低于某条边界时无法同时满足的功能和观察约束。** 第一阶段可以只得到“避免某种转换需要多少额外成本”。若要进一步称为泄漏下界，必须证明这些转换在指定噪声、观察预算和秘密分布下产生可区分性。搬运次数多、功耗高和泄漏更多之间没有自动推论。

可以先定义可行性问题：是否存在功能正确的调度，使寄存器预算 S、随机性预算 R 和周期预算 T 均满足限制，同时所有允许观察的秘密区分优势不超过 ε？秘密区分须针对允许公开行为相同的执行对，不能把功能本来允许输出的信息当成额外泄漏。有限模型中的无解证书比泛泛声称“高阶掩码有极限”更有研究价值。若允许重算、特殊指令、外部存储或不同表示，都必须纳入实现族或明确排除。

**波形预测：**假如候选瓶颈是互补份额的指定资源转换，调整调度后，相应条件信号应跟随那些转换的位置移动；引入模型要求的隔离或刷新后，该读出应按预测改变。只看到总能量上升不支持这个机制。

**交给验证者：**先对一个极小计算图提交资源规则、观察规则和全部允许调度的论证。随后给出瓶颈两侧各一个正确实现及波形预测。小模型可先用严格证明或穷举核查，不需要立即采集整套 ML-KEM。

**否定当前猜想：**找到预算内的安全反例调度；所谓不可避免的转换其实可被合法重算或预充电消除；观察者看不到所需联合量；或者模型假定的读出与实际电路不符。下界不成立时，反例本身可能成为更好的保护实现。

这一方向深化 [BOLD-36 的资源边界](2026-11-13-key-device-seeds-scaling.md)。新增要求是提交可检查的可行性边界，不预设普遍的物理泄漏定律。

## 能否把可见泄漏约束成一个仍然难解的问题

**直觉：也许可以共同设计密码算法与物理实现，使可观察过程只暴露一种被安全假设允许的关系。** 最激进的具体版本，是研究可见关系能否被限定为满足明确参数条件的 LWE 样本。

跨学科对应：密码学归约与通道设计 → 全执行波形及允许泄漏接口 → 波形可以由有限的困难问题实例高效模拟 → 利用波形的优势可被归约到相应困难性。研究目标从“波形是否平坦”推进到“波形究竟允许计算什么”。

先用普通 LWE 写出候选接口，而不套用现有 ML-KEM 参数：

\[
L_i=(a_i,b_i),\qquad b_i=\langle a_i,s\rangle+e_i\pmod q.
\]

a_i 的分布、秘密 s 的分布、误差 e_i 的分布与独立性、样本数量，以及公开信息 P 与这些样本的关系都必须固定。这只是一个候选泄漏接口。安全性依赖相应 LWE 假设及参数，不能凭式子的外形宣告安全。

真正困难的要求是：**给定当时已公开的信息与允许接口 L，存在一个不读取 s、e 或隐藏份额的高效模拟器，能模拟观察者所见的完整执行。** 完整执行包括噪声产生、秘密读取、算术过程、存储搬运、刷新和清理，并覆盖允许的跨调用联合观察。模拟器不能预先使用尚未生成或披露的 L；交互顺序必须写进安全游戏。

这会形成两个独立的研究问题。第一，额外获得 L 后，指定密码任务是否仍然困难？第二，实际观察是否真的只相当于 L，而没有额外秘密信息？游戏须明确经典或量子对手及其计算、样本和交互预算。任何一项缺失，都不能把这个设计称为有安全归约的实现。

已有研究证明了特定条件下 LWE 对秘密泄漏及辅助输入的稳健性，说明“允许泄漏仍保持安全”有理论基础；其结论不直接覆盖这里的物理接口，也不自动覆盖小秘密、模块结构或任意噪声相关性。[Goldwasser 等的作者机构摘要](https://www.microsoft.com/en-us/research/publication/robustness-learning-errors-assumption/)

**最值得先找的反例：**b 看似是带噪关系，但另一段波形同时泄漏 e。两个片段合起来可能消去误差。类似地，随机数重复、读取 s 的早期脉冲、非预期的系数选择和跨调用相关，都可能使完整观察比 L 强得多。给输出增加随机噪声，不足以实现这个目标。

**波形预测：**在固定公开信息及允许接口之后，预先规定的高效检验不应还能利用残余波形改善指定秘密任务，或区分真实执行与模拟执行。评估需同时保留与接口相关的非平凡波形结构；把模拟器输出设为常数并忽略所有波形，不是完成模拟。有限检验未发现残差只能提供有限证据，最终安全论证仍需完整游戏与归约。

**交给验证者：**先设计一个小型算术模块的允许接口及离散观察语义，尝试构造实现与模拟器，或找到最短的完整执行反例。随后单独讨论参数化构造的困难性；小尺寸实例只能检查语义，不能承载计算安全。物理可实现性是后续独立关卡。

**否定当前版本：**模拟器需要秘密或未公开的误差；波形能联合消掉误差；合法输入使样本分布离开假设；需要偷偷保护一个不受观察的大模块；或即使抽象实现也无法满足接口限制。

这是 [RP-C 实现逆向设计](2026-11-13-three-research-programs.md)的具体构造方向。它最偏离目前的局部波形预测主线，应保留一次小规模理论诊断机会。并不建议直接修改标准 ML-KEM，也不声称已经得到构造。

## 能否让物理解释提前预测另一份实现

**直觉：一个足够好的机制模型，应能告诉我们改哪一行实现会让哪一段响应怎样改变。** 如果每换一个正确实现都必须重新给波形贴标签，得到的可能只是局部拟合。

跨学科对应：反事实预测与变形测试 → 功能等价实现之间的受控差异 → 同一物理机制应约束变换后的响应 → 未测实现能否按事前预测出现或失去指定信号。这里的“跨实现规律”只覆盖明确的平台、操作和干预族。

可以从一个模乘或蝶形内核构造四份功能正确的实现：A 为原实现；B 改指定寄存器的前驱；C 改资源复用关系；D 组合 B、C 的变换。变换是否独立、是否改变指令数和时序，要从实际汇编或 RTL 核对，不能仅凭源码声称控制住了变量。D 留作整份实现的预测检验。

为它们同时保留三个竞争解释：只依赖当前机器字的模型、依赖资源转换的模型，以及含有限供电恢复状态的模型。前两者对改变前驱的响应应不同；第三者还应给出等待间隔或公开前置活动的影响。模型需要提前给出变化的窗口、方向或区间，不能测完后再选择一个有利统计量。

**最强版本：只用 A、B、C 和公开校准固定模型，然后预测 D 的整段预定响应差异。** 可接受的预测可以是某个条件效应消失、峰的相对顺序改变，或恢复幅度落入一个区间。D 上不得重新调整机制、窗口和参数；若仪器校准确需更新，要预先规定只用哪些公开活动以及如何更新。

已有 Scam-V 通过模型等价的输入在真实硬件上寻找抽象反例；LmSpec/LmTest 则允许显式描述候选微架构的泄漏模型并测试实现。本方向借用“可反驳的观察模型”，进一步要求物理参数对受控实现变换给出留出预测；这些先例的摘要不构成这一扩展已实现的证据。[Scam-V](https://arxiv.org/abs/2005.05254)、[LmSpec 与 LmTest](https://arxiv.org/abs/2402.00641)

**波形预测：**资源转换解释应追随指定资源前驱；恢复状态解释应追随预定的时间与供电路径；纯当前值解释不应凭空预测前驱效应。组合变换出现的交互也必须由模型给出，不能默认两个单独效果线性相加。

**交给验证者：**先回传四份实现的功能关系及实际资源差异表，再提交至少两个机制对 D 的分叉预测。先审查预测是否不同，再安排独立采集。大模型可以负责搜索更短的等价变换和竞争解释，验证者决定哪些操作真正实现了干预。

**否定当前模型：**D 的结果落在预定预测之外；新实现只能靠重新定义状态解释；所谓迁移只是认出地址、长度或采集批次；或者所有模型在可实现干预下都给出相同预测。最后一种属于尚不可辨识，应寻找新的干预，而不是投票选模型。

这深化 [原型 M](2026-11-13-echo-representations-mechanism-discovery.md)与 [BOLD-19 的保护干预](2026-11-13-interventions-memory-device-diversity.md)。目标是从“解释一组波形”走向“预言一次实现修改的结果”。

## 分别交给验证者的第一轮任务

| 方向 | 适合的验证者 | 第一轮应交付 | 结果怎样才有价值 |
|---|---|---|---|
| 资源下界 | 掩码电路与形式化研究者 | 极小图、完整操作规则、无解证明或反例调度 | 边界成立，或反例给出更省资源的保护方式 |
| 难问题泄漏 | 格密码与泄漏韧性研究者 | 允许接口、条件安全游戏、候选模拟器或完整执行反例 | 找到可成立的小构造，或明确指出循环假设 |
| 跨实现预测 | 编译器、电路与测量研究者 | 四份等价实现及对留出实现的分叉预测 | 预测通过或失败都能淘汰明确的机制版本 |

每位验证者回传原命题、实际核查范围、最强反例、尚未排除的解释和下一版命题。数学成立、实现存在、物理可见与密码任务收益分别判定。当前 Reference-PPM 波形不直接提供上述受控实现族或完整泄漏接口，不能用同一批离线数据代替这些资格检查。

## 构思修订与来源范围

“有限硬件必然泄漏”收紧为指定实现族与观察模型下的资源可行性问题；“把泄漏变成 LWE 就安全”拆成接口安全与全执行模拟两个证明责任；“模型理解了电路”改为对整份留出实现给出不可事后调整的预测。

本轮由 Codex 单独构思，未开展独立代理讨论。实际阅读为 Hong 与 Kung 原论文的摘要、引言及第二节定义相关内容，LWE 稳健性的作者机构摘要，以及 Scam-V、LmSpec/LmTest 的 arXiv 摘要与元数据。没有完成这些论文的证明复核或本提案的新颖性普查。

没有运行实验、仿真、训练、攻击程序或派发验证任务；文档和链接检查仅用于发布。正式文献卡片数与已有实验状态保持不变。后续证据追加版本和反例，不覆盖本次待验证状态。
