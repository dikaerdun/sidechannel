# 文献收集、筛查与遗漏审计协议

版本：2026-11-12。目标：形成近五年侧信道安全研究的可追溯知识库，重点深入后量子密码，同时保留通用侧信道研究。

## 时间与会议边界

- 滚动五年窗口：2021-11-12 至 2026-11-12。
- 按完整会议年/卷年收集 2021–2026 目录，以免边界与在线发表日期造成遗漏。窗口外但同年度的记录保留并标记，不冒充窗口内发表。
- 期刊卷年、会议举办年、在线发表日期、预印本首次公开日期分别记录。TCHES 的某卷第一期可能在前一年发表，不能仅按出版年筛卷。
- 截止日已公开的录用目录可以收集；尚未正式发表的论文标为 forthcoming/录用记录。CCS 2026 举办于 11 月 15–19 日，截至本次截点尚未举行。
- 核心目录：TCHES/CHES、IEEE S&P、USENIX Security、ACM CCS、NDSS，每年都要核查。
- 扩展来源：CRYPTO、EUROCRYPT、ASIACRYPT、PQCrypto、COSADE、HOST，以及引用追踪发现的相关期刊、会议和预印本。扩展来源不是可忽略的附录，相关论文同样进入主库。
- 五年以前的奠基论文作为 foundation 收录并标明越界原因，不计入五年核心覆盖数量。

## 主题边界

纳入侧信道攻击、泄漏建模与评估、掩码/隐藏/恒时实现、防护与验证、测量与学习方法。覆盖功耗、电磁、时间、微架构、缓存、推测执行、共享资源、相关物理信号及它们的组合。非密码目标的侧信道研究单独标记应用领域，不能因为不攻击密码就从总范围中消失。

PQC 加深索引至少覆盖：ML-KEM/Kyber、ML-DSA/Dilithium、SLH-DSA/SPHINCS+、Falcon、HQC、BIKE、Classic McEliece、NTRU、Saber、FrodoKEM、历史同源方案及其他相关候选。NTT、模约减、采样、拒绝过程、哈希/Keccak、编码/译码、掩码转换与随机性供应等作为跨算法标签。

纯数学密码分析、纯故障攻击、PUF 建模、一般流量/行为推断等按具体泄漏关系判定。与本主题紧邻但不满足纳入条件的条目保存在 adjacent 层并说明理由；不能仅凭标题含“attack”“lattice”“leakage”自动纳入。

## 来源与去重

1. 优先使用会议官方目录、出版商页面、作者/机构论文页、IACR ePrint 和正式标准。
2. Crossref 是出版商提交的书目元数据来源，可用于目录、DOI 和日期核对；数据库记录不替代全文证据。
3. DBLP、搜索引擎等用于发现和交叉核对。搜索首屏、单个作者主页或某个关键词结果不算完整目录。
4. DOI 为优先身份键；没有 DOI 时保留官方论文页和稳定标题键。预印本与正式版本建立明确关系，不能仅因标题相近就自动合并。
5. 原始目录中的非相关论文也保留元数据和筛查状态，以便核查漏筛。目录条目数、候选数、正式纳入数、版本去重后的论文数分别报告。

## 筛查阶段

每条目录记录先处于 pending。关键词只用于安排阅读顺序，不会自动把未命中的论文判为不相关。

1. 全目录逐题筛查，在 `title-decisions.jsonl` 记录 candidate / adjacent / outside_title_scope / uncertain 及理由。它们均为暂判，不构成最终纳入/排除，后续证据可以修订。
2. 对候选和不确定条目阅读原始摘要；对标题不足以判定的未命中条目补查摘要。
3. PQC 核心条目、关键机制和核心主张进一步阅读全文相关章节，记录具体阅读范围。
4. 对待入库主张分别标明作者报告、数学推导、仿真、实测、代码可得性与本地复现状态。标题与摘要不能支持未读的实验数字。
5. 确认研究对象、威胁模型、所需访问、实现/平台、防护条件、恢复目标、限制及反例。无法核实的字段写未知。

摘要及以上阅读后的 include / exclude / adjacent / uncertain 判定另存 `decisions.jsonl`。标题初筛数量、摘要及以上判定数量、正式纳入数量分开统计。未读正文的卡片标为 `abstract_and_bibliographic_metadata`；只读若干章节标为 `selected_full_text_sections`，必须列出范围，不能称为全文精读。

## 引用追踪

从 PQC 核心论文、综述和关键通用方法启动 backward / forward 引用队列，记录起点、方向、轮次、来源和处理状态。

- Crossref 未提交 references 时，标为参考文献数据缺失，而不是论文没有参考文献。
- 从可公开访问的作者或出版商全文核对引用；只公开必要书目信息、关系和原创摘要。
- 新发现的范围内论文进入同一筛查队列，并继续核查其相关引用。
- 维护版本边、引用边与主题关联边，三者不能混称。
- 某一引用数据库没有结果，不证明没有后续引用；需结合作者/出版商页和题名检索核查。
- 未处理候选、失效链接、无法读取全文及未核查引用方向都保留为缺口。没有新发现的某一轮不能单独证明全局无遗漏。

## 完成条件

完成必须同时具有：核心 30 个会议年单元的目录与覆盖证据；扩展来源的相关条目；逐条筛查记录；PQC 专题整理；版本去重；引用追踪记录；来源与阅读层级；可浏览的主题/年度索引；GitHub 提交及远端内容核对。

抓取成功、JSON 可解析、关键词候选列表或一批摘要整理，均不等于上述任务完成。不能保证数学意义上的绝对无遗漏；应给出已核查范围、检索方法、剩余缺口和可重复的审计依据。

## 公开产物与本地缓存

公开目录只包含元数据、原创综述、分类、必要引用关系和链接。完整 HTML、第三方摘要集合及论文 PDF 留在仓库之外的缓存，不提交第三方全文。文件摘要校验值、请求 URL、获取时间、分页数量与失败原因用于追溯。

沿用已有知识库和 SRC 编号；旧条目的阅读层级与实验结论不被新目录自动升级。文献提出或报告的结果不写成我们已复现。
