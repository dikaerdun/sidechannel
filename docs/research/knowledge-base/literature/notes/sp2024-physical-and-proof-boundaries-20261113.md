## 摘要与项目页能确认到哪一步

[Video-Based Cryptanalysis 项目页](https://www.nassiben.com/video-based-crypta)及出版摘要描述 LED 将供电变化转换为视频可见量，实例包含 ECDSA 和历史 SIKE 实现。页面说明易受攻击的密码实现、LED 供电耦合、滚动快门及 LED 充满画面等条件；直接拍摄智能卡读卡器与借同一 USB hub 上外设 LED 间接观察手机是不同布置。不能简化为任意摄像头都能读出任意密码。仅读摘要和项目页，ePrint PDF 获取失败，没有升级为论文正文阅读。

DeepTheft 的摘要将容器内 RAPL 与频率观察分开，作者实验涉及 Docker 20.10.18。频率方案使用另行训练的模型，不能写成 RAPL 模型无需训练即可迁移；当时容器的权限结果也不代表当前所有容器部署。

Silicon Critic 的摘要报告设计与模拟层面的评估，未据此标记为流片后的实测验证。GOMR 的匿名接收者元数据保护按通用侧信道研究收录，不能仅因使用 FHE 就标成后量子实现攻击。

## 主题相邻不等于同一种泄漏

WESEE/INTFAIL 的恶意异常处理与直接内存复制、CI 工作流的缓存对象、WPS 的定位 API 枚举、MetaFly 的无线信号截获，分别保留其具体机制。它们不能仅凭名称中的 cache、leakage 或 side 一词混作 CPU 缓存通道或功耗攻击。MIGP、Pandora 等摘要尚不足以穷尽实现通道的条目也保留待正文复核。
