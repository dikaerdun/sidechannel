# ML-KEM 与 NTT 互动课件 · 第二版

**从四个有标签的格子开始，逐步看懂完整 ML-KEM 运算。** 本课共 17 章，保留真实密钥封装实验，新增单位根、四点手算、蝶形数据通路、真实 256 系数 NTT 和寄存器翻转对照。

## 打开课件

**最方便：**打开 [单文件离线 HTML](./ML-KEM_Interactive_Offline.html)，在 GitHub 文件页面选择 **Download raw file**，下载后用 Chrome、Edge 或 Firefox 打开。所有动画和计算代码都已包含在文件中，无需安装依赖或连接服务。

GitHub 的 HTML 文件预览展示源代码，不会直接运行页面。也可以下载整个仓库，在本目录打开 `index.html`。不支持脚本的文件预览器需要改用浏览器。文献和配套 Markdown 讲义链接需要联网。

想先读文字，请打开 [逐步讲义与八道自测](./TEACHING_GUIDE.zh-CN.md)。

## 三条学习路径

| 路径 | 建议顺序 | 学会什么 |
|---|---|---|
| 建立直觉 | 01 → 02 → 03 → 04 | 系数、共享秘密、模运算、噪声抵消 |
| 算懂 NTT | 05 → 06 → 09 → 10 → 11 → 12 | 卷积、折回、单位根、点值、蝶形与逆变换 |
| 完整算法与硬件 | 07 → 08 → 13 → 14 → 15 → 16 | Module、压缩、标准 NTT、完整 KEM、寄存器和掩码 |

新增章节配有“这一页记住”和“动手试一下”；单步实验可以暂停、回退和重置。先预测下一个结果，再点击验证。并非每章都需要按同样速度学完。

## 要保持清楚的边界

- 模 17 的标量、4 系数和 8 点实验用于教学，没有实际密码安全性。
- 四点、八点入门 NTT 是循环模型；真实 ML-KEM 工作于 `x^256+1`，使用 128 个二系数块乘法。
- 真实 NTT 模型是 FIPS 203 算法 9–12 的规范整数运算，未模拟 Montgomery 编码、延迟约减或处理器流水线。
- 完整 KEM 实验使用 `@noble/post-quantum` 0.7.1 的预构建代码，覆盖三种标准参数；固定课堂种子是公开示例。实验页面会显示秘密，不能当成生产密钥管理工具。
- 寄存器页面展示理想 HW/HD 计数，未使用实测功耗或电磁数据，也不声称据此完成真实设备攻击。
- NTT 是可逆的计算表示；抗量子数学依据和抗侧信道实现应分别理解。

## 内容与源代码

- `index.html`、`style.css`、`extra.css`：页面与样式。
- `app.js`、`extra.js`：原有实验与新增 7 章的交互。
- `math.js`：标量、模块、压缩、多项式及小参数 NTT。
- `real-ntt.js`：[真实 NTT 模型及接口说明](./REAL-NTT-NOTES.md)。
- `crypto-bundle.js`：完整 ML-KEM 预构建浏览器代码；入口保留在 `src/crypto-entry.mjs`。
- `third-party-licenses.txt`：所用第三方 MIT 许可文本。
- `build-offline.py`：把本目录页面导出为单文件 HTML，不需要第三方 Python 库。
- `tests/`：[核验范围与结果](./tests/VERIFICATION.md)。

## 可复现验证

算术测试只需要 Node.js：

```bash
node tests/verify-course.cjs
node tests/verify-real-ntt.cjs
```

如需运行 DOM 交互测试，安装本目录的固定开发依赖后执行：

```bash
npm install
npm run test:ui
```

DOM 测试覆盖导航、预设、非法输入恢复、单步播放、真实 NTT、三参数集 KEM 与密文修改；它不测量真实浏览器布局或硬件侧信道。

重新导出离线文件：

```bash
python build-offline.py
```
